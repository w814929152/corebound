## 2. 复核项 ② · z 值 / SE 独立核算（比例标准误）

公式：单比例 `SE = √(p(1−p)/n)`；两比例 `SE_diff = √(p₁(1−p₁)/n₁ + p₂(1−p₂)/n₂)`；`z = Δ/SE`；`95% CI = p ± 1.96·SE`。

### 2.1 ③ 六槽定因（B=0.817 vs B+bulwark=0.800 · n=300）

| 量 | 我算 | 文档报 | 判定 |
|---|---|---|---|
| `SE_diff` | **0.032120** | 0.0321 | ✅ |
| `Δ` | −0.017 | −0.017 | ✅ |
| `z` | **−0.5293** | ≈−0.52 | ✅ |

→ ③ 的 SE_diff / z **自洽、正确**。

| `SE_T0` | **0.013447** | **0.0126** | 🔴 **不符（应为 0.0134）** |
| T0 CI | [0.736643, 0.789357] → 四舍五入 [0.737, 0.789] | [0.737, 0.789] | ✅ |
| T0 z | −2.7515 → −2.75 | −2.75 | ✅ |

🔴 **发现（文档转录错误）**：② 的 **T0 `SE=0.0126` 与其自身 CI / z 不自洽**。

- 由 T0 定义反算：`SE = √(0.763·0.237/1000) = 0.013447 ≈ 0.0134`。
- 由 T0 的 `z = −2.75` 反推：`SE = 0.037/2.75 = 0.01345` —— 指向 **0.0134**，非 0.0126。
- 由 T0 的 `CI=[0.737,0.789]` 反推：`SE = (0.789−0.763)/1.96 = 0.01327` —— 亦指向 **0.013**。
- 若 `SE` 真为 0.0126，则等价 n ≈ 1139（≠1000）。
- 🟢 **脚本本身无误**：`scan_counterplay_upper_ci.gd` 实跑打印 `SE = 0.013`（两位同为 0.013，因 T0/T1 的 SE 都落在 0.0125~0.0134 区间，3 位小数同为 0.013）→ 正确。**错误仅存在于文档 `§7.2` 表格的 4 位小数转录**。
- 🟡 附注：正确口径下 `SE_T0 (0.0134) > SE_T1 (0.0125)`（p 越近 0.5 方差越大）。文档现写 `0.0126 vs 0.0125` 虽保留了排序，但**量级被压平 —— 仍属错误值**。

## 3. 复核项 ③ · 判读逻辑核查（「反向 = 结构成因，与几何无关」）

**工程判据（预登记）**：`六槽 B+bulwark ≤ B 地板` → 反向是**结构(build)**成因（**与几何无关**）；`> 地板` → 几何(槽位)成因。

**实测触发**：六槽 `0.800 ≤ 0.817` → 触发"结构成因"分支。

**核查结论：方向可支持，但「与几何无关」过度解读（overstated）。** 三条理由：

1. **六槽 Δ 在统计上不显著，不能作为方向证据。**
   `Δ = −0.017`，`z = −0.53`，`95% CI = [−0.080, +0.046]` —— **区间含 0**（甚至含正值至 +0.046）。
   → "六槽 ≤ 地板"只是**点估计**陈述；数据与"零效应"乃至"轻微正效应"**同样相容**。以不显著的点估计判定"方向一致"= 用噪声定符号。

2. **八槽 Δ 亦不显著（边缘）** → 两种几何**都没有稳健的"反向"证据**。
   八槽 `Δ = −0.067`，`z = −1.82`，`95% CI = [−0.139, +0.005]`（含 0）。
   → 「反向是结构成因」建立在**两个不显著的、同号点估计**之上；这是**倾向性**证据，非确证。

3. **实验并非"仅几何"的单变量隔离（存在 confound）。**
   - 六槽臂：`scan_bulwark` → `run_loop_aggro`（**aggro-only**，无 elite、**无 Sapper**）。
   - 八槽臂：`scan_counterplay_player_arm`（C-9）→ `run_loop_proto_aggro`（**proto+elite+aggro**，**Sapper ×3 在场**）。
   → 二者差异至少混淆 `{几何 6·PATH / 8·RADIAL · n_slots 6/8 · elite ON/OFF · Sapper ON/OFF · runner}`。
   → 尤其 **Sapper（塔杀手 ×3）与 bulwark（挪塔）存在机制交互**，无法排除"反向幅度由 Sapper×几何共同调制"。
   → 文档 `§3.2` 自己声明"口径不同 → **不可直接相减**"，但 `§7.1` 仍做了跨口径的定性归因 → **内部张力**。

4. **文档已部分自纠（应予肯定），但结论框仍过度。**
   `§7.1` 的"幅度细化（诚实标注）"正确写出"六槽 z≈−0.52 **噪声内** / 八槽 z≈−1.81 边缘显著" —— 诚实。
   但 `§7.1` 结论行与 `§7.3` 表仍写 **「🟢 结构（build）」**、**「非几何特有 / 与几何无关」** 为已确立结论 → **结论强度 > 数据支持**。

**建议的保守表述（供工程/设计采纳）**：

> ③ 证明：八槽的较大负效应（`−0.067`）在六槽**未被复现**（六槽 `≈ −0.017`、**不显著**）→ **反向的幅度与几何/config 相关**。
> 但「反向是**纯结构**成因、**与几何无关**」**未被证明**：六槽 Δ 的 95% CI 含 0，且六槽/八槽还混淆了 runner 与 elite/Sapper。
> → 宜降级为 🟡「**倾向**结构成因（六槽点估计不指向正效应，n.s.）；幅度受几何/config 调制；欲确证需**单变量对照**（固定 runner 与 elite/Sapper，仅换几何）」。

🔴 **判定：❌ 判读过度（overstated）** —— 事实层（反向存在、幅度几何调制）成立；**因果归因层（"与几何无关"）**超出数据支持。**不影响 ③ 作为"反向事实"本身的登记**，但不应作为"结构 vs 几何"二分的定论。
