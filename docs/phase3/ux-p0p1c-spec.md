# §A 环境换装规格（art-bible §2.4）

## A.1 设计裁决：把 §2.4 的"环境雾色"当**色相锚**，明度重映射以守住暗场身份

> art-bible §2.4 给了四档"环境雾色"（`#2A3550` / `#4A2E52` / `#5A1E32` / `#2A1240`），语义是"**背景/雾底**"。但这四值**明度远高于现状背景**（`#141726`），若**逐字**当背景用，会让整场**骤然变亮**，既破坏"暗底衬托数值爆炸光效"的既有身份（art-bible §11-1 选题理由），也会**压低单位与地面的对比**（可读性风险）。

**裁决（本刀采用）**：取 §2.4 四值的**色相与饱和关系**作为**色调迁移锚**，把**明度重映射进现有暗场包络**，并为每档**显式钉死**四个环境元素的 hex（背景 / 场地圆 / 同心环 / 放射刻度），**保证**：

1. 明度阶梯 `背景 < 同心环 < 场地圆` 恒定成立（= 第一刀已建立的"暗底 + 亮场地"结构）；
2. 单位配色**一律不动** → 塔青/怪橙对场地的对比**全部**保持 ≥ 4.5:1（见 §A.4）；
3. 场地圆明度**随档单调下降**（0.0271 → 0.0200 → 0.0200 → 0.0157）→ 视觉读感 = **"光在流失、压力在爬升"**，与波次叙事同向。

> 🟡 这是对 art-bible §2.4 的**有意偏离**（逐字用背景色=过高明度）。**只登记不改 art-bible**，见 **§D-8**。

```gdscript

static func tier_of(w: int) -> int:

    if w <= 5:  return 1
    if w <= 10: return 2
    if w <= 15: return 3
```

- 迁移**只在跨档边界**发生（`w ∈ {1, 6, 11, 16}` 三处/四处），**同档内波次不换色** —— 对齐 art-bible §2.4「每 5 波做一次环境色调迁移」。

## A.4 对比度校验（🔴 不得牺牲可读性的硬地板）

> 计算法：WCAG 相对亮度 → 对比度 `(L1+0.05)/(L2+0.05)`。**单位**取主色：塔/核心青 `#3ED0E8`、怪橙 `#FF6B3D`（**不随档变**）。

| 档 | 场地圆 lum | 场地 vs 背景 | **塔青 vs 场地** | **怪橙 vs 场地** | 同心环 vs 场地 |
|---|---|---|---|---|---|
| T0 夜幕 | 0.0216 | 1.21:1 | **7.96:1** | **5.18:1** | 1.11:1 |
| T1 晨雾 | 0.0271 | 1.28:1 | **7.39:1** | **4.81:1** | 1.17:1 |
| T2 黄昏 | 0.0200 | 1.22:1 | **8.14:1** | **5.30:1** | 1.14:1 |
| T3 血夜 | 0.0200 | 1.25:1 | **8.14:1** | **5.30:1** | 1.16:1 |
| T4 虚空 | 0.0157 | 1.21:1 | **8.67:1** | **5.65:1** | 1.12:1 |

**1 帧可辨的对比度地板（契约）**：

| 关系 | 地板 | 全档实测最小值 | 结论 |
|---|---|---|---|
| 塔/核心青 ↔ 场地 | **≥ 4.5:1** | 7.39:1（T1） | ✅ 富余 |
| 怪橙 ↔ 场地 | **≥ 4.5:1** | **4.81:1（T1）** | ✅ 贴线达标（T1 为全场最亮场地 = 最坏帧） |
| 场地 ↔ 背景（play-area 边界） | **≥ 1.15:1** | 1.21:1（T4） | ✅ |
| 同心环 ↔ 场地（刻度可见） | **≥ 1.10:1** | 1.11:1（T0） | ✅ |

> **过渡期安全**：任一 3s 过渡中，场地 lum 始终落在两端点之间（单调解），而**最坏端点 = T1（0.0271）** → **过渡全程** `怪橙↔场地 ≥ 4.81:1`、`塔青↔场地 ≥ 7.39:1`。**任意单帧都不低于地板**。

### A.4.1 灰度可分性复核（art-bible §9.1/§9.2 / 任务硬约束 7）

单位配色不变 → 灰度亮度**排序恒定**：

```
塔青 0.520  ≈  核心内芯(近白) > 塔青 > 怪橙 0.321 > 空槽钢灰 0.370 > ... > 场地 0.016~0.027
                                          （塔/怪/核心/空槽 全部 ≫ 场地）
```

**结论**：换装只改**环境层明度**（远低于任何单位），单位↔地面灰度对比**只增不减**；四重编码（颜色/形状/底座环/描边色）中**三条与灰度无关**（形状/底座环/描边色），**完全不受影响**。✅ 前两刀 Basic P0 未被削弱。

## A.5 档间过渡方式（🔴 不得突变）

> art-bible §2.4 原文：「迁移用 **3 秒缓动过渡**，不得突变（突变会造成视觉惊吓与可访问性风险）。」

| 参数 | 值 | 说明 |
|---|---|---|
| 触发 | **跨档边界**（`tier_of(w)` 变化） | 同档波次不触发 |
| 时长 | **3.0 s** | art-bible §2.4 明定 |
| 曲线 | **smoothstep** `e(t)=t²(3−2t)` | 起止导数为 0 → 无"起跳/急停"；比线性更接近"缓动"语义 |
| 空间 | **线性 RGB 逐通道 `Color.lerp`** | Godot 无 OKLab/HSL lerp；两端明度相近 → 中途明度下探可忽略（见 §A.4 过渡期安全） |
| 频率安全 | 3 s 单调过渡 ⇒ **≈0.17 Hz 包络** | **远 < 3 Hz**（art-bible §9.2 红线②，光敏癫痫）✅ |
| 起点 | `T0` 基线（首帧 = 现状色） | 无开波前不换色 |

**伪代码骨架（每个渲染器各自持有一份，见 §A.6）**：

```gdscript
var _env_tier: int = -1
var _env_prev: int = -1
var _env_t: float = 1.0            # 1 = 过渡完成
const ENV_FADE_SEC := 3.0

func _update_env(w: int, dt: float) -> void:
    var ti := EnvPalette.tier_of(w)
    if _env_tier < 0:
        _env_tier = ti; _env_prev = ti; _env_t = 1.0    # 首次：直接落位，无过渡
    elif ti != _env_tier:
        _env_prev = _env_tier; _env_tier = ti; _env_t = 0.0
    if _env_t < 1.0:
        _env_t = minf(1.0, _env_t + dt / ENV_FADE_SEC)

func _env_col(key: String, alpha: float) -> Color:
    var a: Color = EnvPalette.get(_env_prev, key)
    var b: Color = EnvPalette.get(_env_tier, key)
    var e: float = _env_t * _env_t * (3.0 - 2.0 * _env_t)     # smoothstep
    var c := a.lerp(b, e)
    return Color(c.r, c.g, c.b, alpha)
```

## B.1 威胁方位楔形

### B.1.0 现状与目标

- **现状**（第一刀已落）：`_draw_threat_wedges()` 遍历**每只存活怪**，在其方位画一段 `±6°` 弧（`#FF6B3D @α0.45`）→ 表达"**哪边正在来怪**"。**N 只怪 = N 次 `draw_arc`**。
- **目标**：升级为"**提示下一波来袭方位**"（预测性），并修掉现状的"楔形随怪数线性增长（可能糊成一片）"。

### B.1.1 数据缺口（🔴 关键，先读）

- 「下一波方位」= 第 `w+1` 波的**出生方位角**。出生角是**确定性**的：`SpaceModel.spawn_theta(index, w+1)`（黄金角低差异序列，**零 RNG**，`space_model.gd:100`）。
- **但**要枚举 `index` 必须知道**下一波出生数 `n_next`**，而 `n_next = _WaveSim.monster_stats(w+1, cfg)["n"]`——**属玩法/仿真侧**（`wave_director.gd:242` 现只导当前波 `n`）。
- ⇒ 本项**需要新增 snapshot 字段**（见 **§E G-8**）：
  ```
  WaveDirector.snapshot() 增：
      "next_wave": { "w": int, "n": int, "angles": Array[float] }   # 推荐
  或  "next_spawn_angles": Array[float]                              # 最小化
  ```

> 🔴 **禁止**渲染层为拿 `n_next` 去调 `_WaveSim.monster_stats()` / 直接算 `spawn_theta` 枚举——**那会跨出纯渲染层**（读仿真数据），违反 §0.2-3。**必须由玩法侧以只读字段导出。**

### B.1.2 分级交付

| 级 | 内容 | 是否需要新字段 | 本刀 |
|---|---|---|---|
| **MVP** | **现状楔形「扇区去重」**：把 N 只怪的方位**吸附到 8 个 22.5° 扇区**，每扇区只画 1 段弧，α 随该扇区怪数递增 → 修掉"糊成一片" + **降 draw call** | ❌（只用现有 `monsters[].pos`） | ✅ **落地** |
| **增强** | **下一波预告楔形**：在出生环上按 `next_wave.angles` 画**预告弧**（与"当前威胁"**视觉区分**） | ✅（G-8） | 🔶 **字段就绪后落地；未就绪 = 零绘制** |

### B.1.3 MVP：现状楔形扇区去重（参数表）

| 参数 | 值 | 说明 |
|---|---|---|
| 扇区数 | **8**（每 45°） | 与放射刻度 ×8 对齐（方位直觉一致） |
| 吸附 | `idx = floor(fposmod(atan2(pos−core), TAU) / (TAU/8))` | 每怪归 1 扇区 |
| 弧宽 | **±11°**（22° 跨度） | 扇区中心左右各 11° |
| 弧半径 | `R_s`（出生环上） | `= SPAWN_RADIUS * sc` |
| 弧宽（线宽） | `maxf(2.0, 0.30*sc)`（同现状） | |
| 颜色 | `#FF6B3D` | 敌方橙（现状） |
| α | `0.35 + 0.05 * min(count, 5)`，**上限 0.60** | 怪越多越亮 → "这方位压力大"**余光可读** |
| 上限绘制数 | **≤ 8** 段 `draw_arc` | 由"≤N"降为"≤8" |

```gdscript
func _draw_threat_wedges(sc: float) -> void:
    var ms: Array = _snap.get("monsters", [])
    if ms.is_empty(): return
    var core := _SpaceModel.RADIAL_CORE
    var c := _to_screen(core)
    var rs := float(_SpaceModel.SPAWN_RADIUS) * sc
    var sect := {}                                  # idx -> count
    for m in ms:
        var pos: Vector2 = m["pos"]
        var a := atan2(pos.y - core.y, pos.x - core.x)
        var idx := int(floor(fposmod(a, TAU) / (TAU / 8.0)))
        sect[idx] = int(sect.get(idx, 0)) + 1
    for idx in sect:
        var ac := TAU * float(idx) / 8.0 + TAU / 16.0     # 扇区中心
        var alpha := minf(0.60, 0.35 + 0.05 * float(mini(int(sect[idx]), 5)))
        draw_arc(c, rs, ac - deg_to_rad(11.0), ac + deg_to_rad(11.0), 8,
            Color(P_ENEMY.r, P_ENEMY.g, P_ENEMY.b, alpha), maxf(2.0, 0.30 * sc), true)
```

## B.2 核心呼吸缩放

### B.2.1 目标与现状

- **现状**：核心**内芯**已 `±6%` 呼吸（`_vfx_t`，1.6s，`_draw_radial_core`）。外环 / 中盘 / 刻齿**恒定**。
- **目标**：让**整个核心圆盘**做**极小幅**周期缩放（"活着"的感觉），内芯保留其更快的一层。

### B.2.2 参数表

| 参数 | 值 | 说明 |
|---|---|---|
| 层级 | **盘级**（外环 + 中盘 + 刻齿 + 外描边 + 受击闪） | 整体呼吸 |
| 幅度 A | **±2.5%**（`0.025`） | 极小幅 → 不读作"缩放"而读作"呼吸/脉动" |
| 周期 P | **2.4 s** | 比内芯（1.6s）**更慢** → 两层不同频叠出"有机感"，避免机械同步 |
| 相位 | `φ = 0` | 起始 = 最大 |
| 曲线 | `sin`（天然 ease-in-out） | 无需额外缓动 |
| 内芯 | **保留现状 ±6% @1.6s**（不回退） | 内层更快、更明显 = "心跳" |
| 触发 | **常驻**（波内/波间均播） | 不依赖 `w` |
| 落点 | 层5（核心）+ 层3（核心影，**同步缩放**） | 影随盘缩，避免"影浮于盘外" |

```
R_disc(t) = U_CORE * sc * (1 + 0.025 * sin(2π·t / 2.4))     # t = _vfx_t
内芯半径 = R_disc(t) * 0.32 * (1 + 0.06 * sin(2π·t / 1.6))   # 保留现状叠加
```

```gdscript
func _core_breath() -> float:
    return 1.0 + 0.025 * sin(_vfx_t * TAU / 2.4)

# _draw_radial_core：所有 rc 乘 _core_breath()
var rc := U_CORE * sc * _core_breath()
# _draw_all_shadows：核心影半径同步
_blob_shadow(_to_screen(_SpaceModel.core_pos()), 1.15 * U_CORE * sc * _core_breath(), ...)
```

### B.2.3 绘制顺序 / 性能 / 可访问性

- **落点**：层5（核心）与层3（核心影）。**无重排**。
- **性能**：**0 次新增调用**（仅半径乘一系数）；`_core_breath()` 是纯 `sin`。
- **可访问性**：2.4s 周期 = **0.42 Hz ≪ 3Hz** ✅；幅度仅 2.5%，不构成闪烁。可选：接"减弱特效"开关时冻结呼吸（非硬要求）。

## B.3 怪物 squash & stretch 摆动

### B.3.1 目标与"帧间稳定"约束

- **现状**：怪身 `_blob12(c, R, out_dir, rs, ts)` 用**固定** `rs/ts`（Rush 径向拉长 1.5/0.75；Tank 宽扁 0.85/1.25）——**无时间变化**。
- **目标**：移动时的**挤压拉伸 + 摆动**（art-bible §3.1「扭曲、挤压拉伸、摆动前进」）。
- 🔴 **硬约束**：**只读 `pos` 派生、帧间稳定**（第二刀裁掉"命中闪/死亡碎片"是因为**无稳定怪物 id**；移动摆动**不依赖 id**，故可做）。
- 🔴 **不得**引入逐帧噪声 / 随机（会抖）；**不得**破坏剪影类（`细长/中等/粗短`，art-bible §11-4 / 第一刀 §A.2.2）。

### B.3.2 相位派生（🟢 只用 `pos`，无 id、无 RNG）

用**极坐标**构造一个"随移动平滑推进"的相位：

```
θ = atan2(pos.y − core.y, pos.x − core.x)     # 方位（怪径向移动 → θ 恒定）
ρ = |pos − core|                              # 到核心距离（单调减小）
ph = θ + (−ρ)·k_ρ + φ_proto                   # 相位
```

| 项 | 作用 | 为何稳定 |
|---|---|---|
| `θ`（恒定项） | **给每只怪一个天然不同的相位偏移**（同环形上不同方位的怪不同步） | 怪**径向**移动 → θ 不变 → 偏移恒定 |
| `−ρ·k_ρ`（时变项） | 相位**随接近核心平滑推进** → 摆动速率**绑定移动** = "在走" | ρ 由 `pos` 唯一决定、随帧平滑变化 |
| `φ_proto` | 原型间错开（不同类型不同步） | 常量 |

> ✅ **帧间稳定**：`pos` 由 snapshot 平滑插值 → `ph` 平滑 → 无抖。**边缘 case**：新怪出生在 `ρ≈R_s` → 同半径怪 `−ρ·k_ρ` 相同，但 `θ` 各异 → **仍不同步**（仅"从边缘涌入"的一圈大致同频脉冲，可接受且强化"涌入"读感）。

### B.3.3 参数表

| 原型 | 拉伸幅度 `A` | 相位偏移 `φ_proto` | 体摆动幅 `rot_amp`(rad) |
|---|---|---|---|
| **Rush**（小快） | **0.10** | `0.000` | 0.18 |
| **Swarm**（中） | **0.06** | `2.094`（2π/3） | 0.12 |
| **Tank**（大慢） | **0.04** | `4.189`（4π/3） | 0.08 |
| 精英 | 继承原型 | 继承原型 | 继承原型 |

| 全局参数 | 值 | 说明 |
|---|---|---|
| 空间频率 `k_ρ` | **0.50 rad/unit** | 约每 `2π/0.5 ≈ 12.6 u` 一个完整呼吸 → 在 `v0=5.5 u/s` 下 ≈ **0.44 Hz**（各怪 `m_spd` 0.667~1.333 → 0.29~0.58 Hz），**全部 < 3Hz** ✅ |
| 时间曲线 | `sin`（派生自 `pos`，无独立计时器） | |
| 大原型阻尼 | 幅度随体量**递减**（0.10→0.06→0.04） | 大怪更"沉稳"，小怪更"活蹦" |

**挤压拉伸的守恒近似**（径向拉长 ⇔ 切向压扁）：

```
sw = sin(ph)
rs' = rs · (1 + A·sw)          # 径向（朝核心轴）拉长
ts' = ts · (1 − A·sw)          # 切向压扁（体积近似守恒）
rot' = rot_amp · cos(ph)       # 体摆动：绕中心小幅旋转（"摆动前进"）
```

### B.3.4 伪代码骨架（层7 怪循环内）

```gdscript
# _draw_radial_monsters 循环内，替换原主体绘制的 transform 参数
var rho := pos.distance_to(core)
var th  := atan2(pos.y - core.y, pos.x - core.x)
var k_rho := 0.50
var ph  := th + (-rho) * k_rho + _sway_phase(String(m["proto"]))
var sw  := sin(ph)
var A   := _sway_amp(String(m["proto"]))            # .10 / .06 / .04
var rs2 := rs * (1.0 + A * sw)
var ts2 := ts * (1.0 - A * sw)
var rot2 := _sway_rot(String(m["proto"])) * cos(ph)
# 主体：把 (out_dir) 换成 (out_dir + rot2)，rs/ts 换 rs2/ts2
draw_colored_polygon(_blob12(c, R, out_dir + rot2, rs2, ts2), P_ENEMY)
# 外扩描边同步（用同一 rs2/ts2/rot2 → 见下）
draw_polyline(_closed(_blob12(c, R + w * 0.5, out_dir + rot2, rs2, ts2)), P_MON_EDGE, w, true)
```

- 🔴 **描边必须与主体同参数**（`out_dir+rot2, rs2, ts2`），否则"描边错位"。
- 🟢 **尖刺扇保持沿 `out_dir`（朝核心）不动** — 尖刺语义 = "扑向核心"，**不该跟着摆**（摆动只属于"身体"，属 §3.1「身体扭曲/摆动」）。可选：整扇随 `rot2·0.5` 微转（非必须）。
- 🟢 **投影（影）不参与摆动** — 影用 `_body_units()`（未缩放）→ 影**恒定**，保证"地面锚点稳定"、无抖动。
- 🔴 **剪影类保全**：`A ≤ 0.10` 使 `rs/ts` 波动 ≤ ±10% → `细长/中等/粗短` 三类**不越界**。

### B.3.5 绘制顺序 / 性能 / 可访问性

- **落点**：层7（怪）。**无重排、无新增图元**（仅改 `_blob12` 入参）。
- **性能**：**0 次新增调用**（每怪多约 6 次浮点运算：`distance/atan2/2×sin·cos`；`draw_*` 次数不变）。百怪 ≈ +600 浮点/帧，可忽略。
- **可访问性**：频率 0.29~0.58 Hz ≪ 3Hz ✅；幅度 ≤10% 不构成闪烁；不依赖色相（形状运动通道）。

### 怪物摆动（相位由 pos 派生）

```
   ph = θ + (−ρ)·0.50 + φ_proto        θ=方位(恒定) ρ=到核心距离(单调↓)
   sw = sin(ph)
   rs' = rs·(1+A·sw)   ts' = ts·(1−A·sw)   rot' = rot_amp·cos(ph)
   A: Rush .10 / Swarm .06 / Tank .04    频率≈0.29~0.58Hz (<3Hz ✅)

   ρ 减小 →  ph 推进 →  身体 拉长/压扁 + 小角度摆动  = "摆动前进"
   同环不同方位怪：θ 不同 → 天然错相，不机械同步
   🔴 尖刺扇仍朝核心（不随摆）、投影恒定（地面锚点稳定）
```
