## 0. 三句话结论（给赶时间的人）

1. **旧规格的事实基础已作废**（`snap/rest` 缺陷修复 → aggro 基线整批撤回，见撤回声明）。旧规格 §3.2 用「无塔死局逐位相同」证明「**Δ 不可能为负**」，而修复后实测 `Δ_free = −0.0133` / `Δ_priced = −0.0333` —— **证明错了，不是实现错了**。根因：修复是**双向操作**（⊕ 恢复 DPS ⊖ 把塔重新暴露给仇恨怪），旧证明只算了 ⊕（→ R-T11）。
2. 🔴 **主判据量从「Δ 的效应量」换成「`hit_surv > 0` 的存在性」**——即"**存不存在掉了塔又爬回来并存活的局**"。它比 Δ 直接、结构性、**不需要效应量门槛**（666 次机会下，真实救回率 ≥0.5% 时检出率 ≥96.5%，见 §3.3）。**Δ 降为并列读法**。
3. 🔴 **单侧改双侧**（单侧的正当性 = "负向效应结构上被排除"，该前提已被推翻）。样本量随之从旧规格的 ≈1140/臂（单侧）上调到 **1480/臂（双侧）**；三臂合计 **4440 局**。参数锁死不变。

## 1. 为什么必须换主判据量

### 1.1 Δ 这个量在本实验里"两头都不靠"

| 问题 | 说明 |
|---|---|
| **① 符号先验不确定** | 修复 ⊕ 恢复 DPS、⊖ 重新暴露仇恨（`wave_sim_aggro:443/:464` 仇恨选目标跳过 `disabled` 塔）→ Δ 可正可负，**不是"越大越好"的一维量**。 |
| **② 单侧正当性丧失** | 旧规格 §3.2 ④ 用「212 局逐位不变」推出 Δ ≥ 0，据此取单侧。修复后 `n_identical = 2`（配对破功）且 Δ 实测为负 → **前提全倒**。 |
| **③ 效应量门槛是"产品口味"** | `+0.05` 这个数是我在 R-T6-b 初判时给的（旧规格 §7 Q-V7-1 已如实标注"这是产品口味，需用户拍板"）。它不是从设计里推出来的常数 → 拿它当主判据，等于把结论挂在一个口味值上。 |
| **④ 它回答不了设计问题** | GDD §2.3 的命题是**存在性**的：「玩家在下一个安全窗**可以**做点什么」。这个问题的答案只有"能/不能"，不是"平均能救回 5% 还是 17%"。 |

### 1.2 `hit_surv > 0` 为什么更好

| 维度 | Δ（效应量） | `hit_surv > 0`（存在性） |
|---|---|---|
| **与 GDD 命题的对应** | 间接（"平均救回多少局"） | 🔴 **直接**（"有没有一局是掉塔→修→爬回→存活"） |
| **效应量门槛** | 需要（+0.05 是口味值） | 🟢 **不需要**（0 与非 0 的界限是结构性的） |
| **符号问题** | 🔴 受双向操作污染 | 🟢 **不受**（只数"存活且曾塔死"的局，Δ 为负不影响它 > 0） |
| **单侧/双侧争议** | 有（且已判双侧） | 🟢 **无**（存在性判据没有方向性假设） |
| **可解释性** | "Δ=+0.05 = 塔死局救回 17%"（要换算） | 🟢 "`n_rescue = 14`，即 666 个塔死局里有 14 局靠修爬回来了" |

🟢 **Δ 保留为并列读法**，用于回答**第二个问题**：「存在性成立之后，修复的**量**够不够玩家感知到、够不够撑起一个正式功能」（判 A 之后看 Δ 的双侧 CI，见 §4 分支 A）。

| 项 | 规格 |

| **每臂局数** | 🔴 **1480 局**（双侧 α=0.05、power=80%、检出 `Δ = 0.05`、假设 `p̄ = 0.62`） |

## 3. 统计口径

### 3.1 Δ 的双侧判读（并列读法）

| 量 | 值 |
|---|---|
| `SE_Δ`（n=1480，独立两比例，`p̄ ≈ 0.62`） | **≈ 0.0178** |
| 双侧 95% 临界（`1.96 × SE_Δ`） | **≈ 0.0350** |
| 🔴 **判读线** | `Δ ≥ +0.035` → 双侧显著为正；`Δ ≤ −0.035` → 双侧显著为负；`|Δ| < 0.035` → **与 0 不可分** |
| 参照 | 旧规格 n=300 时 `SE_Δ ≈ 0.0402`（Δ=+0.05 只有 1.28 SE → 灰区）；加跑后 `SE_Δ` 降到 0.0178，Δ=+0.05 → **z = 2.81**（双侧 p ≈ 0.005）✅ |

🟢 **配对已破功（`n_identical = 2`）→ 一律用独立两比例 SE**，不再有"配对 vs 保守"的两模型之争（旧规格 §3.4.1 的强制前置校验因此降级为登记项）。

### 3.2 主判据 `n_rescue` 的统计性质（存在性检验）

- **H₀（致命诊断）**：干预臂中"塔死局最终存活"的概率 `p_rescue = 0`（或极低）。
- **检验**：`n_rescue ≥ 1` 即拒绝 H₀ —— **一个反例足够**。
- **上界估计**：若 `n_rescue = 0` 且 `n_eligible = n` → `p_rescue` 的 **95% 上界 ≈ 3/n**（rule of three）。
　`n = 666` → 上界 ≈ **0.45%**。即"连 0.45% 的救回率都没有"，这本身已是很强的陈述。

### 3.3 🟢 检出能力（为什么 1480 够，不用更多）

`P(至少 1 局被救回) = 1 − (1 − p_rescue)^{n_eligible}`

| `p_rescue` | `n_eligible = 281`（保守：按 OFF 臂塔死率 0.19×1480） | `n_eligible = 666`（预期：按 FREE 臂 N=300 实测 135 线性外推） |
|---|---|---|
| 0.002 | 43% | **74%** |
| 0.005 | 76% | **96.5%** |
| 0.01 | **94%** | **99.9%** |
| 0.02 | 99.7% | ≈100% |
| 0.05 | ≈100% | ≈100% |

→ 🟢 **结论**：1480/臂对"存在性"判据**检验力过剩**（真实救回率只要 ≥1%，保守口径下检出率已达 94%）。
→ 🔴 **反过来这也是纪律**：若 `n_rescue = 0`，那不是"样本不够"，那是**真的没有**—— 此时必须走 §4 分支 B/C，🔴 **禁止以"样本不足"为由回避定性**。

## 4. 判读分支（🔴 按新口径重写）

| **C · 致命诊断**<br>🔴 **需双侧显著** | 两臂 `n_rescue` 均为 0，**且** `Δ_free` 与 `Δ_priced` 的双侧 95% CI **上界均 < 0**（`z ≤ −1.96`，即 `Δ ≤ −0.035`） | 🔴 修复不仅无效、还**显著更糟** → 塔死亡是正反馈螺旋的**不可脱出环节**（R-T10 坐实） | 🔴 **才允许**动 GDD §2.3 定性 → 走 **Q-A(b) 改机制**（Disabled 保留部分输出 / 缩短 Disabled 持续波数 / 自动重启）；**R-T10 同步升为立项** |

### 4.1 🔴 为什么分支 C 要双侧显著，分支 A 不要

| | 分支 A | 分支 C |
|---|---|---|
| **命题类型** | **存在性**（∃ 一局被救回） | **全称性**（∀ 局都救不回 + 修复显著有害） |
| **举证责任** | 🟢 低 —— **一个反例即推翻** H₀，且检出能力已量化（§3.3） | 🔴 高 —— 它是**唯一会改写已定稿设计定性**的分支，改定性 = 推翻 §2.3 的定稿结论 |
| **需要的证据** | `n_rescue ≥ 1` | `n_rescue = 0` **＋** `p_rescue` 的 95% 上界（≈0.45%）**＋** Δ 双侧显著为负 |
| **若只满足一半** | — | 🟡 `n_rescue = 0` 但 Δ CI 含 0 → **判 B，不判 C**。<br>🔴 **"救不回来"与"修了更糟"是两个不同命题**，前者不足以支撑改定性 |

> 🔴 **纪律**：分支 C 触发后**不得由我直接改 GDD**，必须回 Q-A 二次拍板（这是设计哲学选择，与 Q-R2-1「塔死亡是税还是风险」同一层面）。
