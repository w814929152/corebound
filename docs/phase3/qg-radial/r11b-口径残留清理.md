## 1. ① `ATTRITION` 口径判定（F-4 / D-W7）· **结论：同一物理量，非撞名**

### 1.1 三者对照

| 出处 | 定义 / 用法 | 值 | 单位 |
|---|---|---|---|
| `mechanics-tower-life-death` §2.1 / §4.2 V-1 | `ATTRITION = 怪物对塔 DPS ÷ HP0` | 1.50 | s⁻¹ |
| `radial-core-siege-draft` §6.2 / §7.3 V-1′ | 同式（"复合参数"，措辞标"无量纲"→ **措辞不准**） | 1.50 | s⁻¹ |
| `wave-spawner` §2.10.3 / §5.5 | 同式 + 速率锚点 `T_disarm` | 0.083 | s⁻¹ |

### 1.2 判定依据（读引擎实际消费点 → 钉死读法）

- **定义**：三处同源同义 = `怪物对塔 DPS ÷ HP0`。`[HP/s] ÷ [HP] = s⁻¹` → **是速率，不是无量纲**。
- **引擎实际消费点**（权威）：
  - 常量：`scripts/data/monster_data.gd` → `const ATTRITION := 1.5`（⚠️ **`ATTRITION` 不在 `mvp_config.gd`** —— 该文件零命中；此处更正任务书里的路径预期）。
  - 解析：`MonsterData.resolve_attrition(override)`（两处消费点统一经此取值）。
  - 消费：`scripts/engine/wave_sim_aggro.gd:821` 与 `scripts/gameplay/wave_director.gd:518` → `dmg = ATTRITION × HP0 × m_dps × dt`（`DT = 0.1s`）。
  - → 逐帧积分 = **每秒速率** ⇒ **"每秒"读法被代码确证**；"每波"读法在代码中**无消费路径** ⇒ 作废。

### 1.3 换算关系与值差成因

- **换算**：`ATTRITION = 1 / T_disarm`（`h=1, m_dps=1`）⟺ `T_disarm(h=1) = 1 / ATTRITION`。
  - 定稿 `1.50 s⁻¹ ⟺ T_disarm(h=1) ≈ 0.667 s`。
  - 旧提案 `0.083 s⁻¹ ⟺ T_disarm(h=1) = 12.0 s`。
- **值差（1.50 vs 0.083，差 18×）成因**：`0.083`（D-W7 · `T_disarm=12s`）是 **V-1 之前的提议**；实际 V-1（300 局 MC · 2026-10-03）在**原区间 `[0.5, 8]`（每秒口径）**上扫描、定稿 **1.50**（首个全判据通过点）→ **`0.083` 未被采纳**。二者**同量同读法**，差在"提案 vs 定稿"，非单位/读法冲突。

### 1.4 处置

| 项 | 动作 |
|---|---|
| 读法钉死 | **"每秒"（s⁻¹）**；"每波"读法作废（无代码路径） |
| F-4 正式陈述 | 写入 `wave-spawner.md` §2.10.3「F-4 正式处置」🧷 块（6 条） |
| 互指针 | `wave-spawner` §5.5 / 交接点 ⑦ / W16 / §10.2 D-W7 ↔ `radial-core-siege-draft` §6.2「`ATTRITION` 单位注」（头部勘误 ① 同步） |
| 引擎改名 | 🟢 **不需要**（同一量、无符号冲突） |
| 待办（**登记 · 不执行**） | 建议在 `monster_data.gd` 的 `ATTRITION` 注释补"单位 s⁻¹"（纯注释，非改名） |
