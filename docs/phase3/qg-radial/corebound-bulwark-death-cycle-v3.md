## 2. 机制总览：塔的「死」的四段式时间线

```
波内 t0 ─────────── 塔 HP 归零 ─────────────────────────────────→ 波末
             │                                                    │
             ▼                                                    ▼
       ┌───────────┐   N 秒   ┌───────────┐   K 用尽   ┌──────────────────┐
       │ ① 停机    │ ───────► │ ② 重启    │ ────────► │ ③ 终局 Disabled  │
       │ Disabled  │          │ 恢复主动  │           │ 直到波次间       │
       │ + 残响 ON │          │ 残响 OFF  │           │ 残响 ON（整波）  │
       └───────────┘          └───────────┘           └──────────────────┘
             │                     │                          │
             └── 残响 = 减速场 ────┘                          │
                 （怪照常前进，只是变慢）                      │
                                                              ▼
                                            波次间：残响 OFF → §2.3 三选一
                                                   （修 / 拆 / 放着）
                                                   🔴 定性一字不改
```

| 段 | 状态 | 主动（DPS / 吸火） | 被动（残响） | 谁决定 |
|---|---|---|---|---|
| **① 停机** | `disabled = true`，`K` 未用尽 | ❌ 停输出 · ❌ **不被选为仇恨目标**（E-T5） | ✅ **ON** | 系统（自动） |
| **② 重启** | `disabled = false`，`hp = hp_max` | ✅ 恢复 · ✅ 自动重回仇恨池 | ❌ **OFF**（互补） | 系统（自动，零玩家输入） |
| **③ 终局 Disabled** | `disabled = true`，`K` 用尽 | ❌ | ✅ ON 到波末 | 系统 |
| **④ 波次间** | `disabled` 保持或解除 | — | 🔴 **OFF**（波次间无战斗） | **玩家**（§2.3 三选一） |

> 🏆 **这张表是本定稿的核心**：**一座塔在任一时刻，要么主动、要么被动，永不同时。** → 状态与效果**一一对应** → 🟢 认知负担最小（R-B6 / R-B13 的解法）。

## 4. 🆕 机制 B · 残响 `Reverb` —— 死塔的被动残留（🔴 **已裁决：不采纳**）

### 4.0 🔴 最终裁决（V-8 / V-8b 实证 + 用户拍板 · 覆盖本节全部内容）

> 🔴 **裁决：残响 `Reverb` 不采纳 —— 去混淆实证「全剂量域无正向胜率边际」，不作体验层保留。**
> （用户 2026-10-09 拍板「残响砍」；依据 `v8b-final-adjudication.md` §2 / §7.4）

**裁决链（三步，皆有数据）**：

| 步骤 | 轮次 | 结论 |
|---|---|---|
| ① V-8 6 臂 | B4（残响单独）Δ = **−0.0223**、gap_leak 反升、uptime 未升 → 预注册"残响成立"两条判据**均未满足**（→ R-B3 依 §7.2 自设规则程序性回升 🟠、Q-B3 重新开放） | 🔴 但**不可归因**：B4 是**混淆臂**（残响时长 = 肉盾整波离线时长），负向主要来自"整波离线"罚，非残响方向有害。反证：B5 同样开残响，n_td_form = **−5.88%** → 证伪"残响→怪滞留→塔死亡"链 |
| ② V-8b 4 臂（去混淆，复活 ON / 复活参数四臂逐位相同） | 残响**纯净边际**：V1(s=0.30,R=9.0) **+0.00811 ns** / V2(s=0.30,R=13.5) **−0.00541 ns** / V3(s=0.50,R=13.5) **−0.03108 ns** → **全部 CI 含 0，无任何剂量给出正向胜率边际**；剂量阶梯 V1→V3 = −0.039（名义 p=0.031，多重校正后不稳健）。机制链：reverb_slow 4.33 → 10.51 → 26.71 s/run（6.18× 响应），**胜率不升反降** | 🔴 **残响不是"剂量不足型"，是"次感知型"**（覆盖太薄：V1 只 cover 4.0 只/局、挽回 0.57 只/局），加剂量不救 |
| ③ 用户拍板 | **砍**。🟢 不加跑 3000 局（锚点效应 +0.008 太小，翻倍局数仍 ns，对"砍"零决策增量） | ✅ 收敛 |

**🔴 三条必须钉死的边界（防止过度解读）**：
1. **砍残响 ≠ 残响被证明有害**。V3 的 −0.031 是**二次对照（阶梯）非预注册主判据**，多重校正后（3 对照 ≈ 0.093）不稳健 → 正确表述是「**无正向价值**」，**不是**「有害」。
2. **砍残响 ≠ 推翻 §4.1**。「死塔保留被动 = §2.4 ① 的外化」这层**世界观同源性未被推翻**，只是**玩法上未被采纳** → 🔴 **§2.4 ① 保持定稿，一字不改**（它是 `h_j` 供体定性，与残响是否采纳相互独立）。
3. **砍残响 ≠ 动 §2.3**。残响在波次间本就 OFF → 三选一（修/拆/放着）决策结构**一字未改**（§8.3 保持成立）。

### 4.1 🏆 它不是新机制：它是 §2.4 ① 的推论

| | §2.4 ①（**已定稿**） | 残响（**本轮新增**） |

### 4.4 🏆 Q-B17 推荐：残响**无差别**（含 carry 也发）

| 理由 | 说明 |
|---|---|
| 🟢 **一致性**（最强） | §2.4 ①「Disabled 塔仍供 `h_j`」是**无差别**的（不分 carry / 非 carry）。残响是同一前提的推论 → 也应无差别。若只对肉盾生效，等于在 §2.4 里**再切一刀**，且 **diegetic 上说不通**（为什么 carry 的谐波体就不向外辐射？） |
| 🟢 **惩罚未被实质稀释** | 塔死亡的核心惩罚是「**失去 DPS + 失去吸火**」。残响**不杀怪、不吸火、不产输出** → 它是"场所"不是"输出"。🔴 对比 V-7 FREE 臂（让 carry 恢复 **100% 输出**）→ **两者不是一个量级** |
| 🟢 **归因清晰** | 若只对肉盾生效 → "我这座塔死了会留场，那座塔死了什么都没有" → 玩家归因困难（概念 §4.1）。无差别 = 规则可一句话说清 |
| 🟢 **实现更简单** | 只需判 `disabled` → **不需要 `reverb_misqualify` 断言**（没有资格判定就没有误判） |
| 🟢 **金标本零改动有保障** | 残响挂 `reverb_enabled` 诊断开关，**默认 false** → 金标本（开关 off）逐位不变，与 Sapper / 献祭 / 过载同纪律 |

> 🔴 **但这是 L3 语义层判断，我不独自定 —— 列为 Q-B17 请用户拍板。**
> 🟡 **若用户担心稀释惩罚**，退让方案 = 「仅非 carry」（🔴 代价：引入 §4.4 理由 3 的不对称 + 需新增 `reverb_misqualify` 断言 + diegetic 上说不通）。

### 4.5 🏆 Q-B18 推荐：残响持续 = 绑定到 `disabled`（复活即消失，恢复主动）

| 方案 | 机制 | 判定 |
|---|---|---|
| 🏆 **(i) 绑定到 `disabled`** | `disabled == true` → 残响 ON；清 `disabled` → 残响 OFF | 🏆 **推荐** |
| 🟡 (ii) 持续到波末 | 复活后残响仍留 | 🟡 更强，但违反互补性 + 易被滥用为"永久场" |
| 🟡 (iii) 固定 `T_reverb` 秒 | 与 `N` 独立 | 🟡 多一个扫参维度 |
| ❌ (iv) 活塔也生效 | — | ❌ 那是普通光环，不是"死亡残留" |

**推荐 (i) 的五条理由**：
1. 🟢 **语义最紧** —— 残响是「**停机态**」的产物，不是塔的属性。对比：`h_j` 是**结构属性**（所以恒在），残响是**状态的辐射**（状态没了辐射就没了）。→ 这个区分与 §2.4 完全自洽。
2. 🟢 **零新参数**（不需要 `T_reverb`）。
3. 🟢 **回答了"衔接"问题**：**复活 → 残响消失 → 恢复主动**。互补分工，一一对应（§2 表）。
4. 🟢 **最难被滥用**：复活了就没了 → 不会变成"永久减速场" → 不会诱导"故意让塔死着"。
5. 🟢🟢 **它给 `N` 装了一个自动稳定器**：`N` 越大（空窗越长）→ 残响持续越久 → **自动补偿**。→ 🔴 **但这也是本轮新风险 R-B16 的来源，见 §9。**

> 🔴 **第四条（波次间残响 OFF）必须显式写死**：**残响只在「波内 + `disabled`」生效，波次间无战斗 → 残响自然不存在。**
> 🟢 **这条的意义**：它使残响对 **§2.3 三选一（修 / 拆 / 放着）零影响** —— 玩家在安全窗做决策时，残响不在场，不会变成"放着不管"的正收益。→ 🔴 **§2.3 定性因此一字不改**（§8.3 核对）。

## 5. 🆕 机制 C · 增加复活次数 `K`（「玩法」设计）

> 用户原话：「**可以有相应的玩法来增加复活次数**」。目标：`K` 从"系统常量"变成"**玩家可投入的维度**"。

### 5.1 三条表达路径

| # | 表达 | 机制 | 成本 | 判定 |
|---|---|---|---|---|
| 🏆 **L1** | **涌现轨：`K` ∝ 投入** | `K_i = K_base + floor(h_i / H_STEP)`（`H_STEP` PLACEHOLDER，建议扫 `{8, 16, 32}`） | 🟢🟢 **零新资产**（复用已有 `h`） | 🏆 **主推** |
| 🟡 **L2** | **显式轨：T1 卡「冗余核心」** | 单塔效果卡，每层 `+1` 次重启（做成卡 → **不买不生效** → 金标本零改动，与玩法④过载同处理） | 🟡 一张卡 | 🟡 **推荐备选** |

### 5.2 🏆 为什么主推 L1（`K ∝ h`）

| 理由 | 说明 |
|---|---|
| 🟢🟢 **与 P2「失控必须被 earned」三次同族** | GDD §2.6 已定稿：深塔 `HP ∝ h^0.6` →「你投得越深越难被打掉 = earned 的**耐久侧**表达」。`K ∝ h` 是**同一条语义的第三次表达**：**层数越厚 → 谐波体越稳 → 越能自我重启**。→ 🟢 三条（HP / `h^0.6` 抗打 / `K`）**全部 ∝ 投入**，语义完全统一 |
| 🟢 **零认知成本** | 不需要新商品、新卡、新 UI 数字 → 玩家只需知道"投得深的塔更扛造"（这本来就是 `h^0.6` 已经教过他的一件事） |
| 🟢🟢 **它补上了肉盾玩法最大的一个洞** | 玩法②「肉盾塔」的定性是「**不产 DPS** → 投它是**纯成本**」。玩家凭什么投肉盾？之前只有"保住主塔"这一个（间接的）理由。现在有**第二个、直接的理由**：**投 `h` → 换重启次数**。→ 🟢 **肉盾从"纯成本"变成"有回报的投资"** → 🟢 同时缓解 R-B4 的反面（肉盾太弱 → 没人带） |
| 🟢 **不破坏平衡（自限）** | `K` 只在**波内**有效且有 `K_base` 地板（≥1）→ 它放大的是"这座塔能撑几轮"，不是"它能打多少" → **不触碰 DPS 曲线、不触碰经济、不触碰 7 乘区** |
| 🟡 **风险（诚实登记）** | 肉盾通常是**低 `h` 塔** → 按 `K ∝ h`，肉盾的 `K` **最低** → 若 `H_STEP` 太大，L1 形同虚设（肉盾 `h=4` → `K=1`）。→ 🟢 **这正是设计意图**（把"要不要给肉盾投层"变成真实取舍），但 `H_STEP` **必须扫**，且 A 路径 `max_towers=2` 下塔位稀缺 → 这个取舍的张力最大 |

### 5.3 关于「是否破坏平衡」的正式检查

| 检查项 | 判定 |
|---|---|
| 是否产生**主导策略**（"每局必堆 K"）？ | 🟡 **有风险，但被两件事对冲**：① 投 `h` 要真花钱（与 `build`/`up`/`reinf` 抢预算 → 机会成本真实）；② `K` 只影响"撑几轮"，**不产 DPS** → 堆 `K` 不解决"杀不动"。→ 🟢 与玩法②「肉盾不产 DPS → 苟活期价值≈0」同一自限机制 |
| 是否**触碰金标本**？ | 🟢 **否**：`K_base=1` + `H_STEP` 挂诊断开关 `revive_k_growth`，默认 `H_STEP = ∞`（= 关闭成长）→ 金标本逐位不变。**V-8 不扫 `H_STEP`**（见 §6.3 维度控制） |
| 是否**与 `Repair` 形成废按钮**？ | 🟡 需 V-8b 检查：`repair_cost`（治标·本次）vs「投 `h` 换 `K`」（治本·本局）。🏆 我的判定：**两者是互补不是竞争**（修 = 让这座塔现在活；投 = 让它未来多死几次也不倒）→ 面向不同时间尺度。🔴 但需扫参确认 |
| 是否**违反 T-C1 / T-C2**？ | 🟢 **否**：`K` 的成长发生在**波次间**（投 `h` 是波次间的 build 行为）；战斗中只静默消耗，零输入、零读数 |

🔴 **不给数字**（T-C2）。🟢 复用 R-B13 的图标策略：**塔体底部"重启充能"点亮**（`K` 次未用 = 亮 `K` 个点，`K_base` 时 = 1 个点）→ 零文本、余光可读。

## 7. 🏆 R-B3 是否被「保留被动」解决？

### 7.1 答：**是的，而且比 (C2) 残骸嘲讽更彻底**

**R-B3 原文**（v1 §5 ③ / §10）：「**A 单核流冗余不足的结构性矛盾** —— 肉盾最需要的路径（A，`max_towers=2`）恰恰最没有补位空间（(C3) 在 A 路径最难成立）」。

| | **(C2) 残骸嘲讽**（用户已否决） | 🏆 **残响减速场** |
|---|---|---|
| 依赖冗余？ | 🟢 不依赖 | 🟢 不依赖 |
| 需要进仇恨池？ | 🔴 **是**（残骸要被选为目标）→ **与 E-T5 直接冲突** + 用户否决 | 🟢 **否** → E-T5 一字不改 |
| 空窗期效果 | 怪**停在原地打残骸** → 不前进 → 不漏 | 怪**继续前进但变慢** → 漏得更少/更晚 |
| 是否抵消塔死亡惩罚 | 🔴 **强**（残骸仍在履行肉盾职责 = **肉盾其实没死**）→ 与 R-B10 永动机**同族** | 🟢 **弱**（只减速，不杀怪、不吸火）→ 惩罚保留 |
| 与 §2.3(a)「已流过去的水收不回」 | 🔴 **直接否定**（水停住了）→ 抹掉张力 | 🟢 **保留**（水还在流，只是慢了）→ 张力从二值变连续 |
| `N` 的扫参鉴别力 | 🔴 被抹平（`N` 不再产生代价） | 🟢 保留（见 R-B16） |
