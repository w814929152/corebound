## 2. 残响最终裁决：🔴 砍（附诚实的边界）

### 2.1 这次的数据为什么是决定性的
V-8 里我（文策渊）推翻过程基岩"残响方向有害"的根因判断——因为 B4 是混淆臂（残响时长 = 肉盾整波离线时长，v3 §9 R-B16 早预登记）。**V-8b 就是为分离这两个变量而设计的**：全部臂复活 ON、复活参数逐位相同，只有 s_reverb / R_reverb 在变。**现在混淆被按住，残响的纯净边际被干净地测出来了——而它没有正向值。**

| 对照 | surv 边际 | 解读 |
|---|---|---|
| **V1 vs C0**（锚点剂量 s=0.30/R=1.0x，= 玩家会玩到的量） | **+0.00811（ns）** | 残响在真实剂量下的边际：**微正、不可辨识** |
| **V2 vs C0**（抬半径 R=1.5x） | −0.00541（ns） | 加半径：转负 |
| **V3 vs C0**（半径 + 减速双抬，上界剂量） | −0.03108（ns，p=0.088） | 加上界：负向点估计 |
| **V1→V3 全阶梯** | −0.03919（名义 p=0.031） | 单调下行，但**二次对照 + 多重校正后不稳健** |

### 2.2 为什么是"砍"而不是"留"——诚实的推理链
1. **没有任何剂量的正向边际可辨识**：三个剂量臂 vs C0 全部 CI 含 0。最好的情况是 V1 的 +0.00811——**这已经就是复活叠加残响（V1≡V-8 B5）相对纯复活（C0≡V-8 B1）的增量**，SE≈0.018，远未达判读线 0.035。**残响在真实剂量下贡献的胜率价值 ≈ 0。**
2. **"加剂量可救"被证伪**：剂量从 4.33s/run 拉到 26.71s/run（6.18×），胜率不升反降（点估计）。残响**不是**"剂量不足型"机制——它是**次感知型**：覆盖太薄（V1 只 cover 4.0 只怪/局、挽回 0.57 只/局），动不了胜率。
3. **上界剂量的负向信号真实但不稳健**：V3 的 −0.031 是点估计真实的负向，但它是**二次对照（阶梯）而非预注册主判据**，多重校正后（3 对照 ≈ 0.093）不显著。**我不会把它当"残响有害"的铁证**——它只告诉我"别往上界加"，不告诉我"残响本身有害"。
4. **设计理论红线（R-B19 认知过载）**：残响是**第 7 个需读的量**。为一个零胜率价值的层付实现成本 + 认知成本，正好踩中"认知过载"红线。**当一个层没有可辨识的正向价值、 yet 增加玩家读数负担时，成本/收益明确倒向砍。**

### 2.3 🔴 我必须诚实标注的边界（防止过度解读）
- **砍残响 ≠ 残响是个坏主意被证伪**。残响作为 §2.4 ①「死塔仍供 h_j」的外化，**世界观同源性未被推翻**（§4.1 依然成立）。它只是**在胜率维度上没有可辨识价值**。若用户出于主题/体验理由想保留一层"死塔余辉"的视觉场，那是**体验决策**，不是数据能替用户拍的板——但**默认应是砍**。
- **V3 的负向我不建议靠加跑来"坐实"**（见 §4）。理由：加跑只能坐实"上界有害"，而坐实"上界有害"不改变"砍"的结论——我们砍残响是因为**它没有正向价值**，不是因为**它有害**。

> **裁决：残响砍掉（默认）。** 依据是"全剂量域无正向胜率边际 + 认知过载"，不是"证明有害"。若用户要保留为纯体验层，请用户显式拍板（§7.4 给选项）。

## 4. 是否需要加跑 3000 局坐实 V3？——🟢 不建议

**诚实的决策分析（这是本次最需要克制的地方——用户已投入多轮）：**

| 问题 | 分析 |
|---|---|
| 加跑能改变"砍"的结论吗？ | **不能。** 我们砍残响是因为**它没有正向价值**（V1 锚点 +0.00811 ns）。加跑**只会坐实"上界剂量有害"**，而"上界有害"不改变"没有正向价值"这个砍的主理由。 |
| 加跑能把 V1（锚点）救成显著正向吗？ | **数学上不能。** RUNS 从 1480 翻倍到 3000，SE 按 1/√2 ≈ 0.707 收缩：V1 的 SE 从 0.0181 → ≈0.0127，而效应量 +0.00811 不变 → z ≈ 0.64，**仍 ns（p ≈ 0.52）**。**锚点剂量效应太小，任何合理局数都救不回来。** |
| 加跑唯一能做的是？ | 把 V3 的 −0.031 从"名义 p=0.031"坐实为"稳健显著"（3000 局下 SE≈0.0127 → z≈−2.45, p≈0.014）。**但这只是把"上界有害"钉死——对"砍"的决策零增量信息。** |
| 成本/收益 | 成本：≈ 4 臂 × 3000 ≈ 翻倍机时 + 用户又一轮等待；收益：**零决策增量**（结论不会变）。**在用户已投入多轮后，这是典型的无谓消耗。** |

> **裁决：不加跑。** 现有 1480 局数据**已足够**支撑"砍残响"（全剂量域无正向边际）。V3 的上界负向信号**作为点估计是真实的**，我如实登记为"名义显著、多重校正后边界（0.093）、不稳健"——**但我不建议为它再花一轮**。
>
> 🔴 **唯一例外**：若用户**本就想把残响当纯体验层保留**、并需要知道"上界会不会反而拖累体验"，那加跑 3000 局坐实 V3 才有意义。**但那是"要不要留残响"的用户选择触发的，不是数据需要的。**

### 7.2 什么活着、什么死了、玩家得到什么
