## 2. B4 残响负向信号 · 根因诊断（🔴 我推翻程基岩的根因判断）

### 2.1 程基岩的判读（要复核的对象）
> "B4 残响净效应不成立：Δ=−0.0223 + gap_leak 反升 + uptime 反降 → 机制生效但**剂量太小** + 伴 **n_td_form +2.94%（怪在死塔附近滞留更久）**。倾向'方向本身有代价'。"

### 2.2 我的复核：**症状对，病因错。B4 是混淆臂。**

关键在 **B4 / B5 / B1 的三向分解**（这是程基岩没列表、但对回答"剂量 vs 方向"决定性的对照）：

| 对照 | surv | gap_leak | n_td_form | 解读 |
|---|---|---|---|---|
| **复活效应**（B1 − B0，复活 on / 残响 off） | +0.0129 | −0.86 | **−19 (−5.59%)** | 复活恢复 DPS → 塔死亡大降 |
| **残响叠加复活**（B5 − B1，加残响 on top of 复活） | **+0.0081** | −0.42 | **−1 (−0.31%)** | 残响在复活之上是**小幅正向**，n_td_form 基本不动 |
| **残响单独**（B4 − B0，残响 on / 复活 off） | −0.0223 | +0.26 | **+10 (+2.94%)** | 程基岩据此判"残响有害" |

**决定性反证**：如果"残响减速 → 怪滞留更久 → 塔死亡上升（n_td_form↑）"这个因果链成立，那么 **B5（同样开残响、同样减速）也应该出现 n_td_form 上升**。但 B5 的 n_td_form = 320 = **−5.88%**（相对 B0），相对 B1 也是 −0.31%。**B5 有残响却不升反降** → **"残响导致怪滞留→塔死亡"这条链被 B5 直接证伪。**

那 B4 的 +2.94% 从哪来？**来自"肉盾整波离线"这个 B4 独有的条件**：
- B4 = 复活 off + 残响 on。因为不开复活，肉盾线**整波 Disabled** → 全场无该塔 DPS → 其余塔承受更多命中 → W6..W12 窗口塔死亡 +10。
- 这个 +10 几乎是复活效应（−19）的镜像缺失。B4 与 B5 唯一的结构差异是**"肉盾离线整波 vs 离线仅 N 秒"**，而残响时长 = 离线时长，二者**完全共变**。

> 🔴 **结论：B4 的负面 Δ 无法归因于残响。** B4 把两件事焊死在一起——(a) 残响全程在场（好）、(b) 肉盾整波离线（重罚）。B4 的 −0.0223 主要由 (b) 驱动，(a) 的真实贡献被 (b) 淹没。这正是 **v3 §9 R-B16 早就预登记的混淆**（"残响时长 = disabled 时长 = N ⇒ 二者部分抵消、读数被污染"）——只是 R-B16 担心的是"抵消让 N 失去鉴别力"，而实际发生的是"离线罚让残响的正贡献看不见"。

### 2.3 残响的真实边际贡献（B5−B1）：小幅正向，但次感知

- surv 边际 **+0.0081**（正向，但 SE≈0.018，远未达判读线 0.035）。
- gap_leak 边际 −0.42（小幅降）。
- n_td_form 边际 −0.31%（基本中性，**不是** +2.94%）。
- **覆盖几何太薄**：covered 4.6 只/局、leak_save 0.65 只/局 → **挽回率仅 14%**；reverb_slow 5.09s/run ÷ 20 波 ≈ **0.25s/波**。

> **一句话根因**：**不是"残响方向有代价"，是"残响在 s=0.30/R=9.0 下剂量太弱、覆盖太薄，动不了胜率；而 B4 这个'残响单独'臂又因为强制肉盾整波离线而自带重罚，把残响的正贡献盖住了"。** 加剂量能否救活是**经验问题**，V-8 的数据**既不能证明"能救"也不能证明"更糟"**——因为 V-8 里"残响剂量"与"离线时长"从未被分离过。

### 2.4 对"加剂量会不会更糟"的诚实回答
- 程基岩的"加剂量更糟"在 V-8 里**不可检验**：要加残响剂量就必须加离线时长（B4 路径）= 更接近 B4 = 更差，但这差的是离线罚不是残响。
- 要真正检验"剂量 vs 方向"，**必须在复活 ON 的前提下加残响剂量**（B5′ 变体），把离线时长这个混淆变量按住不动。→ 这就是 §6 的 V-8b 设计。

## 5. gap_leak 是否降级为机制量（主判据去留）

**裁决：降级。程基岩的建议成立，数据强力支持。**

**决定性证据（B3 悖论）**：
- B3 的 gap_leak 降幅**全场最大**（−1.37，z=−2.97，最显著）；
- 但 B3 的 Δ_surv **全场最小**（+0.0034，z=+0.19）。

→ **gap_leak↓ 与 胜率↑ 明确脱钩**。B3（波首复活，N→∞）把漏怪窗口压得最狠，却几乎不动胜率。这说明 gap_leak 度量的是**"机制是否减少了漏怪窗口"（机制活动量）**，不是**"是否赢"**。

**终审口径调整**：
| 判据 | v3 地位 | 终审地位 | 理由 |
|---|---|---|---|
| **Δ_surv 双侧 CI** | 🔴 主判据 | 🔴 **主判据（唯一胜率证据）** | 不变 |
| **gap_leak** | 🔴 机制主判据 ②（与胜率并列读） | 🟡 **降级为机制活动量**（保留为硬机制判据，但**不得作为胜率代理**引用） | B3 悖论证明 gap_leak↓ ≠ 胜率↑ |
| **bulwark_uptime** | 🔴 机制主判据 ① | 🟡 机制活动量（保留） | 同理，在线率是结构量不是胜率 |
| **n_td_form** | 🔴 护栏 | 🔴 **护栏（不变，且更重要）** | 它是唯一直接度量"塔死亡机制是否还有牙齿"的量 |

> gap_leak 仍是**必跑的机制读数**（判断机制有没有按设计工作），但从今往后**不能再说"gap_leak 降了所以胜率该涨"**。这条纪律要写进下一版扫描器规格。

## 6. 三处口径澄清 · 裁决

### 6.1 revive_misqualify 语义拆分 → ✅ **批准（必要的正确修正）**
- **裁决**：批准拆分为 `revive_misq`（硬断言，恒 0）+ `revive_refused`（闸门**正确拒绝**：carry 死 / 非暴露位死，诊断量）+ `carry_death` / `nonexp_death`（死亡时刻快照分类）。
- **理由**：原单一计数器把"闸门正确拒绝"也算进去 → 会恒非 0 → 会**误触发**硬断言，让所有臂作废。拆分后硬断言才有意义（只统计"已落地却违规的重启"）。这是**让硬断言可证伪的必要修正**，不是口径注水。V-8 全臂 misq=0 是**真 PASS**。
- 🔴 **连带发现（批准并正式撤回 v2 §7.1 假设）**：bulwark 口径下 **carry 并非"恒不挨打"**——`carry_death ≈ 0.65 次/局` vs `合格死亡 ≈ 0.64 次/局`。**v2 §7.1 的"carry 恒不挨打"假设不成立**，资格闸门的覆盖面约为预期的一半。**这是校准更新，不是 bug**（闸门工作正常，misq=0）。→ **正式从 v2 §7.1 撤回该假设**，改记："bulwark 口径下 carry 约半数死亡事件会被资格闸门正确拒绝，revive 只覆盖暴露位非 carry 的那一半。"

### 6.2 repair_on_disable 用 9/11、没单列 10 → ✅ **批准（功能等价）**
- **裁决**：批准。`N` 已参数化为 `revive_n_seconds`，mode 9 + N=0.5（B1/B5）与 N=2.0（B2）已覆盖短/长两档；mode 11 = 波首（B3，N→∞ 极限）。mode 10（战斗内即时 N_long 的独立档）与 mode 9 + N=2.0 **功能等价**，不单列不损失任何扫描能力。
- 🟡 **建议**：在 `mvp_config` 注释里把 10 标为"reserved/未用"，避免后续评审误以为漏档。

### 6.3 sim_player snap/rest 必须序列化 5 个新字段 → ✅ **批准（关键正确修正，第二次踩同类坑）**
- **裁决**：批准为**强制序列化不变量**。`rest()` 用 `make_tower` 重建塔对象，若 5 个薄记字段（`revive_t_disabled` / `revive_used_w` / `revived_ever` / `death_exposed` / `death_carry` 等）不序列化，会被静默清回初值 → **B3（波首复活）会退化成空臂**（这正是 V-7 同类坑第二次触发）。
- 🔴 **工程纪律建议**：加一条**回归断言**——snap→rest 往返后，5 字段逐位守恒（`assert restoral_roundtrip`）。这类"重建对象时漏序列化"的坑已经踩两次，值得用一条自动断言钉死，防止第三次。
- 这是**工程卫生项，不是设计决策**，我无异议批准。

### 7.2 哪些活着、哪些死了
- **活着**：复活 M-1（结构改善真实）；完整机制 B5（体验向）；"死塔保留被动 = 残响"的**世界观同源性**（§4.1 未被推翻，只是强度未证）。
- **没死但没被证明**：残响的**玩法价值**（次感知剂量 + B4 混淆，未公平检验）。
- **死了**：残响"成立"的**预注册判据**（两条都没满足）；v2 §7.1"carry 恒不挨打"假设；"gap_leak↓ = 胜率↑"的隐含假设。
- **维持否决**：(C2) 残骸嘲讽（用户是对的，数据不支持翻案）。

### 7.3 是否需要 V-8b？——诚实的决策树（请用户拍板）

> 🔴 **我不替用户拍这个板，给选项：**

**选项 A · 窄口径 V-8b（我的推荐）**
- **设计**：3–4 臂，**全部复活 ON**（按住离线时长这个混淆变量），扫残响剂量 `s_reverb ∈ {0.30, 0.50}` × `R_reverb ∈ {1.0, 1.5}×AGGRO_R`，对照臂 = B1（复活、无残响）与 B5（当前剂量）。
- **主判读**：Δ(B5′ vs B1)——复活之上残响的**纯净边际**（V-8 里被混淆盖住的那个量）。
- **成本**：≈ 3–4 臂 × 1480 ≈ 3–4 分钟。
- **能回答**：残响是"剂量不足可救"还是"加到上界仍次感知"。这是 V-8 唯一没能回答、且**便宜**的关键问题。
- **风险（诚实）**：V-8b 也可能显示"剂量加大 → 漏怪降更多但胜率仍不动"→ 那时残响定性为**体验向锦上添花**，可砍可留，但至少是**基于数据的决定**，不是基于混淆的 B4。

**选项 B · 现在收敛**
- 采纳复活 M-1（数据干净支持结构改善），**搁置/砍掉残响**（V-8 未证明其胜率价值，且它是第 7 个需读的量，R-B19 认知过载）。
- 优点：省一轮；缺点：**残响被搁置的理由是"B4 混淆 + 次感知"，不是"证明有害"，可能冤枉了一个方向正确的机制。**

**选项 C · 直接采纳 B5（复活 + 当前残响）**
- 把残响当体验向锦上添花一起采纳。
- 缺点：残响那层的边际只有 +0.0081，等于**为一个没被证明的量付实现成本**。

> **我的诚实倾向：选项 A（窄 V-8b）。** 理由：残响方向**没有被证伪**，只是被一个混淆臂和一个次感知剂量挡在门外。花 3 分钟去混淆扫一次，要么给它正名、要么干净地砍掉——现在收敛是**在证据不足时对一个用户已经认可的方向下结论**，我不愿意这么做。但**绝不回到 (C2) 残骸嘲讽**。
