## 0. 三句话结论（给赶时间的人）

1. 🔴 **这不是 V-6，杠杆完全不同，挂错名字会把正确的处置带偏。** V-6 问的是「**外环高 HP 肉盾构筑**是否变成必胜解」，其杠杆是肉盾续航 / §2.9 波末残留规则 / `ATTRITION`。V-6′ 问的是「**多塔流相对单核流的安全裕度是否过厚**」，其杠杆是**后期压力源（怪物曲线 / 几何 / 数值）与两条路径的对价结构**。两者对象不同、机制不同、可动的东西也不同 → **必须分案**。

2. 🟢 **但先把命题校准：真正该问的不是「B 能不能活下来」，而是「B 的活下来是不是付了钱」。** 设计上「多塔稳健流生存高」是**意图**（V-0′ ⑤ 把 `B/A < 1` 列为**判据**：单核 A 必须是后期 carry，多塔 B 用后期 DPS 低换取生存高）。所以对价若存在且充分 → 100% 存活是**付费买来的**，不是免费午餐，V-6′ **不触发**；对价若消失 → 才是真问题。

3. 🟡 **已有一个需要盯的信号**：八槽 RADIAL 下 B 的 W20 ratio 由六槽 **9.97 → 13.535（+35.8%）**，`B/A` 由 **0.458 → 0.6217** —— **对价被吃掉约 1/3**（`r4-eight-slot-v0-closure.md` §5.3 / L-2）。这使 V-6′ **值得立项**，但**不阻塞 Phase 6**：当前 `B/A` 仍显著 <1，对价**仍然成立**。

## 1. 命题界定

### 1.1 V-6′ 的正式表述

> **V-6′**：在金标本（AI 参考打法）口径下，**多塔流 B 相对单核流 A 的生存优势是否过厚** —— 即：B 的"稳健"是否仍有**足够的对价**（后期 carry 能力显著弱于 A），还是已经变成"既要生存又要后期"的无对价优势？

### 1.2 观测起点（已知事实，全部为 `1ca10ef` 修复后基线）

| 量 | 六槽金标本定稿口径 | **八槽 RADIAL（修复后实测）** | 出处 |
|---|---|---|---|
| B 存活率 `survive_rate` | —— | **1.000**（300/300） | `r4-attrition8-after.log` L12 |
| A 存活率 `survive_rate` | **0.693**（`card-system` §5.7.2 定稿） | **0.597**（179/300） | `card-system` §5.7.2 · `r4-attrition8-after.log` L12 |
| B 规范 `takeoff_rate` | 0.913 | **0.913**（274/300） | `r4-attrition8-after.log` L28 |
| A 规范 `takeoff_rate` | —— | **0.5967** | `r4-attrition8-after.log` L111 |
| B 末波 `core_hp` | —— | **1000.0（满血）** | `v6-dominance-adjudication.md` §2.2 引探针 |
| **生存差 `Δ_surv = B − A`** | ≈ **0.307**（若 B=1.0） | **0.403** | 派生 |

> 🔴 **口径警示（必须先消除，否则后续所有判读都会串味）**：主理人提示中的「A 69%」来自 `card-system` §5.7.2 的**六槽定稿起飞率**；而八槽 RADIAL 修复后实测的 A 是 **0.597**。**两者配置不同（六槽 PATH vs 八槽 RADIAL），不可直接相减或混用。** V-6′ 的第一条补跑（§4 V6′-R1）就是消除这个混淆。

### 1.3 命题的三种竞争性解释（本项目要求先分辨，再谈处置）

| 假设 | 内容 | 若成立的含义 | 处置方向 |
|---|---|---|---|
| **H1 · 多塔太安全** | B 后期从未被逼近（满血通关），难度曲线对 B 完全无压力 | 后期缺张力，多塔流体验平淡 | 后期压力源（怪物曲线 / Elite / Sapper 密度）—— 🔴 但都是定稿外的新增，需另立项 |
| **H2 · 单核太脆弱** | 问题在 A 侧生存过低（0.597 < 0.60 红线），B 只是正常 | 这是 **A 路径体验调优**，不是多塔流问题 | 属 V-1′ 重标定后 A 路径的调优空间 → 见 §5 红线，**不得与 V-6′ 混案** |
| **H3 · 对价成立（设计意图）** | B 用"后期 carry 弱"换"生存高"，取舍真实存在且充分 | **不是缺陷**，是 V-0′ ⑤ 已定稿的风险画像分化 | 不处置，转为常规监测 |

> 🟢 **我的先验：H3 为主，H1 为部分真，H2 是独立案。** 理由：八槽实测 `B/A = 0.6217`（确定性）/ `0.3937`（MC 均值）**仍显著 < 1** → 单核 A 确实仍是后期 carry → **对价存在**。但 `B/A` 已从 0.458 抬到 0.622（余量吃掉 1/3）→ **对价在变薄** → H1 的分量在上升。**这正是需要立项测量的理由，不是需要立即处置的理由。**

| 维度 | **V-6**（外环肉盾必胜） | **V-6′**（多塔流安全裕度） |

## 3. 判据框架（🔴 先只测量，不设缓解阈值）

> 本节给的是**判读口径**，不是"通过/失败"阈值 —— V-6′ 的数据尚未取得，此时定阈值等于在事实建立前画线（与 `v7-final-adjudication.md` 拒绝在 INCONCLUSIVE 时改定性的同一纪律）。

### V6′-C1 · 对价充分性（🟢 主判据）

| 项 | 规格 |
|---|---|
| 量 | **`B/A` = W20 ratio B ÷ W20 ratio A**（`ratio = dps / total_hp`，`_Stats.takeoff_wave` 同族量） |
| 语义 | B 的后期 carry 能力相对 A 的比例。**< 1 表示 A 仍是后期 carry** —— 这是 B 用生存换来的对价 |
| 当前实测 | 六槽金标本 **0.458** → 八槽 RADIAL **0.6217**（确定性单局）/ **0.3937**（MC 均值） |
| 判读 | 🟢 **显著 <1 → 对价成立 → V-6′ 不触发**；🟡 逼近 1（如 >0.80）→ 对价变薄，升级评估；🔴 ≥1 → **对价消失 → V-6′ 真触发** |
| 🔴 纪律 | 沿用 `card-system` §5.4：上界**硬**（`B/A ≥ 1` 即"后期 carry 归属"无归属，等同翻车）。四种配置为 `κ_r=0.050` / `ATTRITION=1.50` / `max_actions=12` / 八槽 RADIAL —— **结论只对这套配置成立**，换配置须复扫（L-2 已同样登记） |

### V6′-C2 · 安全裕度厚度（🟡 机制量，不得当胜率代理）

| 项 | 规格 |
|---|---|
| 量 | **`M_B`** = 使 B 的 `survive_rate` 跌到 **0.90** 所需的**怪物强度倍率**（只读扫参求得）；对照量 `M_A` |
| 语义 | 把"存活率 100%"这个**二值量**翻译成"**厚到什么程度**"的连续量。`survive_rate` 丢掉了"赢得多轻松"的信息 —— B 末波满血 1000.0 已提示裕度很厚，但**厚到几倍**未知 |
| 判读 | 若 `M_B` 极大（量级 ≥10×）→ 在可预见的难度曲线内 B **永不受压** → H1 成立，后期缺张力 |
| 🔴 纪律 | 沿用 `mechanics-bulwark-cycle.md` L-4「**机制活动量 ≠ 结果量**」（B3 悖论）：`M_B` 描述**裕度**，**禁止**用它直接论证"B 该被削"。是否该削是产品决策，不是测量结论 |

### V6′-C3 · A 侧生存（🔴 边界声明 —— 它不是 V-6′ 的判据）

| 项 | 规格 |
|---|---|
| 事实 | A 存活率八槽 RADIAL = **0.597**，**仍未过 0.60 红线** |
| 🔴 归属 | **这是平衡问题（V-1′ 重标定后 A 路径的体验调优空间），属 H2，不属 V-6′** |
| 🔴 红线 | **不得通过下调任何判据阈值来"让 A 过线"** —— 那是用改尺子掩盖机制失效。也**不得**把它并入 V-6′ 用"削 B"来相对抬高 A（那是拿别人的钱补自己的洞） |
| 处置 | 单列；若主理人要处置 A 侧体验，应另开案（玩家保塔口径，见 `mechanics-tower-life-death.md` §4.2 V-2 / V-4：A 无保护 0.277 → 理想肉盾 0.580，**玩家可操作空间 +0.303 已实测存在**） |
| 🟢 **裁决（2026-10-10）** | **本条已关闭 —— 判为噪声 · 不处置**：`0.60 红线`的权威归属 = **A 路径起飞率 × 六槽定稿配置**（现值 `0.693` · `+3.49 SE` ✅）；八槽 `survive_rate 0.597` 是「跨配置 + 跨指标 + 未出货（`Q-R9` 待拍板）」的三重口径迁移，缺口 `0.106 SE`、95% CI 含 0.60 → **纯噪声**。🔴 **不调参 / 不升 N / 不削 B / 不动任何阈值**。**重开条件**：`Q-R9` 拍板八槽出货 **且** 该口径下 `N≥300` 落红线下方 `≥3 SE`（现状两条均不满足）。详见 `a-side-balance-adjudication.md` |

### V6′-C4 · 护栏

|---|---|

| `n_td_form` | 塔死亡机制仍有牙齿（不得因任何 V-6′ 相关改动 →0） |

## 4. 需程基岩补跑的规格（🔴 全部只读 · 不阻塞 Phase 6）

> 全部为**只读埋点 / 独立脚本 / 只读扫参**。🔴 **不得改动生产行为与定稿数值**；默认回归零扰动为验收前提。按 R1 → R4 顺序，可分批交付。

### V6′-R1 · 双口径对齐重跑（🔴 **最先做**，消除 §1.2 的口径混淆）

| 项 | 规格 |
|---|---|
| 目的 | 回答「A 到底是 0.693 还是 0.597」—— 两者配置不同，必须同屏对齐后才能谈 `Δ_surv` |
| 动作 | 在**同一份输出**里给出两组：`(a)` 六槽 PATH 金标本（seed `20260930`）；`(b)` 八槽 RADIAL（seed `20261002`，`ATTRITION=1.50`，`WARMUP=2`，`max_actions=12`，N=300）。每组均打印 A/B 的 `survive_rate` / `takeoff_rate` / W20 `ratio` / 中位起飞波 |
| 期望 | 至少确认六槽 A ≈ 0.693 与八槽 A = 0.597 的差异**来自配置**（槽数 / 几何 / seed）而非随机噪声 |
| 判读 | 若六槽与八槽 A 差 >0.05 → 🔴 八槽本身就在压 A，这是 **Q-R9（八槽是否启用）的前置输入**，须回传主理人 |
| 成本 | 低（复用既有入口，多跑一组六槽） |

### V6′-R2 · B 路径压力剖面（回答"赢得多轻松"）

| 项 | 规格 |
|---|---|
| 目的 | `survive_rate = 1.000` 是二值量，丢掉了"险胜 vs 碾压"。补出 B 的**逐波压力曲线** |
| 埋点 | 每波打印 B 的 `core_hp` / `leaked` / 场上残留怪数；汇总输出 **`core_hp_min`（全程最低点）与它出现的波次 `w_min`** |
| 期望 | 若 `core_hp_min ≈ 1000.0`（全程满血）→ **B 从未被逼近**，H1 分量上升；若曾显著掉血后回升 → 存在真实压力窗口 |
| 性质 | 🟢 只读计数，金标本零扰动（`diag_on` 守卫，默认零开销） |
| 附加 | 同屏给 A 的对照曲线，便于直接比"两条路径的压力形状"而不只是比终值 |

### V6′-R3 · A 侧失守波次分布（隔离 H2）

| 项 | 规格 |
|---|---|
| 目的 | A 的 121 个失败局**死在第几波**？区分「起手崩」与「后期崩」—— 两者是完全不同的设计问题 |
| 输出 | A 失败局的 `w_end` 直方图（现成字段，`r4-attrition8-after.log` 已在逐局打印）+ 失守前 3 波的 `core_hp` 斜率 |
| 判读 | 若失败集中在 W8–W11（成型期）→ A 的问题是**成型期塔死螺旋**（`R-T10` 已登记的正反馈螺旋）→ 归 H2/A 侧案，**不是**"多塔太安全"的证据；若集中在 W16+ → 才是后期压力不足 |

### V6′-R4 · 安全裕度只读扫参（🟡 T1 排期，本项最重）

| 项 | 规格 |
|---|---|
| 目的 | 求 `M_B`：把"存活率 100%"翻译成倍率，让 V-6′ 第一次有可判读的连续量 |
| 动作 | 🔴 **只读扫参**：对**怪物强度倍率** `s ∈ {1.0, 1.5, 2, 3, 5, 8, 12}` 扫 B 与 A 的 `survive_rate`（N=300/点，或先 100/点冒烟）。🔴 **只扫描、不落点 —— 扫出的倍率不得写回任何配置** |
| 输出 | B 与 A 各自的 `survive_rate(s)` 曲线 + 插值得到的 `M_B`（跌到 0.90 的 `s`）与 `M_A` |
| 判读 | `M_B / M_A` 的比值 = 两条路径的**压力耐受量级差**。配合 C1 的 `B/A` 联判 |
| 零扰动验收 | `s = 1.0` 那一档必须与现行基线**逐位一致**（B 1.000 / A 0.597 / `B/A` 0.6217）；不一致则该批作废 |
| 优先级 | 🟡 T1，排在 R-4 / R-5 现存工作之后 |

## 5. 红线与不做什么

| 🔴 不做 | 理由 |
|---|---|
| **不动任何定稿数值** | `ATTRITION` / `κ_r` / `AGGRO_R` / 塔位 / `SLOTS` / `t_reach` / `hp_growth` / DPS 曲线 —— 事实基础未建立前动定稿数值是双重错误（同 `v7-final-adjudication.md` 纪律） |
| **不因"要救 A"而削 B** | 那是拿别人的钱补自己的洞。A 侧生存（0.597 < 0.60）是**独立案**（H2 / §3 V6′-C3） |
| **不用下调阈值掩盖机制失效** | 主理人 2026-10-09 明确红线：`survive_rate A = 0.597` 未过 0.60 是**平衡问题**，不得通过改判据阈值解决 |
| **不合并 V-6 与 V-6′** | 杠杆不同（§2）。合并会带偏处置 |
| **不用机制活动量当胜率代理** | `M_B` / 压力曲线是机制量，不是结果量（`mechanics-bulwark-cycle.md` L-4） |
| **不阻塞 Phase 6** | 当前 `B/A = 0.6217` 显著 <1，对价成立；本项只补测量，不产出任何待实现的缓解 |
