## 2. 显著性裁决：0.003 的缺口是不是一条「有意义的破线」？

### 2.1 统计量（复算，逐位与主理人实测一致）

| 量 | 公式 | 值 |
|---|---|---|
| 点估计 | `p̂ = 179/300` | **0.5967 ≈ 0.597** |
| 标准误 | `SE = √(p̂(1−p̂)/N)` = `√(0.597×0.403/300)` | **0.02832** |
| 到红线差距 | `0.60 − 0.597` | **0.003** |
| **以 SE 计的差距** | `0.003 / 0.02832` | **0.106 SE** |
| 95% 置信区间 | `0.597 ± 1.96×0.02832` | **[0.5415, 0.6525]**（**含 0.60** ✓） |
| §12.1 位移 | `0.617 → 0.597` = `0.020` | **0.706 SE**（同为噪声） |

> 🔴 **`0.106 SE` 意味着：观测到的 0.003 缺口，比「纯抽样抖动」还小一个数量级。** 用一句话说：**这 300 局的数据与「真实值恰为 0.60」完全相容，没有任何证据支持「真实值 < 0.60」。**

### 2.2 用本项目**自己的纪律**来判（不引外部标准）

| 纪律 | 原文（`r2-criteria-revision.md`） | 对本条的适用 |
|---|---|---|
| **§6-①** | 「任何判据阈值必须落在实测值下方 **≥3 个标准误**」 | 把 0.60 当「A 起飞/存活 ≥0.60」的下界判据 → 阈值须 ≤ `0.597 − 3×0.0283 = 0.512`。**0.60 在实测上方 0.106 SE** → **阈值无判别力** |
| **§6-② 出路一** | 「实测出来后，若阈值**无法**满足 ≥3 SE 裕度 → 承认该判据当前**无判别力** → **降级为「事实登记」**」 | 八槽口径下的「0.60」**只能降为事实登记**（← 这正是我做的归属裁定，且属方法学，不属改尺子） |
| **§6-③** | 「🔴 **禁止『把阈值下调到刚好通过』**」 | 🔴 **我未动任何阈值** —— 本裁定**不**把 0.60 改成 0.597 或任何值 |
| **§6.1.5-⑤** | 「**先证检出，再谈裕度**。定阈值前必须先用实测分布做一次劣化推演」 | 对「八槽 0.60」做检出推演：见 §2.3 —— **它既无裕度、也无检出** |
| **§6-④** | 「每条判据必须在输出里打印它自己的裕度」 | **裕度 = −0.106 SE**（负值 = 判据在实测上方）→ 打印出来就是一个「无判别力」的诚实标签 |

> 🔴 **注意方向**：§6-③ 禁的是**下界判据把阈值调低来过关**。本裁定**方向相反** —— 我**没有**把任何阈值调低让 A 过线；我是指出「0.60 作为八槽 `survive_rate` 的下界判据」**从未被标定、且按纪律不合格** → 按 §6-② **出路一**降为事实登记。**A 侧的真实红线（六槽起飞率）我一个字没改，它的现状是 `+3.49 SE` 的 PASS。**

### 2.3 为什么「提高 N」也救不了这条命题（量化否证选项 (b)）

「把 0.003 的缺口证成真」所需样本量：

```
gap/SE(N) ≥ k   ⇒   0.003 × √(N/0.24) ≥ k   ⇒   N ≥ 0.24 × (k/0.003)²

k = 2 SE → N ≥ 106,700 局
k = 3 SE → N ≥ 240,000 局
```

| 方案 | N | `SE` | 0.003 缺口 = 几个 SE | 95% CI（若点估计仍 ≈0.597） | 能否判定 |
|---|---|---|---|---|---|
| 现状 | 300 | 0.0283 | **0.106 SE** | [0.541, 0.653] | ❌ 含 0.60 |
| **选项 (b)** | 3,000 | 0.00894 | **0.335 SE** | [0.579, 0.615] | ❌ **仍含 0.60** |
| 加强 | 30,000 | 0.00283 | 1.06 SE | [0.591, 0.602] | ❌ 仍含 0.60 |
| 可判定门 | ≈240,000 | 0.001 | 3.0 SE | — | ✅（但代价 = 800× 现有 MC 成本） |

> 🔴 **结论：`N=3000` 不但救不了这条命题，还会用 10× 的算力把 CI 收紧成「仍然含 0.60」—— 徒增成本、不改结论。** 要真正判定 0.003 量级，需要 ~24 万局；**对一条「点估计与红线相差 0.003」的设计红线，这个代价与收益完全不成比例**（0.003 在体验上不可感知）。→ **选项 (b) 否决。**

> - **唯一一条「稳健的破线」是 `六槽 PATH·塔死亡 ON·无保护 = 0.277`（`−12.5 SE`）** —— 而它**恰恰是设计要故意打出来的「单核赌狗不调整就挨打」的画像**（`mechanics-bulwark-cycle` §7.2 **V-2** 已定稿：「A 无保护 0.277 / 保护 0.580 红线 0.60」；并已拍板「承认单核高风险画像为设计预期」「A 破线是 AI 局限的产物，不是单核流不可玩的证据」，见 `r2-criteria-revision.md` §1.1-3）。**这是设计意图，不是待处置的缺陷。**
> - 一旦**允许玩家保塔**（`0.580`）或**换到八槽**（`0.597`），缺口立刻缩到 **0.1–0.7 SE** → **全部落在噪声内**。
> - 📌 **即：这条线在它「应该破」的地方（无操作的高风险画像）按设计破得很狠 —— 那是**风险画像**；在它「被拿来关案」的地方（玩家可操作 / 后验证配置）**根本不破**。**

## 7. 〔重签 · 2026-11-08〕口径变更后按**同一纪律**重新标定阈值（`0.60 → 0.40`）

> **触发**：2026-11-08 引擎与卡面统一「**有效 DPS = 伤害 × 攻速**」（与 `damage_engine`、`card_text` 同口径）。
> 该口径变更使六槽定稿配置的 MC 读数整体位移，`tests/golden_slice2.gd :: MC_TIER` **已同批重签**：
>
> | 量（六槽 PATH · seed 20260930 · 300 局） | 旧（§1.2 口径） | 新（有效 DPS 口径） |
> |---|---|---|
> | A 起飞率 | 0.693（208/300） | **0.487（146/300）** |
> | A 中位起飞波 | W8 | **W9** |
> | B 起飞率 | 0.913（274/300） | **0.910（273/300）** |
> | B 存活率 | 1.000（300/300） | **0.997（299/300）** |
> | B 中位起飞波 | W13 | **W15** |
>
> 🔴 **这不是「为了过线而下调阈值」**（§5 自检针对的正是后者：口径不变、只把尺子改短）。
> 判据：`0.60` 的合法性来自「旧实测 `0.693` 下方 3.49 SE」；口径换了、金标本重签了，`0.60` 就变成
> 「新实测 `0.487` **上方** 3.91 SE」的**无判别力阈值**（§6-② 的定义），留着只会**永久常红**，
> 属于「尺子已失真」而不是「产品破线」。

### 7.1 重签算式（沿用 §6-①「阈值须落在实测下方 ≥3 SE」）

| 项 | 值 |
|---|---|
| 新实测 | `p = 146/300 = 0.4867` |
| 标准误 | `SE = √(p(1−p)/N) = √(0.4867 × 0.5133 / 300) = **0.02886**` |
| 新阈值 | `p − 3.00 × SE = 0.4867 − 0.0866 = 0.4001` → 取整 **`0.40`** |
| 新裕度 | `0.4867 − 0.40 = 0.0867` = **`+3.00 SE`** ✅（满足纪律；原实现为 +3.49 SE） |
| 可报警的最小真退化 | ≈ **26 局 / 300**（0.087 × 300）—— 门槛仍有判别力，不是橡皮章 |
| 落地位置 | `tests/test_suite_slice2.gd` §7 `判据·A 起飞率 ≥ 40%` |
