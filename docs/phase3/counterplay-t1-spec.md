## §3 UI 规格（可落地粒度）

> 🔴 **全场通用的三条只读约束（每个元素都必须满足）**：
> 1. **渲染层只读 `snapshot()`**（`control-manifest §5`）：不持有玩法状态、不写任何字段。
> 2. **零玩法写入**：UI 计时器（`_revive_flash` / `_core_flash` / `_tower_flash` / `_vfx_t`）纯本地演出，不回写玩法。
> 3. **零新信号**：只消费既有信号（`tower_revived` / `wave_started` / `state_changed`）+ 既有快照字段；**不新增任何 signal**。
> 🔴 **编码红线**：恢复/告警一律走**运动 + 亮度**（art-bible §9.1「敌我非色彩冗余」/ 概念视觉锚点 4），**不依赖色相**（色觉可访问）；屏幕闪烁 **< 3Hz**（`§9.2` P0）。
> 🔴 **禁精确读数红线（T-C2）**：**禁数字 / 禁倒计时 / 禁进度条 / 禁"还有 X 秒"** —— 尤其对 `K` 余量与复活时点。

|---|---|
