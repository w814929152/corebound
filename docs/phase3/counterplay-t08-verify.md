## 3. 复核项 C · 🔴 判读强度核查（重点）

**工程主张**（`§8` 判读 + 脚本 line 213-214）：**「Δ 4/4 全为负 → 🟢 结构(build) 成因坐实 · 方向确凿（非几何特有 · 非 Sapper 特有）」**。

### C-1 「方向确凿」是否成立？ → ❌ 不成立

- **单格层面**：4 格中**仅 2 格** CI 排除 0；另 2 格（`六槽×全关 z=−0.31`、`八槽×全开 z=−1.81`）**单独 n.s.**。→ 半数格子单独不足以支撑显著结论。
- 工程 `§8` 也自认"结论靠方向一致性（4/4 负）而非任一格显著性"—— 即**主动把判据落在"4/4 同号"上**。下面对该判据做检验。

### C-2 符号检验（4/4 同号的单侧 p）→ ❌ 不足以支持"方向确凿"

- 在 H0（无一致方向，正负各 1/2）下：`P(4/4 全负) = (1/2)⁴ = 1/16 = **0.0625（单侧）**`；双侧 = 0.125。
- 🔴 **0.0625 > 0.05** → **未达常规显著性**。即"4/4 同号"本身**只是一个边缘趋势（marginal trend）**，**不是**"方向确凿"的证据。
- 🟡 **更强的问题**：4 格**并非独立样本** —— 脚本对**每臂都用同一 `seed=20261002`**（`_cell` 内 `_PyRandom.new(SEED)`）。→ 各格高度相关 → 符号检验（及任何"合并 z"）的独立性假设被违反 → **p 值反保守**（真实证据 ≤ 0.0625 所暗示）。故"4/4 同号"的**独立信息量还低于** 4 次独立试验。

### C-3 「既非几何专属、也非 Sapper 专属」是否成立？ → ⚠️ 对**符号**成立；对**归因/强度**不成立

**2×2 因子分解（我独立算）**：

| 项 | 值 |
|---|---|
| 几何主效应（八槽−六槽） | **−0.0633** |
| elite 主效应（开−关） | **+0.0067**（≈0！） |
| **交互**（六槽内 elite 效应 − 八槽内 elite 效应） | **−0.1867**（大） |

- elite 的**调制方向在两种几何间翻转**：六槽 `开−关 = −0.087`（elite 使反向**更强**）；八槽 `开−关 = +0.100`（elite 使反向**更弱**）。
- → 这是一个**强交叉交互（crossover interaction）**，elite 主效应几乎为 0（+0.007），**效应由交互支配**，而非"几何"或"Sapper"的加性主效应。
- **符号层面**：4 格 Δ 全负 → 反向**不专属任一轴**（"非几何专属 / 非 Sapper 专属"这句**对"符号"成立**）。
- 🔴 **但**：显著的两格（`六槽×全开`、`八槽×全关`）恰在 2×2 的**主对角**，n.s. 两格在**反对角** → 是**交互型**图样（正是 team-lead 所提示的）。→ 把它归为"**结构成因（单一主轴）**"**忽略了支配性的交互**：更准确的说法是"**方向一致，但强度/显著性由 几何×elite 交互决定**"。

### C-4 建议的措辞强度（我的裁定）→ **折中**，且**不**采"方向确凿"

| 候选 | 我的裁定 |
|---|---|
| 维持「倾向结构 · n.s.」 | ❌ **偏保守** —— 2×2 确实**增强了证据**（4/4 同号 + 2 格显著），比单格更强 |
| 升级「🟢 结构成因（方向确凿）」 | ❌ **过强** —— 符号检验 p=0.0625、2/4 格 n.s.、强交互、非独立 |
| **折中** | ✅ **建议采用** |

**建议措辞（供工程/设计采纳）**：

> 🟡 **方向一致（4/4 负）· 倾向结构成因（证据较单格增强）**；**强度受 `几何 × elite` 交互调制**（elite 的调制方向在两种几何间**翻转**）。
> 🔴 **证据强度**：仅 2/4 格 CI 排除 0；**符号检验单侧 p≈0.0625（未达 α=0.05）**；4 格共用 seed → **非独立**（p 反保守）。
> → **不宜**表述为「结构成因**坐实**」或「方向**确凿**」；「既非几何专属、也非 Sapper 专属」**仅对符号成立**，不可外推为"单一结构主效应"。

### C-5 附：脚本内部自相矛盾（方法论提示）
