### 2.2 统计显著性（✅ N=300 判定 —— 处置 A 结果）

```
ΔB (N=300 忠实) = −0.077
p1 (B 无 Sapper) = 0.817 (≈245/300)      p2 (B 有 Sapper) = 0.740 (≈222/300)
SE_diff（独立两比例，保守） = √(0.81667×0.18333/300 + 0.74×0.26/300) ≈ 0.0338
z(ΔB vs 0)     = −0.077 / 0.0338 ≈ −2.27    → 显著（|z| > 1.96）：惩罚确实非零
z(ΔB vs −0.10) = (−0.077 + 0.10) / 0.0338 ≈ +0.69 → 无法拒绝「ΔB ≥ −0.10」
95% CI ≈ [−0.143, −0.010]
```

- ✅ **`ΔB = −0.077 ≥ −0.10` → 维持「温和档」** → 按 §4 处置 A 的**预登记决策规则**：**本案关闭**（不进入兜底处置 D）。
- 🔴 **N=60 的 `−0.117` 是小样本假象**：`SE_diff` 从 0.073（N=60）→ 0.034（N=300，−55%），`ΔB` 由 −0.117 回落 −0.077。**这正是 §4 处置 A 存在的理由** —— 单点 N=60 会**误判档位**。
- 🟡 **两条并不矛盾**：`z(ΔB vs 0) = −2.27` 说明惩罚**确实非零**（效应真实）；`z(ΔB vs −0.10) = +0.69` 说明**量级在温和档内**。
- 对照：`ΔA = −0.007`，`SE_diff ≈ 0.0364` → 95% CI ≈ `[−0.078, +0.065]` **含 0** → A 路径 Sapper 惩罚在噪声内 ≈ 中性。

### 2.4 为什么惩罚会随镜修复而变（机制侧，供工程/复核交叉验证）

镜像 ② 相位原为 **no-op**（丢弃稳定排序返回值）→ 若 aggro 冻结了部分怪的 `t_remain`（Sapper / AggroTower 停下），插入序 ≠ `t_remain` 升序 → 分歧显形。修复后 ② 相位**忠实执行「距核心最近优先」**的伤害分配。Sapper 场景下，冻结的 Sapper 群改变了分配序 → B 路径的 DPS 清场节奏被改写 → 塔死亡时机/数量变化 → 起飞率变化。**单波恒等、整局演化 build 才显形**（`aggro-mirror-fidelity-impl.md` §2 / §5），与「A 路径 0 格分歧、逐位不变」一致（§3.4 整局差异 B:4→0 / B+Sapper:4→0）。

### 3.2 为什么"仍成立"是可辩护的（设计理论侧）

- **Sapper 的定稿角色 = 可读的节奏标点，不是崩盘源**：B 有 Sapper 仍 **0.740** 起飞，且 Sapper **不制造漏怪**（纯塔杀手）→ 惩罚经"塔死 → DPS 崩"传导，是**可归因**的（符合概念 §4.1）。
- **惩罚量级（7.7pp）比旧读数更贴支柱**：旧 `−0.027`（2026-10-07）≈ 接近**非感知**（Sapper 看着像装饰，定稿意图"必须预判"偏弱）；`−0.077` 让"下波有 Sapper → 提前保塔"这个决策**真正有分量** → 强化 **P1（站位/投资即策略）与 P4（预判型决策）**。这是**健康的方向**。
- **`−0.077` 是"金标本 AI 地板"，不是"玩家上限"**：`scan_sapper.gd` 头注明示金标本 AI **不玩反 Sapper 策略**（纯 DPS 贪心）→ 该读数 = **玩家什么都不做**的 worst case。与 V-2 同款逻辑（A 无保护 0.277 → 理想肉盾 0.580，玩家可操作空间 +0.303）。→ 玩家的可应对空间**存在但未测**（见 §4 处置 C）。

### 3.3 🔴 定性翻转：「A 更扛 Sapper」（旧洞察作废 · N=300 稳健）

`scan_sapper.gd:96-97` 的输出判据：`B 更扛 if ΔB > ΔA + 0.05` / `A 更扛 if ΔA > ΔB + 0.05`。

```
ΔA = −0.007 ；ΔB = −0.077  →  ΔA (−0.007) > ΔB (−0.077) + 0.05 = −0.027  →  ✅ "A 更扛"
```

| 旧定稿洞察（失忠 + 旧时点） | 忠实读数（N=300） | 判定 |
|---|---|---|
| 「多塔流更能扛 Sapper（肉盾/冗余塔吸收）」 | **A（单核）几乎不受影响（−0.007，CI 含 0），B（多塔）明显承压（−0.077）** | 🔴 **正式翻转 → 旧洞察作废（D-5）** |
| 「多塔流是肉盾主场」 | 塔耐久 ∝ `h^0.6` → **Sapper ×3 惩罚"塔多"（h 摊薄 → HP 小 → 被 ×3 秒），相对奖励"塔高"（h 大 → HP 大 → 扛得住）** | 🔴 **作废 → 重新表述为「反广度·亲集中」（D-5）** |

> **设计侧解读（供拍板）**：忠实读数下 Sapper 实际上是一个 **"反广度·亲集中"** 的压力 —— 它惩罚"多而薄"的塔、相对奖励"少而高"的塔。这与 Sapper 的**定稿角色（中立的可读威胁）**不冲突，但**是一处此前未登记的隐性 build 偏置**。需在 T1 试玩中确认它是：**可接受的对价回补**（多塔流 Elite 波容错变薄，恰好回应 `v6prime-multitower-margin.md` 的 H1「B 后期无压力」），还是**越界的画像漂移**（B 的"稳健流"身份被 Elite 波侵蚀）。

### 处置 B · ✅ 默认采纳：保留 ×3 不动，升为 T1 观察项
