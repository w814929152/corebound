### 0.2 🔴 实现边界（决定一切的技术前提）

现象：当前战场是**纯 2D 立即模式绘制**，**没有 3D 管线**（无 `Camera3D` / `Node3D` / `MeshInstance`）。

因此在本次范围内：

1. **第一刀 = 在现有 2D 立即模式栈上做可读性 + HUD 重做**，**不引入 3D 低模管线**（3D 化是独立大阶段，见 §C.3）。
2. 全部规格落在 `_draw()` 可实现图元范围内。**经核对，本 spec 不需要任何新的 2D 绘制能力**（可用图元清单见 §A.10）。
3. 只 **只读** snapshot（`WaveDirector.snapshot()` / `Runtime.snapshot()` / `TimeDirector.snapshot()`），**不写任何玩法状态、不新增玩法信号**。

### 0.3 像素尺度（本 spec 全表换算基准）

现有 `monster_layer._xform()` 在 RADIAL 模式下的包围盒 = `[core±(R_s+3)]` = **116 × 116 world unit**，`MARGIN=48`。

```
sc = min( (field_w − 96)/116 , (1080 − 96)/116 )
   = min( (field_w−96)/116 , 984/116 = 8.482 )

@1080p：
  · 抽屉闭合  field_w = 1920 → sc ≈ 8.48
  · 抽屉展开  field_w = 1306 → sc ≈ 8.48   ← 高度是绑定约束，两态同值（稳！）
```

> ✅ **结论**：@1080p 下 **sc ≈ 8.48 px/unit**，且抽屉开合**不改变**战场缩放（只平移），径向布局的空间关系在两种焦点态下**逐像素一致**——这对 P0 可读性是利好，规格直接按 `sc≈8.48` 给 px。

**本 spec 尺寸写法**：`世界单位 u`（工程乘 `sc`）+ 括注 `@1080p px`。所有 px 尺寸随视口等比缩放（`px = u × sc`），不做固定像素坐标（art-bible §6.6）。

## 0.5 ★ 投影裁决：等距 vs 俯视

> **裁决：P0 第一刀 = 正交俯视 2D（top-down，圆保持正圆，零 Y 压缩）。**
> 明确**不采用**「俯视 + 轻量 Y 压缩的伪等距」。

### 理由（3 条，按优先级）

**① 径向布局的核心玩法信息是「角度 + 半径」，只有俯视能 1:1 保真。**
360° 围攻的全部可读性建在两个量上：**威胁来自哪个方位**、**离核心多远**。正交俯视是唯一让"圆 = 圆、等半径 = 等屏距"的投影。art-bible §6.1 的 `rotation=(-30,45,0)` 等距相机把圆压成 **2:1 椭圆**：

- **角度失真**：屏幕上"12 点方向"在椭圆上不是均分角，玩家对"东/南/西/北"的方位直觉被破坏 → 直接违背 P0 目标（1 秒分清）。
- **半径失真**：出生环上不同方位的同半径怪，屏幕视距不等 → 玩家会误判"哪边怪更近/更威胁核心"，而**暴露度判断（P1 支柱）正建立在半径直觉上**。

**② 伪等距在 2D 立即模式下"更贵且更错"。**
真等距的价值（art-bible §1.1）是 **3D 深度缓冲免费解决 y-sort**。伪等距没有 3D，得手工做**非仿射变换 + 逐单位深度排序**——成本高于俯视，收益只是"看起来像等距"，**不解决任何可读性问题**，反而放大①②。

**③ 与 art-bible 的冲突就地登记，不在本次调和。**
art-bible 是按**等距网格世界**（棋盘格 / 菱形瓦片 / 3D 低模）写的；当前项目是**无网格圆环世界**。两者是投影层的根本冲突，见 **§D 修订登记**。本次**不改 art-bible**，仅登记：径向布局下 §1.1 / §6.1 / §7 降级为"可选美术方向"，**保留复用**与投影无关的 §2 配色 / §3 形状 / §4 描边·blob / §5 UI / §8 VFX / §9 可访问性。

### 后续可选（本次不做）

「伪等距 Y 压缩」**不作为 P0 路线**，但在 P2 可**重新评估**，前置门槛 = **通过"角度保真测试"**（同一半径上 8 个方位的屏幕视距差 ≤ 10%），否则不上。可考虑的折中是**只对地面装饰做 Y 压缩，单位位置与出生环保持 1:1**，但这会制造"地面 vs 单位"投影不一致的第二层混乱——**建议整场统一俯视**。

### 俯视下的形状语言转译（art-bible §3.1 的落地补丁）

art-bible §3.1 用「**垂直向上**（塔）vs **水平前倾**（怪）」区分阵营——这是**侧视/等距**语言。俯视没有"高度"轴，故转译为**俯视可读的等效编码**：

| §3.1 原属性 | 俯视转译（P0 采用） |
|---|---|
| 垂直向上 / 重心高（塔） | **同心多层**（外暗内亮的双层八边形）+ **中心高光点偏左上**（假 3/4 顶面）+ **投影偏移大**（越高影越远） |
| 水平前倾 / 重心低（怪） | **单层不规则块** + **尖刺沿"朝核心"方向外向拖曳**（扑来感）+ **投影偏移小**（贴地） |
| 严格对称（塔） | **正八边形**（8 次旋转对称，像素级对称） |
| 不对称（怪） | **基础圆 + 确定性半径扰动 + 外张尖刺扇**（左右不等） |
| 底座环：规则八边形环（塔）/ 不规则裂环（怪） | **直接沿用**（俯视下同样可读，见 §A.8） |

### A.2.2 怪物（敌方 · 不对称 · 尖刺扑来）

**配方**：

```
怪 = 不规则主体(基础圆 + 确定性半径扰动)  +  外向尖刺扇(沿"朝核心"方向拖曳)  +  外扩描边
     (+ 精英额外: 噬品红环 + 尖刺加密)
```

| 层 | 图元 | 参数 |
|---|---|---|
| 1 主体 | `draw_colored_polygon(blob(c, R_body, seed), 熔橙#FF6B3D)` | 见下 `blob()` |
| 2 尖刺 | `draw_colored_polygon(三角, 焦褐#8A2F1C)` × `n_spike` | 见下 |
| 3 描边 | `draw_polyline(blob(c,R_body+w/2,seed) 闭合, 怪描边#2E1008, w)` | `w = 0.22u` |
| 4 精英环 | `draw_arc(c, R_body+0.28u, 0, TAU, 24, 噬品红#E8437F, 0.18u)` | 仅 `elite==true` |

**确定性（关键，防帧间抖动）**：

```gdscript
# 主体轮廓：固定 12 边形 + 固定扰动表（全员共享，帧间稳定）
const BLOB_R12 := [1.00,0.88,1.06,0.92,1.02,0.86,1.04,0.95,1.00,0.90,1.05,0.93]
func blob(c, R, ) -> PackedVector2Array:   # 无 seed 参数 → 全员同形，符合"极简低模"（§11-4）
    for k in 12: pts.append(c + dir(TAU*k/12) * R * BLOB_R12[k])

# 尖刺扇：朝向 = 单位"朝核心"径向反方向（由 pos 平滑派生 → 帧间稳定、语义正确）
var out_dir := atan2(pos.y - core.y, pos.x - core.x)     # 由怪指向核心
for i in n_spike:
    var a := out_dir + SPIKE_SPREAD * (i - (n_spike-1)*0.5)   # 扇形外张
    var tip            := c + dir(a) * (R_body + spike_len)
    var base_l         := c + dir(a - 0.26) * R_body*0.9
    var base_r         := c + dir(a + 0.26) * R_body*0.9
    draw_colored_polygon([base_l, tip, base_r], C_ENEMY_DARK)
```

> ✅ **为什么不给每只怪独立随机种子**：snapshot 无稳定 id，逐帧重建会抖动；且 art-bible §11-4「极简低模 + 剪影测试」的目标是**剪影类可辨**（粗/细/长），**不是个体身份**。用"共享轮廓 + 朝核心尖刺"既稳定又强化"扑来"读感。

**三种原型 + 精英的形状差异**（剪影测试可辨：**细长 / 中等 / 粗短**）：

| 原型 | `R_body` | 主体造型 | 尖刺 | 剪影类 |
|---|---|---|---|---|
| **Rush**（小快） | `0.65u (5.5px)` | 沿径向**拉长**（椭圆 squash，长轴×1.5） | 4 根**细长**（`spike_len=0.9u`） | 长梭/水蛭 |
| **Swarm**（中） | `0.85u (7.2px)` | 12 边不规则球 | 5 根中（`0.55u`） | 刺球 |
| **Tank**（大慢） | `1.30u (11.0px)` | 12 边不规则**宽扁**（短轴×0.9）+ 内层焦褐环 | 6 根**短粗**（`0.4u`） | 破块 |
| **Elite**（修饰） | `R_body × 1.35` | 继承原型 | 每根 +30% 长 + 噬品红环 | 加大一圈 |

> art-bible §3.2-3 体量分层：`Tank/Swarm = 1.53 ≈ 1.6`（对齐 §3.2-3 精英/杂兵宽比），且三档半径差均 **≥ 40%**。✅

## A.3 椭圆投影（Blob Shadow）—— art-bible §3.2-4 / §7.3

1. 建目录 `art/fonts/`（art-bible §10.1 目录结构）。

   - `Theme.default_font = Inter-Regular`，`default_font_size = 20`
