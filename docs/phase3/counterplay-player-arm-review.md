## §1 判读一：T2/T4 在 B·八槽反向 —— **口径差异为主 + 结构耦合为次**

### 1.1 先钉住"哪条先例被推翻"（🔴 避免跨口径错误）

| 先例 | 几何 | build | 被测量 | 数值 | 与 C-9 的关系 |
|---|---|---|---|---|---|
| **V-4**（`scan_bulwark.gd`·300 局） | **六槽 PATH** | **A**（+B **仅无保护**） | A 无保护 / A 隐身 / **A 肉盾** / **B 无保护** | `0.277 / 0.580 / 0.580 / 0.817` | 🔴 **从未测过 `B + bulwark`** → C-9 的 `B+bulwark` 是**新事实**，**不构成对 V-4 的矛盾** |
| C-9（`scan_counterplay_player_arm.gd`·300 局） | **RADIAL 八槽** | **A / B 各臂** | B 的 T0/T1/T2/T3/T4 | `0.747 / 0.813 / 0.680 / 0.777 / 0.683` | 首次量化 B 的完整反制臂 |

> 🔴 **判定**：所谓"T2 反向与 V-4 冲突"是**跨口径误读**（`sapper-balance-review §1.3` / `v7-baseline-retraction §1.1` 同款错误）。V-4 的结论**只覆盖 A、且只有六槽 PATH**；它**没有**断言"bulwark 对 B 有益"。→ **C-9 不推翻 V-4，而是补上了 V-4 的空缺。**

### 1.2 机制根因：T1 与 T2 是**两种不同性质的干预**（源码级）

读 `wave_sim_aggro.gd` 源码（`:286-288` 注释 + `:291 _relocate_carry_to_safe`）：

| 臂 | 干预性质 | 对 **E（共鸣/覆盖）** 的影响 | 机制注释原文 |
|---|---|---|---|
| **T1 `protect_core`** | 主力塔**隐身**（怪跳过它）—— **塔仍在原位** | 🟢 **E 不变**（`_nearest_exposed_tower(..., protect_core)` 只改仇恨目标，不改落位） | `protect_core = 主力塔隐身（怪物跳过它，塔仍在暴露位、E 不变）` |
| **T2 `bulwark`** | 主力塔**真挪到安全位**，安全位塔换到旧暴露位当肉盾 | 🔴 **E 会变**（纯 slot 交换 → `dps_only` 重算 → 安全位 S4/S5 度 3 / 非枢纽 → **共鸣下降**） | `bulwark = 主力塔真挪到安全位（E 会变……），代价是 DPS 下降` |

> 🔴 **关键**：**T1 是"零 DPS 代价的保命"，T2 是"有 DPS 代价的保命"。** 二者**不可互推**。V-4 里"A 隐身 = A 肉盾（Δ=0.00）"只在 **A** 成立（A 的 carry 挪位损失小）；**其逆命题对 B 不成立**（B 的 carry 挪位损失大，见下）。

### 1.3 为什么"B 反向、A 正向"（结构机制猜想 · 与 H1 联判）

```
A 单核（2 塔，全暴露）：           B 多塔（1 深塔引擎 + 5 占位）：
  carry 挪位 → E 损失【小】         carry 挪位 → E 损失【大】
  保命收益【大】（floor 低：0.203）  保命收益【小】（floor 高：存活率 0.900）
  ─────────────────────            ─────────────────────
  净效果 = 正（+0.314）             净效果 = 负（−0.067）
```

| 论据 | 出处 |
|---|---|
| **B 的深塔是唯一供 E 的引擎** —— 占位塔 `h=1 < 3` 本就不供 E（`E=[9,0,134,0,0,0]`）→ **挪走深塔 = 挪走全部共鸣**；换上来的占位塔 E=0 | `mechanics-tower-life-death.md` §0.4 / §1.7 |
| **B 地板已高 → 保命的上升空间被压平** —— H1 实测：**B 后端 W13+ 100% 满血**进入雪崩期，**从未被逼近**（`core_hp_min ≈ 1000`） | `v6prime-multitower-margin.md` §2（R2） |
| **安全位"保命但损 DPS"的结构性取舍**（S4/S5 覆盖低 0.319/0.507 + 度 3 非枢纽） | `mechanics-tower-life-death.md` §0.4 / §4.2 V-4' |

> 🔴 **一句话**：**在 B 里，把深塔从它的枢纽挪到安全位 = 用"它几乎不需要的保命"换"它唯一依赖的共鸣" → 纯亏。** 这不是"bulwark 机制坏了"，是**"真挪塔"是一种单核流味道的反制，被施加到多塔流的引擎上**。

### 1.4 与 sapper「反广度·亲集中」的关系：**同根，不同轴**

| 项 | Sapper 的「反广度·亲集中」 | C-9 的「B+bulwark 反向」 |
|---|---|---|
| 轴 | **威胁**如何与 build 广度交互（Sapper 无视距离 → 惩罚"多而薄"、奖励"少而高"） | **反制**如何与 build 结构交互（挪走引擎 → 惩罚位置敏感的集中式 build） |
| 共同根 | 🟢 **B 的价值集中在"一座位置敏感的深塔"上** —— 这是 B 的**身份**（"少而高 / 稳健流"）而非缺陷 | 同上 |
| 判定 | 🟡 **同根不同轴** —— **不把 C-9 归入 §3.3 的同一族**；但**两者共同强化"B 的深塔是命门"这一画像** | |

> 🟢 **与既有画像自洽**：`v6-dominance-adjudication.md` §2.5 早已实测"**肉盾在一切已测形态下存活率 0.57–0.59（低于 0.60 红线）→ 不可能是必胜解**"。C-9 的 `B+bulwark 0.680` 与之一致（**bulwark 从来不是通解**，是 A 的救援工具）。

## §2 判读二：T1 唯一越线 → **R-S2 未触发**，但登记 R-CP-1

### 2.1 为什么不算"主导策略"（R-S2 未触发）

| 判据 | 结论 |
|---|---|
| **工具箱是否退化为单解题？** | ❌ **否**。四路应对在不同 build 各自有效：**A → 挪塔/肉盾**（Δ+0.314，主解）；**B → 保深塔**（T1）+ **复活**（T3）；**肉盾**在 B 为负向 → **不同 build 的最优反制不同** = 工具箱**未退化** |
| **T1 是"真实可选解"吗？** | 🟡 **它是上界近似**（"隐身"= 非字面操作，`scan_counterplay_player_arm.gd:16` 明示"升 HP / 保塔 的近似"）→ 玩家**不能**真的让塔隐身 → **T1 不构成"玩家会照做"的主导解** |
| **是否存在"严格更优按钮"？** | ❌ 否。T1 的**代价**（升 HP 要花积分/槽位/卡）被诊断臂**省略**了 → 真实"升 HP"臂的收益 **≤ 0.813**，不构成免费更优解 |
| 与 `v6-dominance-adjudication` 一致 | 🟢 肉盾/反制均非必胜解 |

> ✅ **裁定：R-S2 未触发。** 「反制工具箱退化为单解」**不成立**。

### 2.2 🟡 但登记观察项 **R-CP-1**（🟡 中 · T1 试玩观察 · 非缺陷）

> **在 B·八槽口径下，唯一越门禁的反制是「保深塔」单轴（T1）；肉盾（T2/T4）为负向、复活（T3）为辅助。** → 需在 T1 试玩确认：**B 侧玩家感受到的"可应对空间"是否足够宽**，还是收敛为"只有一条路（把主力塔养厚）"。

- **判据**（试玩）：玩家在 B·Elite 波后能否说出**≥2 种**独立的保塔手段（升 HP / 插肉盾 / 卖副塔换钱 / 硬扛后修）并各有其用；若只能说"给主塔升级" → R-CP-1 升级为需处置。
- **非缺陷理由**：`mechanics-tower-life-death.md` §3 玩法② 已**预判**"肉盾天然耦合多塔流、**对单核流是纯成本**"；C-9 结果显示的是**反过来的**（肉盾利 A、损 B）—— 🟡 **这个方向差值得在 T1 观察**（见 §4 建议 ③ 的定因实验）。

### 2.3 判读三：T3 复活 = **辅助臂**（与 V-8 B1 自洽）

| 事实 | 判读 |
|---|---|
| T3 复活 `0.777`（**+0.030 vs 地板**，z≈+0.86 → **噪声内**） | 🟢 **正向但不显著、不单独达标** → 与 `mechanics-bulwark-cycle` **V-8 B1「复活结构改善真实、零胜率代价」**一致 → 复活是**辅助臂**（保下限、稳结构），**不是主解** |
| T4（肉盾+复活）`0.683` ≈ T2 `0.680` | 🟢 组合臂**未超过**单臂 → 说明 T4 的净效果**被 T2 的负向主导**（复活的正向 +0.030 被挪塔的 −0.067 抵消）→ **再次印证 T2 的负向来自"挪塔"而非"复活"** |

> 🔴 **判读**：**复活应作为"第二层代价/续航保底"定位保留**（`mechanics-bulwark-cycle` 原定位），**不应被当作 B 的达标主解**。这与 C-1/C-2 已决策的"产品化 M-1"**不冲突**（产品化是给玩家多一个可用工具，不是宣称它是主解）。

## §3 🔴 独立统计核算（我的复核 · C-9 文档未量化）

> 工程 C-9 只报点估计。设计侧在此**补一次独立核算**（比例的标准误，N=300）——这是判断"结论是否稳健"的必要步骤（沿用 `sapper-balance-review §2.2` 的 N=300 纪律）。

| 对比 | Δ | SE（独立两比例 / 单比例） | z | 稳健性 |
|---|---|---|---|---|
| **T0 地板 vs 门禁 0.80** | −0.053 | SE_T0 ≈ 0.0251 | **−2.12** | 🟢 **较稳健**（地板确实破线） |
| **T1 上限 vs 门禁 0.80** | **+0.013** | SE_T1 ≈ 0.0225 | **+0.59** | 🔴 **噪声内 → 不稳健**（"上限达标"随时可能翻面） |
| T2 vs T0 | −0.067 | SE_diff ≈ 0.0368 | **−1.81** | 🟡 **边缘显著**（"反向"**存在但未达 1.96×**） |
| T4 vs T0 | −0.064 | SE_diff ≈ 0.0368 | **−1.72** | 🟡 边缘显著 |
| T3 vs T0 | +0.030 | SE_diff ≈ 0.0348 | **+0.86** | 🟡 **噪声内**（辅助臂定性成立） |

> 🔴 **统计裁定**：
> 1. **稳健的只有"地板破线"**（−2.1 SE）。
> 2. **"上限达标"落在噪声内**（+0.59 SE）→ `counterplay-player-arm.md` §0-2 的「**反制窗口是达标必要条件**」这句**过强**，须降级为：
>    **「地板稳健破线；上限在噪声内勉强触及门禁（0.813 vs 0.80，+0.59 SE）→ 反制窗口是达标"必要条件"的结论**尚不能坐实**，取决于上限的真实性（见下）。」**
> 3. **T2/T4 反向是"边缘显著"**（≈ −1.8 SE）→ 方向可信、但**量级不宜过度解读**；**不得**据此做任何数值调整（`ATTRITION`/`bulwark` 落点）。

### 3.1 🔴 上限真实性的**结构性缺口**（比统计更根本）

> **T1「隐身」不是玩家能做的动作** —— 它是"升 HP / 保塔"的**理想化上界**（`scan_counterplay_player_arm.gd:16`）。**真实的"升 HP"臂需花积分/槽位** → 其收益 **≤ 0.813**。
> → 既然上限**仅以 +0.013 触线**，那么**真实（有代价）保塔臂极可能落回 0.80 之下** → "达标必要条件"可能**翻转为"上限仍破线（对接处置 D）"**。

> 🔴 **这决定了对 `sapper-balance-review §4-处置 C` 的最终回答**：**处置 C（反制窗口落地）已按规划落地**（暴露度 UI / Elite 预告 / 复活产品化 / 塔信息图标，见 `counterplay-t1-spec.md`），**机制齐备**；但"**玩家上限能否推 B 过门禁**"**仍未被真实臂证明** → **处置 C 的"达标"半边仍是悬案**（对接 §4 建议 ①②）。
