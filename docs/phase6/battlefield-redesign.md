# 关卡地形实装

十关改用各自的异形地块，移除正式游戏中的圆盘、同心环和放射刻度。

| 地图 | 场景主题 |
| --- | --- |
| tri-fissure | 中继站、三向连接道路、设备基座 |
| cinder-forge | 炉区、热流导槽、金属格栅 |
| rime-station | 冰封站、碎冰面与裂纹 |
| rail-corridor | 双轨道、站台与侧翼通道 |
| arc-grid | 电力设施、电容基座与电缆 |
| forge-union | 厂区、装卸区与设备屋顶 |
| bio-lab | 生态实验区、培养槽与苔藓 |
| void-range | 裂隙试验场、破碎地面 |
| overseer-ring | 外城街区、建筑基座 |
| overseer-core | 核心堡垒、装甲地面与红色导光 |

`battlefield_maps.gd` 是地块和障碍的共同数据来源；地形绘制、建塔、放置网格和敌人出生边界都读取它。地块外、墙体和核心附近不能建塔。装饰性道路、铁轨与铺装仍属于可建地面。

敌人从关卡既有入口角度对应的真实边缘出生，继续直线向核心进攻；道路用于环境表达，没有引入沿道路寻路。波次时间和敌人数值不随地图缩放调整。

场地宽高扩大为原版的 1.5 倍，实际地面面积约为原来的 2.25 倍。地块边界、障碍和环境绘制一同扩展，塔的射程与格点间距维持世界单位口径。

`battlefield_camera.gd` 统一地形、单位和特效坐标。默认以近景观察核心；缩放范围为默认视角的 60%—240%。左键拖动空地或中键拖动平移，滚轮围绕鼠标位置缩放。放置时左键继续负责卡牌拖放和落子，中键仍可平移。按 F 或点击“回到核心”恢复默认视角；“总览”完整显示地块。

`battlefield_navigation.gd` 在准备阶段和战斗阶段均可接收镜头操作。商店和背包区域不将滚轮或拖动传给地图；开关商店保留镜头，新一局重置视角，窗口失去焦点会结束拖动。平移受地块范围约束，避免把地图拖丢。已有伤害数字随镜头重投影，塔等级牌和放置预览也同步更新。

地形使用原生绘制并缓存几何，不依赖新贴图。正式窗口入口开启新地形；历史模拟默认保留基准模式。

验证脚本：`tests/run_battlefield_maps_asserts.gd`，覆盖十关的地面、障碍、建塔、入口、进攻路线、地图相机、特效坐标和购买放置流程；窗口模式下同时输出十张预览到 `art/_review/terrain-*.png`。
