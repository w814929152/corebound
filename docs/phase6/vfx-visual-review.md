## 1. §8.3 超杀档 —— ✅ PASS（无 time_scale / 无全屏色差）

**要求**（art-bible §8.3 注 + vfx-art-spec §2.1 注）：超杀档 = **彩虹色文字 + 字号弹跳 + 一次性亮环**（2D 替代）；**不得**出现**全屏色差**或**慢动作 0.35×**（`time_scale` 写入权属 = 架构红线）。

**证据**：
- 代码（`vfx_layer.gd:558-579`）：tier4 颜色 = `Color.from_hsv(fmod(_vfx_t*0.6 + jitter*0.05, 1.0), 0.85, 1.0)` —— **仅文字色**随寿命相移（彩虹流光）；字号弹跳 `size*(1 + 0.35*pow(1-min(1,p/0.25),2))`（tier≥1）；一次性亮环 `if tier>=3 and p<0.3: draw_arc(8+26*rp, α=0.6*(1-rp))`。
- **受控留证**：`shots/ad-vfx-matrix.png`（帧内自绘 tier4「80」）+ `shots/_ad-zoom-dmg-tier4.png`（×3）→ 该数字呈**绿色相**（彩虹某一相位）带深描边 + 身后**一次性亮环**；同帧其余画面**无任何全屏色差/泛白**。
- **时间轴**：受控探针打印 `time_scale before=1.000 after=1.000`（见运行日志）；全层**零** `Engine.time_scale` 写入（`vfx_layer.gd` 无该符号）。

**判定**：✅ **PASS**。
- ① 彩虹色文字 ✓；② 字号弹跳 ✓；③ 一次性亮环 ✓；④ **无全屏色差** ✓（`gl_compatibility` 无 Bloom/色差，且代码无 post-process）；⑤ **无慢动作** ✓（`time_scale` 恒 1.0）。
- ⚠️ **如实标注**：§8.3 表「60–100%」行的「1 级震屏」**未实现** —— 本项目**尚无震屏系统**，且 §9.2③ 要求「震屏必须可关闭」→ **不引入**是更安全的选择（vfx-art-spec §2.1 注①已预判）。**不构成偏离**。

## 4. A2 伤害数字 vs §9.1「最小字号 ≥16px」—— ✅ PASS

**问题**（team-lead 项 4）：伤害数字属**玩法可读性读数**还是**纯演出装饰**？前者须 ≥16px。

**判定依据**：
- **性质** = **玩法可读性读数** —— 数字传达**单次伤害占目标最大血量的档位**（`frac = dmg/hp_max`），是玩家评估「我这发打了多少 / 是不是超杀」的依据 → **必须 ≥16px**。
- **实现**（`vfx_layer.gd:63`）：`DMG_TIER_SIZE = [20, 26, 34, 44, 60]` → **最小 20px ≥ 16px** ✓。**无需 dev-only 豁免**（§9.1 的 F3 豁免不适用于此）。
- **对比度**：`draw_string_outline`（深描边 `#05050A`-级 α）+ 亮字 → 深底（`#232838` 场）上对比充足（`_ad-zoom-dmg-tiers.png` 白「4」/淡金「20」/辉金「45」/橙金「80」均清晰）。
- 复核：五档**字号递增**可观（20<26<34<44<60，矩阵帧 `ad-vfx-matrix.png` 五档同框）。

**判定**：✅ **PASS** —— 伤害数字属玩法读数、且**满足 ≥16px 红线**（最小 20px），无需豁免。

## 7. 追加：C3/C4 性能伴随的视觉等价 —— 🔴 **已证伪（`VFX-C3-01`）**

> 🔴 **本项原判 PASS 已被推翻** —— 推翻者为 **quality-lead 的独立定量探针**（非本人自截）；缺陷编号 **`VFX-C3-01`**。以下为订正后的完整记录。

**缺陷（`VFX-C3-01`）**：
- **C3 几何缓存键** = `Vector3(sc, vs.x, vs.y)`（`monster_layer.gd:988`）—— **漏了「抽屉」维**。
- 但地面几何实际依赖 **`c := _to_screen(_SpaceModel.RADIAL_CORE)`**（`monster_layer.gd:949`），而 `c` 经 `_field_width()` **受抽屉状态影响**。
- **产品默认档 1920×1080**：开抽屉时 **`sc` 逐位不变**（`vh`-bound，`sc ≈ 8.4827`），但 **`c.x` 位移 −307.2px（960 → 652.8）** ⇒ **缓存键不变 ⇒ 返回旧几何**。
- ⇒ **地面几何（同心环×3 / 放射刻度×8 / 出生环）错位 307.2px**；且首次 `sig` 后**整局锁定不再重建**（除 `sc`/视口变化外）。
- 影响面：**仅"开抽屉"态**（收抽屉时 `sc` 与 `c` 同源于本层，键恰好够用 → 故同状态对比看不出）。

**🔴 我原判 PASS 的错因（方法论教训 · team-lead 要求长期保留）**：
- 我的等价性证据是 **`ad-drawer-closed.png` vs `ad-drawer-closed-2.png` = 同一状态（都"收起"）**；
- 而缺陷**恰好只存在于我没做 diff 的那个状态（`open`）**；
- 我**截了** `ad-drawer-open.png`，却**只做目视、没做像素差** ⇒ **硬证据退化成自证**（同状态对比恒为 0，**永远 PASS**）。
- ⇒ 🔴 **判据：等价性测试必须 cross-state（open vs closed），否则无法发现"只在某一状态错"的缺陷。** 这条比本次具体缺陷更值钱。
- 追认：`closed` vs `-2` 的 **`diff = 0` 只是"静止态自洽"，不是"等价性证明"** —— 我此前把它**误当成了后者**。

**证据修正**：`ad-drawer-open.png` 由「✅ 几何正常」**改判为**「**缺陷现行帧**」——该帧正是本缺陷的可视载体（本应做 open↔closed 的 cross-state 像素差，而我没做）。

**处置（不由本人执行）**：**修复 + cross-state 永久断言** → engineering-lead；**增量复核** → quality-lead。**本人只做：① 订正本判定；② 登记上述教训**；**未重建采集器、未改生产代码、未 push**。

**订正后判定**：🔴 **已证伪（`VFX-C3-01`）** —— C3 缓存在**开抽屉态**造成地面几何 **307.2px 错位**，**非"无视觉缺失"**。
