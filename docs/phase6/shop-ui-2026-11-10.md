# 商店 UI 与交接 · 2026-11-10

商店在屏幕上方水平居中，只展示三张竖版商品卡。按玩家要求去除商店外框、背景底板、标题栏、分隔线和插画区域独立底框；卡片自身保留底色、边界与购买 / 锁定按钮。

## 当前布局与操作

- 三卡共用最小尺寸 `184 × 306`，实际高度随字体与内容增长；分配宽度允许 1px 取整差异。
- 浮层最大宽度 640px，顶距 104px；小窗口限制高度并保留纵向滚动，地图始终使用完整视口。
- 卡面展示序号、卡名、属性、透明底插画、卡种、购买价格与锁定操作。购买、锁定按钮上下排列。
- 鼠标停留同一卡面 0.4 秒后显示详情；移出或换卡时清除详情并重新计时。
- `1 / 2 / 3` 购买、`R` 刷新、`Tab` 收起，沿用既有输入接线。
- 商店内隐藏刷新 / 收起工具栏、预算条、拆塔与受损塔处置工具组；保留内部绑定，未改玩法意图与数值。
- 已购建筑仍在底部建筑背包展示和拖放；放置模式关闭商店。
