# 怪物图鉴

主菜单新增「怪物图鉴」，与卡组图鉴并列。支持鼠标点击、主菜单方向键选择后 Enter 进入；图鉴中点击「返回主菜单」或按 Esc 返回。滚轮浏览全部内容，重新进入时回到顶部。

图鉴公开 Rush / Swarm / Tank 三种基础原型，展示外观、定位、生命与速度倍率、对建筑基础秒伤、物理及魔法抗性和应对建议。精英单独说明为变体，不计为第四种基础原型。数值读取 monster_data / combat_types，不修改战斗、存档或解锁规则。

外观优先使用当前工作区的 machines_v1 怪物素材，素材缺失时回退到已有 sp_mon 贴图，不依赖未提交素材也可打开。

实现：scripts/ui/monster_library.gd；入口与页面切换：main_menu_overlay.gd。UI 样式专项覆盖四个菜单入口、图鉴切换与返回、三原型外观及属性、开始与退出信号。
