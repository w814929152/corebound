## 0. 结论前置

1. **56 个组合里只有 8 个能通 W20（14.3%），且全部含「霜序包」**。
2. 失败组合平均只到 **W15.3**，48 个组合 0 胜 —— 当前「纯建筑 + 无强化」的成长曲线
   **打不过 W15 之后的怪物 HP 增长**。
3. 原因不是"卡太弱"，是**缺成长引擎**：没有强化卡，塔只能靠「合成 +1 级」和
   触发建筑升级，而 `h^0.6` 的收益远追不上波次 HP 曲线。
4. 唯一跑通的引擎是**霜序包**（Drillmaster 每波全场 +1 级 + 大量减速），
   它给出的"免费等级"正好补上成长缺口 —— 说明**触发建筑是目前最有效的成长手段**。

## 3. 解读

### 3.1 为什么只有霜序包能赢

霜序包 = `Icicle · Drillmaster · Glacier · Hail · Permafrost · Frostbite`
—— 一个「整备（每波全场 +1 级，封顶 3）」+ 五个减速塔：

- **整备 = 免费等级**：2 波内全场 3 级（`h^0.6` → 1.93×），等于每座塔白拿 2 次合成；
- **减速 = 有效 DPS**：`slow` 直接拉长怪物在射程内的时间，等效输出翻倍；
- 两者叠加 → 只有这一包能把 W20 的 HP 曲线压住。

其他包缺其中一环：要么没有成长（无触发塔），要么纯输出没有控制。

### 3.2 这说明什么

- **触发建筑（登场/整备/阵亡）是目前唯一有效的"建筑内成长"**，方向是对的；
- **但只有 3 张触发建筑、且分散在 3 个包里** → 3 选 3 时最多拿到 1 张，
  大部分组合拿不到成长引擎；
- **减速的收益远高于同价位 dps**（霜序 5 塔全带 slow）→ 其他包需要
  等价的"等效输出"手段，否则永远是下位选择。

## 4. 建议的下一步（待拍板，不在本报告内改数）

1. **触发建筑扩容**：每个包至少 1 张触发建筑（8 张），让任何 3 包组合都有成长引擎；
2. **给非霜序包补"等效输出"**：射程（远程覆盖）/ 群伤（多目标）/ 真实（无视抗性）
   需要换成可量化的等效收益，否则减速一家独大；
3. **调 `tower_stack_exp` 或合成成本**：`h^0.6` 在无强化卡时太慢；
4. **把实时钩子纳入 MC**：用 `WaveDirector` 跑实时 MC（慢，但能测 DoT/光环/击杀升级）。
