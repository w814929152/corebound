## 0. 结论前置

1. **56 个组合里只有 8 个能通 W20（14.3%），且全部含「霜序包」**。
2. 失败组合平均只到 **W15.3**，48 个组合 0 胜 —— 当前「纯建筑 + 无强化」的成长曲线
   **打不过 W15 之后的怪物 HP 增长**。
3. 原因不是"卡太弱"，是**缺成长引擎**：没有强化卡，塔只能靠「合成 +1 级」和
   触发建筑升级，而 `h^0.6` 的收益远追不上波次 HP 曲线。
4. 唯一跑通的引擎是**霜序包**（Drillmaster 每波全场 +1 级 + 大量减速），
   它给出的"免费等级"正好补上成长缺口 —— 说明**触发建筑是目前最有效的成长手段**。

## 3. 解读

### 3.1 为什么只有霜序包能赢

霜序包 = `Icicle · Drillmaster · Glacier · Hail · Permafrost · Frostbite`
—— 一个「整备（每波全场 +1 级，封顶 8）」+ 五个减速塔：

- **整备 = 免费等级**：8 波内全场 8 级（`h^0.6` → 3.48×），等于每座塔白拿 7 次合成；
- **减速 = 有效 DPS**：`slow` 直接拉长怪物在射程内的时间，等效输出翻倍；
- 两者叠加 → 只有这一包能把 W20 的 HP 曲线压住。

其他包缺其中一环：要么没有成长（无触发塔），要么纯输出没有控制。

### 3.2 这说明什么

- **触发建筑（登场/整备/阵亡）是目前唯一有效的"建筑内成长"**，方向是对的；
- **但只有 3 张触发建筑、且分散在 3 个包里** → 3 选 3 时最多拿到 1 张，
  大部分组合拿不到成长引擎；
- **减速的收益远高于同价位 dps**（霜序 5 塔全带 slow）→ 其他包需要
  等价的"等效输出"手段，否则永远是下位选择。

---

## 4. 建议的下一步（待拍板，不在本报告内改数）

1. **触发建筑扩容**：每个包至少 1 张触发建筑（8 张），让任何 3 包组合都有成长引擎；
2. **给非霜序包补"等效输出"**：射程（远程覆盖）/ 群伤（多目标）/ 真实（无视抗性）
   需要换成可量化的等效收益，否则减速一家独大；
3. **调 `tower_stack_exp` 或合成成本**：`h^0.6` 在无强化卡时太慢；
4. **把实时钩子纳入 MC**：用 `WaveDirector` 跑实时 MC（慢，但能测 DoT/光环/击杀升级）。

## 7. 追加：弹射机制上线后复跑（2026-11-07）

**弹射**：电弧系六座塔的子弹可跳弹（`bounce` 1~2 次），聚合池口径下每次跳弹 +20% 等效输出
（池子本就把溢出伤害顺延到下一只怪，跳弹 = 一发打多只的放大）。卡面第 3 行写「弹射 N 次」。

复跑读数：

| 口径 | 通关率 | 平均波次 |
|---|---|---|
| 仅赏金 | 10 / 56 = 17.9% | W15.70 |
| **赏金 + 弹射** | **10 / 56 = 17.9%** | **W15.79** |

胜率没变、平均波次 +0.09 —— 弹射只是把电弧包的单点输出抬了一档，**没有补上成长缺口**。
结论与 §4 一致：真正的瓶颈是「无强化路线缺成长引擎」，不是单塔输出。

## 8. 追加：触发升级上限 3 → 8 后复跑（2026-11-07）

## 9. 追加：贯穿机制上线后复跑（2026-11-07）

**贯穿**：穿刺系五座塔（Lance 2 / Javelin 1 / Ballista 3 / Sniper 2 / Harpoon 1），
聚合池口径下每穿透一个敌人 +25% 等效输出；卡面写「贯穿 N 个」。

| 口径 | 通关率 | 平均波次 |
|---|---|---|
| 赏金 + 弹射 | 10 / 56 = 17.9% | W15.79 |
| **+ 贯穿** | **11 / 56 = 19.6%** | **W16.50** |

贯穿比弹射更有效（+1 胜场、平均波次 +0.71）：穿刺系本来射程就长（26~34），
穿透等效输出直接吃到「长射程 + 多目标」的双重收益。方向验证：
**给长射程塔补多目标 = 有效的等效输出**，符合 §4「非霜序包补等效输出」的建议。

## 10. 追加：攻速光环上线后复跑（2026-11-07）

**攻速光环**：`Drummer 战鼓`（由原 `Cleave` 改造）= **附近塔攻速 +20%**（可叠，封顶 +60%），
聚合口径等价于全场 dps ×(1+Σ)。卡面写「攻速光环 +20%」。

| 口径 | 通关率 | 平均波次 |
|---|---|---|
| + 溅射 | 11 / 56 = 19.6% | W16.75 |
| **+ 攻速光环（策略会买 Drummer）** | **14 / 56 = 25.0%** | **W17.13** |

这是目前**单条机制里提升最大的一次**（+5.4pp / +0.38 波）：
攻速是**乘全队**的，比「多一个目标」的线性加成更能放大已经成型的输出。
方向确认：**团队乘区（攻速/攻击）> 单塔多目标**，与 §4 的「补等效输出」建议一致。

## 11. 追加：伤害类型转换上线后复跑（2026-11-07）

**相位塔**（三张，替代原 Mortar / Harpoon / Frostbite）：
`Kinetic`→物理、`Arcane`→魔法、`Purity`→纯粹。自身不攻击，把**最近的一座塔**转成指定类型
（按格心距离取最近，同距离取索引靠前 —— 确定性）。

| 口径 | 通关率 | 平均波次 |
|---|---|---|
| + 攻速光环 | 14 / 56 = 25.0% | W17.13 |
| **+ 伤害类型转换** | **14 / 56 = 25.0%** | **W17.59** |

胜率不变、平均波次 +0.46：转换不增加 dps，价值在**改抗性分布**
（把物理塔转成魔法去打 Tank，或转纯粹绕过抗性）——对最终通关是"质变"而非"量变"。
⚠️ 注意：MC 的 `combat_types_enabled` 默认关闭，本读数**没有真正吃到抗性收益**；
实机（`boot.gd` 全开）里转换的价值会更高。

## 12. 追加：死亡爆炸（2026-11-07）

**Pyre 火葬**：阵亡时对**半径 6.0** 内的敌人造成 **40 点真实伤害**（无视抗性），
在 `wave_director` 的阵亡分支里结算（与「阵亡 +1 级」同一时机，先加等级再爆炸）。

- 🔴 只在实时战斗生效：批处理镜像（MC/金标本）不执行死亡分支 → 本机制**不进 MC 读数**；
- 🔴 金标本的塔没有 `death_blast` 字段 → 不触发，逐位不变；
- 卡面写「阵亡：爆炸 40」。

⚠️ 这意味着当前 MC 的 14/56（25%）**又一次低估**了实机：
登场/整备/阵亡爆炸/觉醒/回复/DoT/击杀升级/伤害转换都是实时钩子。
建议下一步做一版**实时口径 MC**（`WaveDirector` 驱动），否则这些机制的价值永远无法进入读数。

## 13. 追加：召唤小兵（2026-11-07）

**Necro 亡灵塔**（原 `Abyss`）：每波开始召唤 **2 个游魂**（8 dps / 存活 10s / 移速 6），
游魂自动追最近的敌人、贴身后持续攻击（无视抗性），击杀同样触发打击杀链。

- 实现：`wave_director._spawn_summoned()`（波首生成，围绕塔心错开）、
  `_update_minions(dt)`（子步移动 + 攻击）、快照新增 `minions` 供渲染层画青蓝小点。
- 🔴 只在实时战斗存在：批处理不生成 `minions` → 金标本 / MC 零扰动，也**不进 MC 读数**。
- 卡面：`召唤游魂作战 / 伤害 3 · 射程 18 / 标记：真`。

至此实时钩子清单：登场、整备、阵亡升级、死亡爆炸、召唤、觉醒、回复、DoT、击杀升级、伤害类型转换。
**MC 的 25% 仍是不含这些机制的下界** —— 实时口径 MC 的优先级进一步提高。
