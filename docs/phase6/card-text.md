# 卡面信息补全轮 · 让每张卡自己回答「这张卡干什么」

> 触发：玩家反馈 **「我不知道建筑卡的描述，和效果卡的描述」**。
> 结论：不是玩家没看，是**界面上根本没有这段信息** —— 商品位只有「卡名 + 卡种」两行，
> `Cannon` 和 `FireUp` 除了名字不同，卡面上没有任何东西能区分它们的作用。

---

## 1. 改造前的实测缺陷

| # | 缺陷 | 证据 |
|---|---|---|
| 1 | 商品位**只有卡名与卡种**（`建筑卡` / `单塔效果卡` / `全局效果卡`），无任何效果说明 | `shop_overlay.gd` 的 `_slot_note` 只写**条件事实**（H2 协同 / H4 已达上限 / H5 层数 …），无卡时为空串 |
| 2 | 「买完要去哪」完全缺失 | 买了建筑卡进 `待放置队列`，但没有一句话说「要再进安全窗点塔位落子」 |
| 3 | 强化卡「强化谁」不可知 | `FireUp` 只对 `tag=fire` 的塔生效（当前仅 `Cannon`），tag 是内部英文标识，玩家看不到任何提示 |
| 4 | 「同卡再买 = 层数 +1」这条核心叠层规则无提示 | `ShopAI.apply_action` 有此逻辑，UI 未表达 |

## 2. 交付

### 2.1 新增 `scripts/data/card_text.gd`（纯文案层，**只读**数值 SSOT）

- **不往 `TowerData` 加字段**：`TOWERS` / `REINF` / `PRICE` / `CARD_NAMES` 是金标本逐位对齐的数值 SSOT
  （control-manifest §1），任何字段增删都要走 ADR + 重签基线。本文件对它们只读不写。
- **数值全部现场派生**：`stat_line()` 从 `TOWERS` / `TOWERS_EXT` 现取 `dps` / `rng`，
  改数值 → 卡面自动跟随，不可能出现「卡面写 dps 10、引擎跑 11」。
- **「可强化」也派生**：`hosts_of_tag()` 遍历两张塔表按 tag 筛选，
  以后新增同 tag 的塔会自动出现在强化卡的点名里，不会漏。
- **三行结构**（每张卡恒定 3 行，三个位等高同构 → X3）：

  | 卡种 | 第 1 行 | 第 2 行 | 第 3 行 |
  |---|---|---|---|
  | 建筑卡 | 机制（溅射 / 减速 / 单体） | `伤害 7 · 射程 18` | `标记：火` |
  | 单塔效果卡 | 强化「火」系塔 | `可强化 Cannon` | `同卡再买叠层` |
  | 全局效果卡 | 提高废料收入 | `每层 +20% 废料` | `占1槽，上限3层` |

### 2.2 版式硬约束（实测数字，非估算）

商品位**实际内宽只有 155px**：

```
抽屉 614.4（= 1920 × 32%）
 − 面板内边距 32
 − 抽屉边距 36
 − 卡片间距 20
 = 526.4 ÷ 3 = 175 卡宽
 − 卡片内边距 20 = 155px 文字宽
```

16px 汉字 ≈ 16px/字 ⇒ **一行只放得下约 9 个汉字**。

> 🔴 第一版没数这 9 个字，文案写到 14 字，结果 `Cannon` 的描述块从 3 行涨到 **7.3 行**
> （实测 `size.y = 153px`），把卡片从 340 撑到 379，
> 并出现「溅/射」「窗/落子」这种在词中间断行的难看效果。
> 现在 `run_ui_style_asserts.gd` §I 有一条 **「每行 ≤9 汉字」** 断言把这件事钉死。

### 2.3 购买流程提示（`FLOW_HINT`，放在三张卡下方）

同一卡种的三张卡流程完全一样，写进卡面等于三条重复文案白占三行高度。
改为在卡片下方按卡种说一次（三行，每行 ≤30 汉字，避免孤字尾行）：

```
建筑卡：买后进待放置队列，安全窗内点塔位落子
单塔效果卡：投给点选的塔（未选投主塔），同卡再买叠层
全局卡：买入立即生效，占 1 个全局槽
```

### 2.4 `shop_overlay.gd`

- 新增 `_slot_desc`（恒 3 行 = 75px，`custom_minimum_size` 固定 ⇒ 三位等高的根因）
- 层级：序号 → 卡名 26 → 卡种 → 价格 20 → 分隔线 → **描述**（正文色）→ 备注（辅助色）→ 按钮
  - 描述用 `C_TEXT`、备注用 `C_TEXT_DIM`：前者是「这张卡干什么」的正面信息，后者只是条件事实
- `SLOT_SIZE` 244 → **352**（实测内容高度，非拍脑袋；`run_slice4_scene_smoke.gd` 改为一律从该常量派生，
  不再手抄第二份数字 —— 上一轮就是因为手抄，实现改了测试忘改，静默 45/46）
- 备注 `custom_minimum_size` 42 → 0：无事实时不占高度，交给 `gap` 吸收，按钮仍贴底

## 4. 不做 / 已知边界

| # | 项 | 原因 |
|---|---|---|
| 1 | 卡面写**精确的强化倍率**（每层 ×1.06） | 155px 放不下；且 `reinf_compound` 是 `A:1.10 / B:1.06` 双路径参数，卡面写死一侧会误导。放在 `docs` 与 F3 面板。 |
| 2 | 卡池**稀有度 / 蓝图风** | 与 `ui-polish.md` §4 第 2 条同一缺口，需先有稀有度字段。 |
| 3 | 鼠标悬停弹 tooltip 补充长文案 | 需要新增一层 tooltip 系统（Z 序 / 跟随 / 触摸屏兼容），另批。当前 3 行已覆盖「能不能买、买了干什么、买完去哪」。 |
