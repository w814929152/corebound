# 怪物攻击建筑

正式游戏入口开启 `WaveDirector.structure_attacks_enabled`。从第一波起，怪物行进至附近防御塔的仇恨范围时停下攻击；目标停机、拆除或离开退出范围后恢复行进。锁塔精英也需进入攻击范围，不能隔图扣血。

没有防御塔可攻击时，怪物沿原路线接近核心，在距核心 3 世界单位处停下持续攻击。怪物不会因抵达核心而消失；仍可被击杀，存活攻核怪会阻止波次提前结束。核心附近新建防御塔可以吸引其转移目标。

伤害按战斗子步持续结算，基础每秒伤害为 20，乘怪物原型的 `M_DPS`；锁塔精英对塔保留精英倍率。参数集中在 `monster_data.gd`，不再使用历史攻塔的高损耗系数。当前参数为可玩的初始值，尚未完成整局平衡调优。

完全冻结阻止攻塔和攻核；解冻后继续攻击。防御塔归零复用现有停机、阵亡触发、复活和维修流程。核心伤害同步到玩家状态，归零仅发送一次失败事件。准备阶段不产生攻击。

画面显示短暂攻击方向线、核心受攻圈和受损防御塔生命条，均复用战场镜头坐标。地图拖动和缩放不改变攻击判定。

历史模拟默认关闭新开关，保留原有漏怪扣血及起手保护口径。专项验证为 `tests/run_structure_attacks_asserts.gd`；窗口模式生成 `art/_review/monster-structure-attacks.png`。
