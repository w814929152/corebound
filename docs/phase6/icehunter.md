# 碎冰猎手

新增霜序包建筑 `Icehunter`。优先攻击射程内 `frozen_remaining > 0` 的单位，组内沿用原有威胁顺序；没有冻结目标时正常攻击。

对完全冻结的目标不计算任何抗性，包括经相位塔转换伤害类型后的物抗、魔抗。只有冰冻层数或减速、但未完全冻结的敌人正常计算抗性。击杀后剩余伤害继续在射程内按上述优先级结算，并保留原有冻结死亡冰暴。

初始参数：基础伤害参数 7、攻速 0.8、射程 22、单体魔法、冰 tag，抽取权重 0.08。不附加冰冻，需要其他控制塔配合。参数是可玩初值，未做平衡校准。

只接入玩家战术战斗，不修改金标本模拟器与 AI 卡池。霜序包增加至 11 张，全建筑卡 82 张。

验证：`tests/run_icehunter_asserts.gd` 覆盖优先级、两类抗性、解冻、射程、溢出与逐塔实际调用；已接入默认回归。
