# 玩家关卡攻击范围

首轮全卡配置覆盖 85 张建筑卡。半径使用战场单位，角度指完整扇角。合成成长次数只计算同卡落子；登场、击杀、整备等机制额外增加的塔等级继续按各自规则结算。

圆形塔适合守核心和多入口，近中程扇形塔用更宽的角度扫入口，长射程扇形塔沿通道布置。延程塔和展域塔在合成上限之外提供光环加成，扇角最多 360°。普攻与溢出伤害都遵循有效范围。溅射、弹射、引爆、死亡爆炸和召唤继续使用各自的机制。

本版将普攻基础半径在首轮配置上提高约 20%，按最接近的整数取值。基准模拟仍使用原始射程表。
