## 4. 需要拍板的一件事

**卡面 14px 与 §9.1「玩家可见文本 ≥16px」冲突。**

- 14px Noto Sans SC 行高 24，两行 48；若用 16px，两行 48–50，加上 28px 卡名（行高 41）
  与类型条，信息区需要 113px = 卡高 33%，与「信息区约 30%」直接冲突。
- 当前选择：**按说明走 14px**，代价是 §9.1 P0 出现唯一例外（已在
  `run_ui_style_asserts` 与该测试注释、设计文档 §11.2 三处标注）。
- 若不批：`CARD_DESC_LINES = 1`、类型/摘要字号改 16、面板高度回 92，
  一条命令即可回退（`_make_slot` 三处数字 + 一次 `gen_card_frame_v3.py`）。

## 5. 待确认（本轮假设）

1. 摘要取 `describe()` **前两行**（第 1 行身份、第 2 行数值），完整 3 行机制仍在悬停详情。
2. 说明里的「箭塔插画以弩身和箭头为裁切焦点」：全幅卡面统一走 `COVERED` 居中裁切，
   未对单卡做焦点偏移；若要逐卡焦点，需要一张 `focus` 参数表。
3. 「卡包名如需展示则单独从卡包数据读取」——本轮卡面仍只显示「建筑 · 类型」，未加包名。
4. 类型文案取 `card_text.tag_cn()`（如「建筑 · 常规」），未采用说明配图里的「泛用」字样。

  （卡名 28 / 类型 14 / 摘要 14×2 / 插画窗 8,8,194,220）；不接价格、锁头、悬停与购买。
