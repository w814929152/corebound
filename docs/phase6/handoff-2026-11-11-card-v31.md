## 2. 卡面 v3.1 细修（摘要）

完整规格见 `design/art/card-redesign-2026-11-11.md` §10，这里只列会影响后续维护的点。

### 2.1 顶栏做减法
- **删除编号 `01`**：它原本唯一的作用是「按 1 买第 1 位」的位置提示，功能没了就不再需要。
- **删除稀有度 `▲×N` 角标**：5 档时 5×16px 会顶到锁头。
- **稀有度第二通道改为描边线宽**：新增 `ui_card_edge_v3_{1,2,3}.png`，按 `ui_style.RARITY.bw`（1/2/3）取图，
  悬停只换 `modulate` 青色、线宽不变 —— art-bible §2.3 的 `bw` 字段第一次真正落到 v3 卡框。
- **✓ 只在买不起时变成 ✗**（费用胶囊左侧 124px）：可购状态不再挂常驻对勾，顶栏只剩锁头 + 费用胶囊。
- 锁头从左中（x=86）移到**左上 (14,8)**；顶部深底由「194 整条带」缩为 **92×24 渐隐芯片**。

### 2.2 卡框细节（贴近参考图）
- 四角 L 形**双刻线**（偏移 3.5 / 6.3px）；侧边**双青斜纹**；顶部正中**青梯形刻口**。
- 中缝六边形**两侧加青箭头**；**底部青刻口改为跨在面板下沿**（y 324.6–331.4，一半米白一半框带）——
  既与参考图一致，也不会被卡底裁切（v3 的刻口压在框带边缘，实机被切掉一半）。
- 外层米白双描边（α155 / α210），内轮廓内收到 6.6。

### 2.3 信息区排版
| 元素 | v3 | v3.1 |
|---|---|---|
| 卡名 | 28px @ (16,242,178,30)，`clip_text=true` | **30px @ (16,232,178,54)**，`clip_text=false` |
| 类型条贴图 | 142×18 @ (34,278) | **194×20 @ (8,275)**，横线贯穿面板 + 两端青斜纹「//」 |
| 类型文字 | 16px @ (34,276,142,18) | 16px @ (54,268,102,34) |
| 描述 | 16px @ (16,296,178,20) | **17px @ (16,294,178,34)**，色 `#282D37`（比卡名柔一档） |

- 🔴 **标签高度必须 ≥ 字体行高**：实测 Noto 16px 行高 24 / 17px 25 / 30px 44。
  v3 把 18px 高的 Label 开 `clip_text=true`，字形上下被矩形削掉（实机可见）。v3.1 给足高度并关闭 `clip_text`，
  宽度仍由 `OVERRUN_TRIM_ELLIPSIS` 负责。
- 描述与类型条的间距按参考图实测比例（标题字心 y≈259 / 条 285 / 描述 308）。

### 2.4 结构性修复：卡位不再横向拉伸
v3 用 `SIZE_EXPAND_FILL`，实机在 1920 宽抽屉里把卡拉到 **221px**，而卡面所有层按 210 绝对坐标摆 →
右侧 11px 空气、框线与底部刻口与卡边错位。
v3.1 改 `SIZE_FILL`（固定 210）+ `slots_row.alignment = CENTER`；实测 `slot rect = (210, 340)`。
