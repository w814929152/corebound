# 准备阶段恢复与移位

- 玩家进入准备阶段时，全部防御塔解除停机并按当前等级、防御光环恢复满血；基地恢复到既有最大生命值。
- 失败结算不复活基地、不恢复建筑；已结束的局不能通过拖拽继续操作。
- 准备阶段按住已部署防御塔并拖动，松手后吸附到合法空格。不消耗废料，不改变等级、附加卡、投资额、塔数量或塔位编号。
- 基地不是可拖拽塔，核心禁建区仍禁止落子。已有塔、障碍、地图外以及 UI 区域均不能接收移位；非法落点保留原位置。移位不会触发同格升级。
- 拖动时显示半透明塔和青/红落点提示。Esc 取消，开始战斗也会取消拖拽；战斗中不能移位。地图平移、背包拖放仍使用各自原有交互。
- 玩家战斗场景启用 `ShopRuntime.preparation_actions_enabled`；直接实例化运行时默认关闭，保留历史模拟及测试基线。恢复只在准备阶段调用，地图移动由接线层接收意图后交给运行时验证并执行。
- 基地恢复同时同步 `WaveDirector.core_hp`，避免下一波受伤使用旧血量。准备期新放置/升级塔后也刷新血量。
