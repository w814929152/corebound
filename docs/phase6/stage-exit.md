# 关卡内退出（2026-11-10）

准备阶段、战斗中、商店和放置模式均可点击右上方「退出关卡」。确认弹窗暂停战斗与商店预算，Esc 或「继续游戏」恢复原有状态。点击「放弃本局」返回航图，关卡系统关闭时返回主菜单。准备阶段可选择「保存并退出」回主菜单。

主动放弃不触发胜负结算、不发放余烬或解锁奖励；永久进度保留，本局构筑在重新挑战时重建。确认期间屏蔽战斗快捷键，关卡外与结算时隐藏退出入口。

暂停仍由 `time_director.gd` 唯一写入引擎；`shop_controller.abandon_run()` 停止战斗，`boot.gd` 负责返回选关及新局恢复时钟。退出入口在商店按钮下方，避免遮挡原有操作。

主菜单的「继续游戏」显示存档的关卡与下一波。存档保存所选卡包、波表难度、几何槽位、塔和玩家状态、商店和背包、随机数状态。准备阶段的拖拽和选择会在恢复时重置。每个游戏存档有独立的待续关卡记录。三个槽位及当前槽位一并写入 `user://profiles.save`，写入时先生成同目录临时文件。首次升级会把旧关卡进度、卡包进度及待续记录导入存档 1。开始新关卡会清除当前槽位的待续记录，继续游戏会取出该记录。

`tests/run_stage_exit.gd` 验证暂停、取消、放弃和重新进关。`tests/run_run_save.gd` 验证存档写入失败、界面入口和波次恢复。两者都在 `world` 门禁中。

初次验证：退出专项 11 项通过；world 12 套通过（15.1 秒）；五态时钟 slice3 142 项通过；1280×720 窗口渲染已检查。

2026-11-10 收口复验：本功能已包含在默认完整回归中，退出码 0，world 12/12 PASS（20.1 秒）。Godot 退出仍有既有资源清理警告。
