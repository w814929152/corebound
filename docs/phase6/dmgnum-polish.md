# 伤害数字显示优化（A2 · 2026-11-07）

> 范围：`scripts/ui/vfx_layer.gd`（A2 段）+ `tests/run_vfx_cache_guard.gd`（容器判据 7→8）
> 性质：**纯表现层**。零玩法写入、零新信号、零 snapshot 变更、零 `time_scale`、零运行时 `instantiate`。
> 规格：`vfx-art-spec.md` §2.1–§2.4 全部保留，新增 §2.5「同怪续喂」。

---

## 1. 症状（改前实拍 + 探针）

`docs/phase6/shots/ad-vfx-combat.png` 里，右上角一只怪周围散着 6 个「1」。
受控探针（`tests/probe_dmg_visual.gd`，22 dps）复现：

```
[dmg-probe] before-02.png  dmg=7
  2(912,216) 2(816,168) 2(912,264) 2(912,168) 2(1008,168) 2(816,216) 2(912,168)
```

**同一只怪、同一数值、7 个数字同时在场**，按 96×48 网格排成一片 3×3 —— 读不出任何信息，只剩噪点。

## 2. 根因（三条叠加）

1. **每 tick 铺一格**：玩法是 hitscan **连续结算**（`_WaveSim.DT = 0.1s`，`wave_director._substep ②`），
   每 0.1s 单怪掉一次血。逐帧差分 ⇒ 每 0.1s 新建一个数字；`DMG_LIFE 0.7s` ⇒ 同屏 **7 个**。
2. **网格螺旋外扩 = 均匀铺满四周**：旧 `_find_free_cell` 从半径 1 圈开始按 `dx/dy` 扫描，
   同怪连续 tick 依次占掉右、左、上、下 —— 视觉上数字像"从怪身上炸开"。
3. **`_merge_dmg` 会搬位置**：聚合时 `e["base"] = sp`，把旧数字瞬移到新伤害点（违反 §2.2 禁乱飞），
   且文本只留 `×N`，**丢掉了唯一的数值信息**。

## 3. 改动

| # | 改动 | 口径 |
|---|---|---|
| 1 | **同怪续喂** | 同一 `index` 的活跃数字在 `life ≤ 0.45s` 内被新伤害累加；`age > 1.0s` 断代，在怪的新位置重开 |
| 2 | **主文本 = 累计伤害** | `_fmt_dmg(amount)`；`×N` 降为右上角小标（次数）——§2.3 语义保留、数值不丢 |
| 3 | **网格上方优先** | 固定偏移表排序：正上 → 斜上 → 两侧 → 下方（无随机、帧间可复现） |
| 4 | **聚合不搬位置** | `_merge_dmg` 保留原 `base`；距离 > 140px 直接丢弃，不跨屏瞬移 |
| 5 | **格子与寿命同步** | 数字死亡即 `erase(cell)`（旧实现按 `_vfx_t + DMG_LIFE` 批量过期 → 续喂延长寿命后格子会提前空出，同格叠字） |
| 6 | **小数值保底** | `_fmt_dmg` 的 `round(0.4)=0` → 显示「0」；改 `maxi(1, ...)` |
| 7 | **数值格式** | `<1k` 整数 / `1.2k` / `12k` / `1.5M`（去尾 `.0`） |
| 8 | **手感** | 低档轻弹 ×1.06 · 续喂脉冲 +5%/0.1s · 上浮随档位递增 · 淡出起点 0.62 · 基线按基准档固定（升档不跳） |
| 9 | **PATH 守卫** | 新增容器 `_dmg_by_owner` 纳入「判据 ≡ 动作」（8 容器） |
