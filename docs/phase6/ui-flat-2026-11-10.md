# 界面「少边框」重排与焚星塔充能口径 · 2026-11-10

本批把 11 月 10 日的界面改版与焚星塔充能口径一并收口。设计来源见 `design/ui/battle-ui-spec-v1.md`（§0.5 v3「少边框」修订）与 `design/ui/battle-ui-mockup.html`；本文只记落地口径与验证，不重复设计说明。

## 风格方向

用户拍板：**尽量减少边框，只保留文字，或用色块**。落地为两层职责，互不越界：

- `ui_style.gd`（菜单 / 选关 / 选包 / 结算 / 弹窗）：`_base()` 统一零描边，层级靠色块明度差；面板保持半透明深底，按钮改**底色块染色**（primary 金块 α0.16 / normal 青块 α0.12 / danger 红块 α0.14 / unavail 暗块 / ghost 保留下划线）。九宫格 `ui_btn_*`、`ui_panel_9slice` 贴图自带烘焙描边，一律停用，回落纯色 StyleBoxFlat。
- `battle_theme.gd`（关卡内 HUD / 卡片 / 浮层）：底色块全部透明、阴影移除，层级只靠**文字颜色 / 字重 / 位移**。悬停浮卡取消底块，改**深色文字描边**（outline 6px）保证压在战场或插画上仍可读。
- 四角 L 刻线停用：选包、结算、选关画布与详情卡四个调用点移除；HUD 内 2px 强调下划线保留（线不是框）。
- 稀有度不再走边框：卡面底色按稀有度色 `lerp 0.08` 微染 + 既有 ▲ 数（1–5）双通道；可购性 = 底色提亮 0.05 + ✓/✗ 字形 + 价格色。

## 布局与交互

- **商店**：三张竖版卡 184×306 → **210×340**（X3 恒等），浮层宽 640 → 700、上移到 y=88；决策预算 / 刷新 / 模式徽标从「两个隐藏、一个挤在标题行」收拢成卡组下方**一行信息带**，并新增一行选牌提示。购买由底部按钮改为**点击整张牌面**，锁头是卡面右上角独立热区（点锁头只切换锁定，点插画穿透到牌面）。README 的操作表同步。
  - 接手修（20:5x）：取消底部「购买」按钮后，价格行在 `_make_slot()` 里仍是默认 `hide()`，`_refresh_shop()` 又漏了 `show()` → 实机三张卡**完全看不到售价**。已在有货分支补 `_slot_price_row[i].show()`，回归截图 `art/_review/shop-portrait.png` 可见 `✓ ◇ 12 分`。
- **航图节点 = 场景缩略卡**：新增 `STAGE_SCENE_TEX`（十关 → `art/2d/stages/stage_scene_<关>_1_v*.png`），缩略卡 88×55、下压符号垫深色底衬保证可读；贴图缺失（headless / 未导入）逐节点回退原六边形，与贴图前逐位一致。生成提示词见 `design/art/stage-scene-prompts-v1.md`。
- **放置模式徽标**：波次仪表下方显示 `时间 × <倍率> · 部署中`，倍率只读 `TimeDirector.snapshot()`，不直写 `time_scale`；星紫语义由文字颜色承担（零描边）。
- **核心 HP**：底槽承托块透明，段位本身即编码；段碎裂演出由闪白改**警报红**、0.18 → 0.30 s（与 ≤25% 告警同色）。
- **背包**：悬停芯片整体上浮 3px，命中判定仍用原矩形（避免悬停抖动）。

## 焚星塔充能口径

充能事件从「每次火焰附加、按命中敌人数计数」改为「**每次火焰十层引爆充能一次**，与命中敌人数无关」，上限 **12 → 10**。文案、卡池表与断言同步：`card_text.gd`（机制行 / 详情）、`card-catalog.md`、`fire-charge-tower.md`、`run_fire_charge_asserts.gd`、`run_card_description_asserts.gd`。

> ⚠️ `fire_charge` 是数值口径，按 AGENTS 硬约束 2 属需拍板项。本批只如实记录已落地的 12 → 10 与触发事件变更，**待平衡侧确认**；若要回退，改 `building_card_params.gd` 的 `Pyroclasm.fire_charge` 与相应断言即可。
