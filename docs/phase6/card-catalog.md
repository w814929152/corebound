# 《守核 Corebound》卡牌图鉴

> **版本**：v1.3 · 2026-11-08 ｜ **范围**：当前玩家卡池 80 张建筑卡 + 16 张旧效果卡附录 ｜ **数据源**：`scripts/data/tower_data.gd` / `card_packs.gd` / `combat_types.gd` / `card_text.gd`（只读）

## 0. 速览

| 项 | 值 |
|---|---|
| 建筑卡 | **80 张**（8 包 × 10 张，一卡一包） |
| 每局选包 | **8 选 3** → 本局卡池 **30 张** |
| 价格 | 建筑卡 **12 废料**；新建与同格升级同价 |
| 有效 DPS | **= 表内 `dps` × `attack_speed`**（Arrow 80% / Cannon 70% / Frost 65%，其余 100%） |
| 等级成长 | `DPS = base × h^0.6`；`HP = 120 × h^0.6` |
| 塔数上限 | **10 座**（当前自由摆放）；旧金标本 6 槽 |
| 攻击类型 | 物理 / 魔法 / 真实（真实无视抗性） |
| 特殊升级 | 登场 / 整备 / 阵亡 / 击杀，封顶 **Lv8** |
| 旧效果卡 | 16 张（14 强化 + ScrapUp + RerollD），**当前未投放** |

> 🔴 **读表提醒**：`群伤` / `减速` 是卡面设计标签；当前引擎把它们折算成 **AoE 密度乘区** / **Aux 挂件乘区**，不是逐次溅射或逐怪移速削减。
>
> 🔴 **v1.3 口径（2026-11-08）**：本表 `DPS` 列一律是**有效 DPS** = 伤害 × 攻速，与卡面「伤害 X·攻速 Y%」逐字同源（`card_text.stat_line`）。基础三塔因此下调：箭塔 10.0→8.0、炮塔 7.0→4.9、霜塔 5.0→3.3；其余塔攻速 100% 不变。泛用包均值 5.4→4.8、最高 10.0→8.0。

## 3. 属性与公式

### 3.1 全局规则

| 项目 | 值 | 说明 |
|---|---|---|
| 建筑卡价格 | 12 废料 | 新建与同格升级同价；`wave_price_step = 0` |
| 每局卡包 | 8 选 3 | 当前 8 包全开 |
| 每包张数 | 10 张 | 一卡一包；80 张不重不漏 |
| 本局卡池 | 30 张 | 3 包 × 10 张，无跨包重复 |
| 塔数上限 | 10 座（当前） | 自由摆放；旧金标本 6 槽 |
| 常规升级 | 同名同格 +1 级 | 无硬上限 |
| 触发 / 击杀升级 | 封顶 Lv8 | Vanguard / Drillmaster / Martyr / Null |
| 拆塔 | 返还 50% 累计投入 | 装配卡全销毁；仅安全窗 |
| 强化槽 / 全局槽 | 5 种 / 3 个 | 仅旧效果卡使用；当前建筑-only 卡池不占用 |

### 3.2 等级与成长

| 项目 | 公式 / 值 | 说明 |
|---|---|---|
| DPS | `base_dps × h^0.6` | h = 建筑卡层数（等级） |
| 塔生命 | `120 × h^0.6 × (1 + 防御光环)` | HP0 = 120；与 DPS 共用指数 0.6 |
| Lv1 / Lv3 / Lv5 / Lv10 HP | 120 / 232 / 315 / 478 | 未计防御光环 |
| Lv3 / Lv5 / Lv10 DPS 倍率 | ×1.933 / ×2.626 / ×3.981 | 相对 Lv1 |
| 觉醒 | Lv ≥ 3 → 自身 DPS ×1.3 | Pyre / Rift |
| Tag 层数 | Σ 该 Tag 塔的 h（+ 同 Tag 强化层） | 3 层起协同档 |
| 共鸣 | d ≤ 0.65(Ri+Rj) 且双方 h ≥ 3 | E_i = Σ(1+h_j) |

### 3.3 攻击类型与怪物抗性

| 怪物原型 | 物抗 | 魔抗 | 真实抗性 | 设计角色 |
|---|---|---|---|---|
| Rush（快速低血） | 0% | 20% | 0% | 快而脆，怕魔法 |
| Swarm（集群基准） | 0% | 0% | 0% | 基准怪，双抗为零 |
| Tank（高血慢速） | 30% | 0% | 0% | 铁甲重盾，物攻刮痧、怕魔法 |
| Elite（词缀） | 沿用宿主 | 沿用宿主 | 沿用宿主 | 只放大 HP，不额外加抗性 |

> 伤害公式：`实际伤害 = 原始伤害 × (1 − clamp(抗性, 0, 1))`；真实伤害无视抗性。

### 3.5 术语

| 术语 | 解释 |
|---|---|
| 建筑卡 | 放在塔位上的塔；同格同名再落 = 升级。当前卡池唯一卡种。 |
| Tag（标记） | 构筑流派：火 / 冰 / 穿甲 / 电 / 破甲 / 咒术 / 真；与攻击类型是两套维度。 |
| 中性塔 | Tag 为「无」的塔；不贡献 Tag 层数，但仍计入塔数、链接与共鸣。 |
| h / Lv | 塔的等级，等于该塔累计吃到的建筑卡张数。 |
| 群伤 | 设计标签；引擎折算为全局 AoE 密度乘区。 |
| 减速 | 设计标签；引擎折算为 Aux 输出乘区，不直接改怪物移速。 |
| 削抗 / 破甲 | 有效抗性 = clamp(静态抗性 − 破甲量, 0, 1)；只削到 0。 |
| 觉醒 | Lv ≥ 3 时自身 DPS ×1.3；Pyre / Rift 专属。 |
| 触发升级 | 登场 / 整备 / 阵亡 / 击杀时写 h；封顶 Lv8。 |
| 经济建筑 | 不攻击，按波结算废料；Foundry 每座 +15%。 |
