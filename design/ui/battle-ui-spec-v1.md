> 配套高保真交互稿：`design/ui/battle-ui-mockup.html`（三种状态可切换 + 设计标注开关）

## 0. 设计立场（为什么这么画）

现有战斗 HUD 的骨架（左上废料 / 顶中波次 / 右上按钮簇 / 右抽屉商店 / 左下背包 / 底中核心 HP）是对的，本次设计**不改骨架**，只做三件事：

1. **把主界面的蓝图语言补齐到战斗场景**：四角 L 刻线（`attach_corner_chrome`）、直角蓝图卡座、Tag 电路芯片、等宽数字——这些在选包 / 选关 / 结算界面已经是既定语言，战斗场景的波次模块、背包、HP 条尚未完全共享。
2. **信息层级对齐 §5.2**：数字 > 图标 > 文字 > 装饰。L0 读数（废料 / 核心HP / 波次）用大号等宽字；L2 说明文字全部 16px 辅助色。
3. **状态全通道表达**：可购性 ✓/✗、精英波品红预警、放置模式 0.25× 徽标、威胁边缘红光——每个状态至少两条通道（颜色 + 形状/亮度/位置），满足 §9.2 红线 1。

**零新色承诺**：本文引用的所有色值逐字来自 art-bible §2.2，与 `ui_style.gd` 常量一一对应，不含任何未登记色。

## 0.5 🆕 v3「少边框」修订（2026-11-10 · 用户拍板）

**方向：尽量减少边框出现，只保留文字，或用色块。** 本节推翻上文所有「描边 / 刻线」描述，冲突处以本节为准：

- **全部面零描边**：`ui_style._base()` 内部一律 `set_border_width_all(0)`（参数保留，API 兼容）。层级靠**色块明度差**：面板 `0.94` 深底 → 卡片亮一档 → 内嵌槽更暗。
- **第二样式层 `battle_theme.gd` 同步零描边**（实机截图发现战斗 HUD 还有描边残留——废料/核心面板的 1px 亮框来自这一层）：`panel()` 去描边保阴影、`card()` 稀有度底色微染（0.16/0.10）、`well()` 纯色块、`button()` 主按钮实心金色块 + 墨字。`hud.gd` 波次轨道白框、放置徽标星紫框一并移除。
- **九宫格贴图停用**：`ui_panel_9slice` / `ui_btn_*` 贴图自带烘焙描边，与新方向冲突，`panel()` / `button()` 一律回落纯色 StyleBoxFlat。
- **按钮五变体改底色块染色**：primary 金块(α0.16)+金字 / normal 青块(α0.12)+白字 / danger 红块(α0.14)+红字 / unavail 暗块+灰字 / ghost 保留下划线（线不是框）。
- **稀有度改底色微染**：卡面 `bg.lerp(稀有度色, 0.08)` 色块 + 既有 ▲ 数（1–5）双通道，替代稀有度边框。
- **可购性**：卡面底色提亮 0.05（色块）+ ✓/✗ 字形 + 价格色，三通道不变。
- **四角 L 刻线停用**：`attach_corner_chrome()` 三个调用点（选包 / 结算 / 选关）移除；商店 slot chrome 本就未显示。HUD 内 2px 短下划线（标题 accent）**保留**——它是强调线不是框。
- **mockup 已同步**：`.cr { display:none }`、`.panel/.cbd/.tag/.btn/.pslot/#hint/#slowbadge/#legend` 全部去边框，Tag 与按钮改染色块。
- 验证：uistyle 138 PASS / world 全 PASS / 全量回归见当日日志。

## 0.6 🆕 v4「仅文字」+ 分层收敛（2026-11-10 晚 · 用户两轮拍板）

1. **「去除背景，只保留文字」→ 收敛为分层口径**（用户：「恢复其他界面的按钮背景，只去掉关卡中界面的背景」）：
   - **`ui_style.gd`（菜单 / 选关 / 选包 / 结算 / 弹窗）回退 v3 色块**：panel 0.94 深底、卡片实底、按钮五变体染色块（primary 金 α0.16 / normal 青 α0.12 / danger 红 α0.14）。
   - **`battle_theme.gd`（关卡内持久 UI）保持「仅文字」**：panel/card/well 全透明（alpha 0）、阴影移除、按钮纯文字色区分。悬停 / 按下反馈 = 缩放动效 + 文字提亮。
2. **统一关卡内风格**（用户：「统一关卡中的UI风格」）：残留底块清零——HUD 波次轨道（0.42 黑块→透明）、核心 HP 底槽承托（C_BG→透明）、悬停浮卡承托底（→透明 + **深色文字描边**替代，card_hover.gd）。统一后的关卡内视觉 = **纯文字 + 内容插画（整卡 rarity_backdrop 属内容资产，保留）+ 数据条（HP 段 / 进度填充 / 预算条）**，零 UI 面板块。
3. 协作者同期落地的整卡插画背景（`card_backdrop` 程序化生成 + 「背景铺满整张卡」）保留——插画是内容不是 chrome。
4. 断言随结构变更同步：`run_shop_overlay_asserts.gd` 稀有度断言改「bg alpha < 0.01 + ▲ 数」；`run_shop_interaction_asserts.gd` 两处 `_slot_buy[0].pressed.emit()` 改「点击整卡」（独立购买按钮已取消，`_slot_buy`→`_slot_can_buy` 布尔态，入口 = `p.gui_input`）。
5. 验证：uistyle 138 PASS / shop 门禁 0 错 / shop_interaction PASS / world PASS（23.6s）/ 全量 exit 0（2086 PASS，5m9s）。实机截图（HUD 三态 + 商店）放大目检：段位圆点、进度填充、按钮文字全部无底浮层。
6. mockup `.btn` 基类补 `border:none; outline:none`——HTML `<button>` 的 UA 默认边框在去底后会漏出来，设计稿同踩此坑。

## 2. 布局网格（1920×1080 基准 · 四边 5% 安全区）

```
┌─A────────┐┌────B────┐┌─────C─────┐
│ 废料 188×72││ 波次 430 ││  按钮簇    │  y=24, 高≤72
└──────────┘└─────────┘└───────────┘
                    ┌─── 商店抽屉 614 ───┐
   （战场 · 双焦点压暗）│ x=1282…1896       │
                    │ y=110…970          │
┌─D───────┐         └────────────────────┘
│ 背包 760×96│                        y=870…966
└─────────┘┌──── 核心 HP 600×60 ────┐
            └────────────────────────┘  y=996…1056
```

- **A 废料**：`left:24 top:24`，金描边 + 辉金 L 刻线（资源语义）。
- **B 波次模块**：顶中 430 宽，标题 + 10 段进度 + 等宽读数一行。
- **C 按钮簇**：右上，随阶段换装（见 §4）。
- **D 背包**：抽屉收起态出现，`left:24 bottom:110`。
- **核心 HP**：底中 600×60，CanvasLayer 130 穿透式，抽屉/商店永不遮挡（§5.6-2）。
- 商店抽屉宽 614 ≈ 32%（§5.6 常驻侧栏已否决，保持覆盖层形态）。

## 4. 三态与组件规格

### 4.1 准备阶段（安全窗 · 商店浮层）

> **🆕 v2（2026-11-10，参考图重排 + 已实装）**：商店形态从「右抽屉」改为**参考图语言**——
> 大卡横排顶部居中、无抽屉底板（`StyleBoxEmpty` 透明浮层）、战场保持可见可玩（双焦点压暗降档 55% → 35%）。
> 已落地 `shop_overlay.gd`：`SLOT_SIZE` 184×306 → **210×340**（X3 恒等）、浮层宽 700 @ y=88、
> 卡组下一行选牌提示 + 信息带（**刷新 · R / 决策预算条 / 轻决策·重决策徽标**，三者原先两个隐藏一个在标题行）。
> HP 条实装口径 = **左列信息栈**（废料 → 核心HP → 关卡简报；bb1e18f 起底部中央已被居中背包占用）。

- **双焦点**（§5.6-1）：浮层打开战场压暗 35%（0.25s 过渡），两层永不同亮度。
- **右上按钮**：`商店·Tab`（normal）+ `开始战斗·Space`（**primary 金** = 安全窗推进主操作）。
- **商店抽屉**：
  - 头部：`建筑商店`（display 900 26px）+ 右侧读数 `建筑 1/10 · 待放置 1`（中文骨架 + 等宽数字拆分，与选包/选关底栏同语言）。
  - **商品卡 ×3**（X3 断言：三位同 state 同样式）：
    - 结构：直角 2px 底座 + 四角 L 刻线（可购 → 耀青提亮；买不起 → 钢灰压暗 + 底色降一档）。
    - 行序（155px 内宽红线，每行 ≤9 汉字）：`序号 + Tag 芯片` → `卡名` → `插图区 118px`（内嵌槽底）→ `机制` → `伤害 7 · 射程 18`（等宽）→ `✓ 价格 12`（等宽辉金）→ `购买`（primary 小号 38px）→ `锁定`（ghost 下划线）。
    - Tag 芯片：`◇火 熔橙 / ●霜 耀青 / △穿 辉金`，颜色逐字复用 `TAG_COLORS`，同色靠字形区分。
    - 买不起：`✗` 警报红字形 + 价格转钢灰 + 按钮变 unavail 灰——**颜色+字形+明度三通道**（§9.2-1）。
  - 底栏：`⟳ 刷新 · R · 剩余 3 次`（辉金描边条，刷新=收益类操作用金）+ 一行购买流程说明。
- **波次模块**：标题`准备阶段`，进度条已完成段耀青、当前段呼吸脉冲、第 5/10 位**品红刻位**（精英波预告，形状+颜色双通道）。

### 4.2 战斗中（抽屉收起）

- 右上换装：`总览`（ghost）/ `回到核心·F`（ghost）/ `商店·Tab`（normal）/ `退出关卡·Esc`（danger）。
- **开波横幅**：`WAVE 2` 88px display 900 落下 + 青色 3px 下划线，1.2s 淡出（§5.3）。
- **核心 HP**：20 段（每段 50 点），段数=主编码；受击段闪警报红 0.3s 后碎裂为暗槽；读数 `800 / 1000` 等宽。
- **威胁脉冲**（§8.6-4）：核心 HP < 30% 时屏幕边缘红光 1.6Hz 呼吸（<3Hz 合规），**不依赖数字告警**。
- **背包**：左下出现，待放置芯片 72×72 + 数量角标（等宽辉金），悬停抬起 1.05。

### 4.3 放置模式（⑤）

- 抽屉收起、战场全屏；顶中降级为 `时间 × 0.25 · 部署中` 徽标（星紫描边——减速信号，§5.6-4）。
- 正六边形网格：可新建 = 耀青实线 + 半透明填充 + `＋` 徽标；可升级 = 辉金粗框（只描边）；禁建 = 钢灰虚线，**点击无反应不踢人**。
- 徽标全部 `draw_line` 绘制，渲染层零文本（AC-T1-24）。
- 底部一行提示：`左键 落子 · Esc 退出放置 · 灰格为禁建区无反应`。

## 5. 可访问性自查（§9 Basic 级）

| 项 | 结论 |
|---|---|
| 状态不只靠颜色 | ✓ 可购性 ✓/✗ 字形；精英波=品红+刻位位置；放置=徽标形状；减速=徽标文字+时间读数 |
| 全屏闪烁 < 3Hz | ✓ 威胁脉冲 1.6Hz、当前波段脉冲 0.625Hz |
| 正文对比度 ≥ 4.5:1 | ✓ `#C8CFDA` on `#141726` ≈ 10:1；辅助 `#8B94A5` ≈ 4.6:1 |
| 最小字号 | ✓ 全稿 ≥16px（键位角标由 14 抬 16，属存量修正项） |
| 触控/点击目标 | ✓ 按钮高 44px、背包芯片 72×72、HP 段不可点 |
| 塔轮廓/HP条不被遮挡 | ✓ HP 条 CanvasLayer 130 穿透；抽屉不进底部中央区 |

## 7. 验收红线（对齐 `tests/run_ui_style_asserts.gd`）

1. 不出现系统默认控件；调色板不漂移（新色 = 0）。
2. 玩家可见文本 ≥16px；三位商品位样式一致（X3）。
3. 卡面每行 ≤9 汉字（155px 内宽）。
4. 抽屉开 → 战场压暗、HP 条仍可见（双焦点断言）。
5. 数值口径冻结：本设计**零玩法写入**，渲染层只读 snapshot（README 红线）。
