## 0. 结论前置（给赶时间的人）

### 0.1 售卖 vs 拆塔（任务 1 的答案）

> ✅ **已定稿（Q-T1 = A′）：方案 A′「售卖 ≡ 拆塔」** —— 两者是**同一个动作、同一套规则、同一个确认弹窗**，只是玩家侧的叫法不同（UI 统一为「拆除并回收 `Salvage`」）。
> 🔴 **本条是本定稿中唯一进 MVP 的落地项**，已回写进 `card-system` **v1.1.4**（术语统一 + 塔移除结算器分支登记 + 反通胀红线 T-R1/T-R2 + F-2 观察项），**Q-C3 定稿数值一字不改**。
> **唯一的扩展**：把它升级成一个**统一的塔移除结算器**，按**触发源**分两个返还系数：
>
> | 触发源 | 谁发起 | 时机 | 返还 | 装配卡 |
> |---|---|---|---|---|
> | **主动移除**（售卖 / 拆除 `Salvage`） | 玩家 | 仅**波次间安全窗** + **二次确认** | **50% 累计投入**（Q-C3 原文，一字不改） | **全销毁**（Q-C3 原文） |
> | **被动移除**（被怪物打死 `Destroyed`） | 系统 | 战斗中 | **0%**（新，`PLACEHOLDER`） | 走 Disabled 中间态（见 Q-T4） |
>
> **一句话理由**：A/B/C 三条岔路里，**B 和 C 的每一种"差异化"都会撞上一条既有定稿红线**（详见 §1.2 / §1.3）——B 的"保留卡"会让拆塔变成废按钮（主导策略），C 的"更高返还 / 战斗内即时到账"会同时违反 §4.3 战斗内轻决策铁律与 Q-C3 的「50% 是为了保留 P4 不可逆性」。**A′ 是唯一不付代价的答案**，且它把"售卖 vs 死亡"的差别变成了**风险定价**：主动管理回收一半，被动挨打颗粒无收。
>
> 🔴 **落地批次（Q-T10 = ② 已定稿）**：**「主动移除」行 = MVP**（Q-C3 原文，已落地）；**「被动移除」行 = 🔒 设计冻结 / 实现进 T1**（其全部参数由 Q-T2 ~ Q-T9 冻结，见 §2）。

### 0.2 塔死亡的核心定性（任务 2 的答案）

> 🔴 **本机制能否成立的红线，就是这一句话：**
> **塔死亡 = 一次「资产折旧事件」，不是「操作考验」，也不是「局终」。**
> **它在战斗中发生，但只在波次间被结算。**
>
> 落地为 **三条硬约束（缺一即违反 P1/P4）**：
> 1. **战斗内零可操作**：塔挨打、受创、停机，玩家**不能**修、不能卖、不能加固、不能撤退。玩家对"将死的塔"唯一能做的动作，发生在**上一个波次间**（提前升级 HP / 提前卖掉 / 不投卡给它）。
> 2. **余光可感知，不占注意力**：塔的损伤状态用**塔体损伤演出 + 运动/亮度告警**表达（与核心告急的"红光脉冲"同族），🔴 **禁止**做成需要玩家精确读数的数字血条 —— 那会把注意力从商店锁回战场，直接破坏双焦点界面（视觉锚点 6）与 P4。
> 3. **不算失败，且不断链（✅ 已定稿口径 · Q-T5 + Q-T7）**：塔死亡**不触发**局终（沿用 Q5：只有核心 HP 归零才失败）；定稿口径下它也**不改变** `E_i` / `κ` / `N_tower` → **对已定稿的 7 乘区管线零改动**，只需在 `Raw_i` 末尾乘一个 `disabled ? 0.0 : 1.0`。
>
> 🔒 **§0.2 整节（塔被攻击死亡）实现进 T1**：设计已定稿冻结，MVP **不实现**；MVP 只需在 `Raw_i` 末尾保留一个**恒为 `1.0` 的 `Disabled_i` 因子占位**（§4.3 交接点 ③），T1 接管时无需改结构。
>
> ✅ **切片6 落地留档（2026-10-01，用户拍板：T1 仇恨留后续批次）**：本条 MVP 占位已**代码落地**——
> ① `player_state.gd :: TowerState` 新增 `disabled: bool = false` 字段（MVP 恒 false）；
> ② `damage_engine.gd` per_tower 末尾 `dps_i *= disabled ? 0.0 : 1.0`（MVP 恒 1.0 → 对定稿 DPS **逐位零影响**，金标本零改动、判据链不变）；
> ③ `per_tower` 记录附 `disabled` 字段供单测断言。
> 🔴 **切片6 边界 = 口径登记 + 数据地基 + 占位落地，不激活任何 T1 玩法**：仇恨（怪物转向攻塔 → 塔会被打死 → 漏怪分布变）在物理上会破坏切片5 刚建立的「实时版与金标本逐位等价」基线 → 与 S5-D1（三原型+Elite 列校准闸门）同一哲学，**整体留后续批次 + 300 局 MC 重扫后上线**。暴露度数据地基（`d_path` 表 / `AGGRO_R=9.0` 切分 4 暴露位+2 安全位 / 硬约束「≥1 安全位」）经 Python 金标本交叉验证逐位一致，已随切片5 落地（`path_geometry.gd` + `test_suite_slice5` AC-W1/W2）。

## 1. 售卖 vs 拆塔辨析（任务 1）

### 1.0 先把已定稿的事实钉死（引用，不改）

`card-system` **Q-C3 ②（v1.0 定稿）· §7.2.2** 的规则，逐条原文引用：

| 项 | 定稿规则 | 出处 |
|---|---|---|
| 返还 | 该塔**累计投入的 50%**（该塔花费的建筑卡分 + 其上装配的单塔效果卡分之和，**向下取整**） | §7.2.2 |
| 装配卡 | 该塔装配的**全部单塔效果卡及其层数全部销毁** 🔴（不可回收，与"弃卡"同口径 §4.3） | §7.2.2 |
| 塔位 | 释放，可再建新塔 | §7.2.2 |
| 重算链 | `N_tower` 变化 → **全场 κ 立即重算**（E11）；链接重算（E6）；`Aux` 重算；`CoreTower` 重算（E4） | §7.2.2 |
| 确认 | 🔴 **必须二次确认**，弹窗列出"返还 **X** 分 / 销毁 **N** 张卡（共 **M** 层）" | §7.2.2 |
| 时机 | 仅**波次间安全窗** | §7.2.2 · §4.3 |
| 锚点 | **A16**：卸下 **降 1 层** / 弃卡 **全销毁** / 拆塔 **返还 50% + 装配卡全销毁 + 二次确认** | §5.8 A16 |

**Q-C3 定稿的三条理由（`card-system` §7.2.2 原文，必须尊重）**：
> ① 「不可拆」会让"建错塔"变成**不可挽回的沉没成本**，失败归因滑向"我开局点错了"，违反概念 §4.1；
> ② **50%（而非 100%）** 保留了 **P4 的不可逆性** —— 认赔要有代价，但代价可承受；
> ③ **「装配卡全销毁」让拆塔产生一个真实取舍**：拆掉一座深叠塔 = 放弃它的全部复利 → **"何时认赔"这个决策的来源正在于此**，而不是来自返还比例本身。

### 1.1 三个方案的定义

| 方案 | 定义 | 与 Q-C3 的关系 |
|---|---|---|
| ✅ **A · 别名**（**已定稿 · Q-T1 = A′**） | 售卖 ≡ 拆塔。同一动作、同一规则、同一弹窗；只是 UI 上叫"售卖/回收"，且**塔被摧毁也走同一结算器**（返还系数不同）。 | 零冲突，Q-C3 一字不改 |
| ❌ **B · 并存**（**已否决**） | 售卖 ≠ 拆塔，两个按钮：**拆塔** = 销毁换塔位 / 反装配卡；**售卖** = 即时换积分，但**保留卡或塔**。 | 🔴 冲突（见 §1.2） |
| ❌ **C · 增强版**（**已否决**） | 售卖 = 拆塔 + 额外好处：更高返还 / 战斗内即时到账 / 可换别的资源。 | 🔴 冲突（见 §1.3）<br>🟢 其中「献祭」形态保留为 **T1 玩法 ③**（§3），附加条件：收益 ∝ 累计投入 |

### 1.2 为什么否决 B（并存）

B 的差异化只有两个可能维度，**两个都会产生主导策略**：

| B 的差异化维度 | 后果 | 判定 |
|---|---|---|
| **售卖保留装配卡**（塔没了卡还在 / 卡可转移） | 拆塔的最大代价（装配卡全销毁）被绕开 → **玩家永远点"售卖"，"拆塔"按钮变成废按钮**。更致命：Q-C3 理由③ 明确指出「**装配卡全销毁才是"何时认赔"这个决策的来源**」→ 保留卡 = **把 Q-C3 的决策来源拆掉**，P4 的不可逆性当场失效 | ❌ 否决 |
| **售卖保留塔**（塔降为"离线"但仍占位） | 塔位不释放 → 与 Q-C3「塔位释放，可再建新塔」直接矛盾；且"保留一座不输出的塔"在 `N_tower` 语义上会**继续吃 κ 广度折价** → 玩家得到一个纯负收益按钮 → 废按钮 | ❌ 否决 |

> 🔴 **一句话**：**B 的每一种形态都在"拆塔"旁边放了一个严格更优的按钮。** 一个严格更优的按钮 = 主导策略 = 违反概念 §7.2 R2，也直接违反 `card-system` §1.2「若卡可无痛重来 → 决策退化为假选择」。
> 📌 **唯一例外（可接受）**：B 的"保留塔"形态**恰好就是我要在 §2.3 提的「Disabled 中间态」** —— 但它必须改名为「**被摧毁后的残骸**」，由**系统**触发（塔被打死），而不是由玩家的"售卖"按钮触发。**触发源不同，性质就完全不同**：系统给的中间态是**惩罚的缓冲**，玩家点的按钮是**逃生舱**。

### 1.3 为什么否决 C（增强版）

C 的"增强"有三条可能路径，**三条各撞一条既有定稿红线**（这不是巧合，是因为 Q-C3 的 50%/安全窗/二次确认本来就是**为守住 P4 而设的三道锁**）：

| C 的增强路径 | 撞哪条红线 | 出处 |
|---|---|---|

**为什么"死亡返还 0%"是对的（四条理由 · ✅ Q-T8 已定稿为 0%）**：

2. **它防止了"送死套利"** —— 若死亡也返还 50%，玩家的最优解会滑向「把塔放在最暴露的位子让它被打死换 50%」，这是**反向激励**。
3. **它保住了失败归因**：塔被打死是**损失**，玩家能明确说出"我那座塔站得太靠路了" → 归因于**决策**（概念 §4.1 胜任感）。若死亡还能返钱，损失感被稀释，归因模糊。

### 1.5 经济闭环：售卖会不会导致通胀？

> ✅ **结论：不会。在数学上不可能。以下给出证明，并给出必须写进 GDD 的两条反通胀红线。**

**已知事实**（`corebound_sim_v03.py:57` / `154` / `398`，`card-system` §7.4）：
- 卡价 `PRICE = {tower: 12, reinforce: 9, econ: 10}`（= A1 锚点）
- 每只击杀积分 `scrap_per_kill(w) = 2.0 + 0.5 × w`（波次线性）
- 波次怪物数 `N(w) = 8 + 1.6 × w` → **W1 收入 ≈ 9.6 × 2.5 ≈ 24 分**（与 `card-system` §7.4 一致）
- 🔴 **M5：局内唯一货币 Scrap 仅从击杀获得**（概念 §2.1）→ **售卖不铸币，只退币**

**证明（三步）**：

1. **退币不是铸币**：设玩家整局击杀总收入为 `S`，则整局总支出 `E ≤ S`。售卖返还总额 `R = 0.5 × (被拆塔的累计投入) ≤ 0.5 × E ≤ 0.5 S`。
   → **返还的上限是"已花出去的钱的一半"**，它**不新增任何一分钱**，只是把已支出的部分回流。
2. **单次循环严格亏损**：一次"买塔(12) → 卖塔(返 6)"净亏 **6 分**；一次"买强化卡(9)投塔 → 拆塔(返 4.5)"净亏 **4.5 分**。
   → **循环次数越多，总资源越少**。这是**严格通缩**的操作，不是通胀。
3. **回流有上限且不可重复**：同一座塔只能被移除一次（移除后塔位为空/Disabled，实体已消失）；要再次套利必须**重新全额买入** → 又回到第 2 步的亏损。
   → **不存在可无限重复的套利环**。

> 📌 **数值体感**：W1 全波收入 ≈ 24 分，卖掉一座 `h=1` 的塔返 **6 分**（≈ 1/4 波收入）。→ 售卖在 MVP 是**"认赔杠杆"**，不是日常经济来源。这符合 Q-C3 的定位。

**🔴 必须写进 GDD 的两条反通胀红线（防未来卡池破坏上述证明）**：

| # | 红线 | 理由 |
|---|---|---|
| 🔴 **T-R1** | **任何情况下，塔移除的返还系数 ≤ 100%，且不得存在「买入折扣」与「移除返还」同时生效的组合** | 一旦 `买入价 × 折扣 < 返还价`，第 2 步的"严格亏损"被翻转 → 出现无限套利环 → 经济崩溃 |
| 🔴 **T-R2** | **不得新增任何"以移除塔为触发条件的铸币效果"**（如"每拆一座塔 +10 分"的全局卡） | 它把"退币"变成"铸币"，直接绕过 M5「积分仅从击杀获得」，且会与 G1 回收协议（击杀积分 +50%）叠乘 |

> ✅ **落地状态**：T-R1 / T-R2 已随「售卖 ≡ 拆塔」术语统一一并写入 `card-system` **v1.1.4 §1.4**（属 MVP，与售卖同批生效）；🔒 **T1 塔死亡实现时同样受这两条约束**（被动移除返还 0%，更不可能铸币）。

### 1.6 🟡 售卖的"重"，是特性不是缺陷（预判用户可能的疑虑）

Q-C3 的规则（50% + 卡全销毁 + 二次确认 + 仅安全窗）意味着：
**售卖会很重，玩家不会频繁使用它。**

> ✅ 我认为这是**正确的**，理由三条：
> 1. 若售卖轻到可以随手用，玩家就可以"试错式建塔" → **建塔决策从"落子无悔"退化为"先建了再说"** → 违反 `core-defense` §2.3「塔位不可逆 = P4 不可逆性的来源」；
> 2. `card-system` §1.2 已写明 P4 的兑现方式就是「**每张卡都是不可逆的取舍（弃卡降层、拆塔销毁、塔位不可逆）**」→ 售卖重 = P4 兑现；
> 3. **"重"本身产生了一个可感知的戏剧时刻**：玩家按下"拆除并回收"、看到弹窗"返还 34 分 / 销毁 3 张卡（共 47 层）"、再确认一次 —— 这个瞬间就是"认赔"的情绪峰值，是 concept §2.3「从混乱到秩序的相变」的**负向镜像**。它是**内容**，不是摩擦。
>
> 🟢 **若用户仍希望售卖更轻**，唯一安全的减负方向是**减输入次数**（如拖拽塔到商店即可发起售卖、弹窗默认聚焦"确认"），🔴 **不是减代价**。

### 2.1 分叉一：塔是否有 HP？HP 怎么来？

| 选项 | 定义 | 评价 |
|---|---|---|
| ✅ **① 由建筑卡层数派生**：`HP_i = HP0 × h_i^0.6`（**已定稿 · Q-T2**） | 复用定稿指数 `tower_stack_exp = 0.6`（`damage-pipeline` §3.1.2），与 `Base_i = base_dps × h^0.6` **同一个指数** | 见下"四条理由" |
| ❌ ② 原型固定 HP：每原型一个常量，不随 `h` 变 | 最简单；但"升级塔不会变硬"违反直觉，且**建筑卡失去"保塔"这条价值路径** → 直接砍掉 §3 玩法②（肉盾塔）的地基 | **已否决**（保留为工期紧张时的简化退路） |
| ❌ ③ 塔无 HP，改"受击 N 次即毁" | 与 ① 数学等价但更粗糙；且**无法被"治疗/装甲"类卡消费**（没有连续量就没有可调节的设计空间） | **已否决** |

**定稿 ① 的四条理由**：
1. **零新增资源**：`h_i` 是玩家已经认识的量（= 塔等级 = 谐波层），塔血条不需要玩家学新概念。
2. **语义统一**：「**塔的等级同时决定它的输出与耐久，都是次线性 ∝ h^0.6**」—— 一句玩家能懂的话，工程可复用同一个 `pow(h, 0.6)`。
3. **深塔自动更耐打**：`h=133` → `133^0.6 ≈ 18.8` → **深塔约 19× HP**。这兑现 P2「失控必须被 earned」—— 你投得越深，它越难被打掉。
4. **次线性是关键**：若用线性 `HP ∝ h`，深塔会**无敌**（h=133 → 133×）→ "塔会死"这个机制在后期失效得太彻底；次线性让深塔"更难死但**仍会死**" → 张力保留。

**🔒 已冻结的 PLACEHOLDER 取值（Q-T2 = ① · 待 T1 扫参 V-1 · MVP 不开数值）**：

### 2.2 分叉二：怪物会不会转向攻击塔？

| 选项 | 定义 | 评价 |

| ✅ **① 机会型仇恨（Opportunistic Aggro）**（**已定稿 · Q-T3**） | 怪物默认沿路径冲核心；**但当其当前位置与某座塔的距离 ≤ `AGGRO_R` 时，转向攻击最近的塔**；塔死（或进入 Disabled）后继续前进 | 见下"四条理由 + 三条硬约束" |

**否决 ③ 的正式理由**：概念 **Q5** 的定稿口径是「**核心 HP 归零 = 立即失败（最纯粹）**」（Q-T7 已沿用）。纯 blocker 制会让"漏怪"几乎不再发生 → **核心 HP 1000 与漏怪 −50 这两条定稿数值（`core-defense` N1/N2）失去意义**。这是**机制与失败条件的结构性冲突**，不是数值问题，无法靠调参修复。

**定稿 ① 的四条理由**：
1. **它是 P1 迄今最大的一次强化**：是否挨打由**站位几何**决定（§0.4 暴露度表）→ 站位三维化，且**零新增资产**。
2. **它是可读的、可归因的**：玩家死了一个塔，能明确说出"它站得太靠路" → 归因于决策（概念 §4.1）。
3. **它自限**：雪崩期 DPS ≫ 怪物 HP，怪物在路径前段就被清光 → **塔在 W13+ 几乎不再受创** → 机制自然退场，**不破坏 Submission（`消遣`）美学与"观赏自己的造物"**（概念 §2.3）。这是它能与 P2 共存的关键。
4. **它物理上就是《王国保卫战》的 blocker 逻辑**（概念 §7 参考作品"抄它的：等距布局可读性 / 波次节奏"）→ 玩家零学习成本。

### 2.3 分叉三：塔 HP 归零的后果 —— 直接摧毁，还是 Disabled 中间态？

| 选项 | 定义 | 评价 |
|---|---|---|
| ✅ **① `Disabled` 中间态（停机）**（**已定稿 · Q-T4**） | HP 归零 → 塔进入 `Disabled`：**停止输出、停止参与 Crossfire/AoE**，但**仍占塔位、仍持有装配卡、仍供 `h_j`**；在**下一个波次间安全窗**，玩家三选一：**修复 / 拆除 / 放着不管** | 见下"五条理由" |
| ❌ ② 立即摧毁 | 塔位立即释放、装配卡全销毁（与售卖同口径） | 惩罚最重，但**会触发连锁灾难**（见下）+ 与"塔死亡不算局终"的定性不匹配（一个不失败的机制不该给最重的惩罚） |
| ❌ ③ 直接摧毁但保留残骸可打捞 | 引入"残骸"实体 / 拾取 / 新资源 | **已否决**：MVP 过重，且**"拾取"是操作** → 违反 P1 |

**为什么 ② 会触发连锁灾难（关键论证）**：
`E_i` 与 `κ` 都依赖"塔存在"。若塔一死就释放塔位：
- **灾难 A（共鸣崩塌）**：定稿多塔 B 的 `E = 134` 来自 `Arrow@S0 h=133`。按 §0.4，**S0 的 `d_path = 6.00`，正落在暴露区** → 深塔是最容易被打掉的那座 → 一旦被打掉，`E_Cannon` 从 134 → **0**，`Resonance` 从 `(1.05)^134 ≈ 691×` → **1×** → 多塔流**瞬间蒸发**。这不是"有代价"，这是"**一击致死**"。
- **灾难 B（反向激励）**：若塔死立即释放塔位 → `N_tower` 下降 → **κ 回升**（如 §1.7：6→2 时 κ 0.06→0.10）→ **"塔被打死"在 κ 维度上成了好事** → 荒谬的反向激励。

**定稿 ① 的五条理由**：
1. **它把"战斗内的事故"翻译成"波次间的决策"** —— 完美落在 `card-system` §4.3 的职责切分铁律里（战斗内轻决策 / 波次间重决策）。这是本机制**唯一**能同时满足"塔会死"与"P4 不破"的结构。
2. **它给了玩家一条可归因的补救路径**："我那座塔被冲掉了 → 我选择花 X 分修它 / 我选择放弃它把卡位腾出来" → 归因于决策，胜任感保住（概念 §4.1）。
3. **它保住了全部定稿数值**：Disabled 塔**仍占 `N_tower`、仍供 `h_j`** → `κ` / `E_i` / `Crossfire` / `CoreTower` **全部不变** → 对 7 乘区管线**只需在 `Raw_i` 末尾乘一个 `×0`**（详见 §4.1）。
4. **它避免了灾难 A / B**（上）。
5. **惩罚依然真实且沉重**：失去该塔**全部 DPS**（一座塔常占 30–60% 输出）+ 修复成本 + 覆盖下降（若它是高覆盖位）→ 塔死是**真损失**，不是挠痒。

**波次间三选一的处置表**（🔒 **设计冻结 · 实现进 T1**，`PLACEHOLDER` 价格见 Q-T8）：

| 处置 | 效果 | 何时是正解 |
|---|---|---|
| **修复 `Repair`** | 花 `repair_cost` → HP 回满（或回 50%，见 Q-T8），塔恢复输出，**装配卡全部保留** | 深叠塔（装配卡价值 ≫ 建筑卡价值） |
| **拆除 `Salvage`** | 走 §1.4 的被动移除分支：返还 0%（PLACEHOLDER），装配卡**全销毁**，塔位释放 | 杂兵塔 / 已决定转型 |
| **放着不管** | 继续占塔位、不输出、仍吃 κ 折价 → **隐性持续惩罚** | 没钱 + 不值得拆（罕见） |

> 🔴 **关键的价格关系（必须成立，否则会出现废按钮）**：
> `repair_cost < 重建同层塔的代价`。✅ **已定稿（Q-T8）**：`repair_cost = ceil(0.30 × 该塔累计投入)`（🔒 `PLACEHOLDER`，待 T1 扫参，MVP 不开）：
> - 一座 `h=1` 的杂兵塔：修 **3.6→4 分** vs 重建 **12 分** → 修更划算 ✓
> - 一座深叠塔：修 30% 投入 vs 拆除**损失 50% 投入且装配卡全销毁** → 修远更划算 ✓
> → **修复永远比"放弃它"便宜，但比"没被打掉"贵** → 三个按钮都有存在意义，无废按钮。

### 2.4 分叉四：Disabled 塔是否还供 `h_j` 给共鸣？（用户点名要的"断链"问题）

| 选项 | 后果 | 评价 |
|---|---|---|
| ✅ **① 仍供 `h_j`（断"输出"不断"共鸣"）**（**已定稿 · Q-T5**） | `E_i` 不变 → **定稿 `E=[9,0,134,0,0,0]` 与 `κ_r=0.050` 完全不受影响** | 见下 |
| 🟡 ② 不供 `h_j`（真·断链） | 惩罚更重、戏剧性更强（"我的共鸣网断了"）；但会触发 §2.3 的**灾难 A**（多塔流一击蒸发），且**必须重扫 `κ_r`** | ✅ **已定稿：留 T1 候选**（必须与 `κ_r` 重扫绑定评估，不进 MVP） |

**定稿 ① 的理由**：
1. **保住定稿数值**（最重要）：`κ_r = 0.050` 是 v0.7 复扫、可行区间 `[0.045, 0.055]`、余量 +11pp 才定下来的（`card-system` §5.4 / `core-defense` §5.1 N8）。断链会让 `E` 在战斗中**随机跳变** → `κ_r` 的整个标定基础（"终局 `E` 向量"）失效 → **必须重扫**。
2. **语义自洽**：`h_j` 的 diegetic 定义是「**谐波层**」（`core-defense` §2.5.2：`v0.3 §1.7` 立 `link_min_level` 的理由是"塔要**长成**才会与邻居共振"）。一座**停机但结构仍在**的塔，其机械结构/谐波体依然存在 → 仍能共振。物理上讲得通。
3. **"断链"的戏剧性没有丢失**：塔停机时，该塔**输出归零**（这才是玩家真正感受到的），且链接光弧可以给一次**"暗淡/虚线"**的衰减动效（`core-defense` §2.5.4 已有"链接消失时给一次衰减动效（非静默）"的同款处理）→ 视觉上"断"了，数值上"稳"了。
4. 🟢 **给 T1 留门**：② 是一个**很好的 T1 内容**（"断链"是很强的戏剧时刻），但它必须与 `κ_r` 重扫**绑定评估**（`damage-pipeline` §6.1 已立的同类规则：任何改变拓扑的机制都必须与 `κ_r` 一起评估）。

### 玩法 ① 「暴露度」—— 站位第三维（**地基，必做**）

| 项 | 内容 |
|---|---|
| **是什么** | 把「塔位到路径的距离」变成一条**显式可读的空间事实**（`Exposure_i`），与 `CoverageScore` / `LinkGraph` 并列，成为 `core-defense` 对外供给的**第三个空间量** |
| **触发** | 每次建塔 / 放置模式的塔位高亮时 |
| **玩家决策点** | 「深塔放 **S2**（覆盖 0.819 + 度 5，但 `d_path=5.00` 最危险）还是放 **S5**（`d_path=13.00` 最安全，但覆盖 0.507、度 3）？」 |

#### 为什么"起飞率"是最可能破线的一条（诚实标注）

- 定稿单核 A 起飞率 **69.3%**（`card-system` §5.7.2），红线 60% → **余量只有 +9.3pp**；
- 而按 §0.4 实算，**定稿多塔 B 的深塔 `Arrow(h=133)` 落在 S0（`d_path = 6.00`，暴露区）**，定稿单核 A 的主塔大概率落在高覆盖位（S1/S2，`d_path` 8.00 / 5.00，**同样暴露**）；
- → **两条定稿金标本的 carry 塔都站在暴露区** → 塔死亡会**直接打击它们的输出** → 起飞率下降是**高概率事件**，不是理论风险。
- 🟢 **缓解方向（若破线）**：① 优先降 `ATTRITION`（最直接的旋钮）；② 其次抬 `HP0`；③ 🔴 **最后才考虑动定稿数值**（`hp_growth` 等），因为 `card-system` §5.7.2 已证明方案① 的可行区间（`hp_growth 1.36~1.42`）比方案② 宽得多 —— **若不得不动，也要先复扫可行区间而不是单点改值**。
