## 0. 结论前置（给赶时间的人）

1. **攻击类型**：每座塔**归属单一攻击类型**（物理 / 魔法 / 真实），类型与塔绑定。
   - Arrow（箭）/ Cannon（炮）/ Lance（长枪·扩展包）/ **Sunder（破甲炮·扩展包）** → **物理**
   - Frost（冰）/ Tesla（电弧·扩展包）/ **Hex（诅咒塔·扩展包）** → **魔法**
   - **Oblivion（湮灭·扩展包）/ Void（虚无·扩展包）** → **真实**（无视抗性）
2. **防御抗性**：怪物按**原型**持有两个百分比抗性——`物抗` / `魔抗`。
   - 伤害结算：`实际伤害 = 原始伤害 × (1 − 抗性%)`，抗性 ∈ [0, 1]。
   - **真实伤害不查抗性**（`抗性恒 0` → `×1.0`），也不受破甲影响。
3. **默认值设计**（🔴 零扰动铁律）：
   - 基准怪 **Swarm** 双抗 = **0.00** → 伤害 `×(1−0)` 恒等。
   - Rush：物抗 0.00 / **魔抗 0.20**（快而脆，怕魔法）。
   - Tank：**物抗 0.30** / 魔抗 0.00（铁甲重盾，怕魔法；物攻刮痧）。
   - Elite：沿用宿主原型抗性（只放大 HP，不加抗性）。
   - **真实抗性**：所有原型恒 **0.00**（真实伤害无视一切）。
4. **守恒约束**（W-C1 同族）：抗性的**加权平均减免**按只数占比归一，使整体难度不抬高：
   - 物抗加权平均 = 0.40×0.00 + 0.40×0.00 + 0.20×0.30 = **0.06**
   - 魔抗加权平均 = 0.40×0.20 + 0.40×0.00 + 0.20×0.00 = **0.08**
   - → 纯物攻构筑平均少打 6%、纯魔攻平均少打 8%：**轻微、可读、可接受**；只有「类型错配」
     的构筑才显著变慢（Tank 物抗 0.30 让纯物攻刮痧）。
5. **🆕 破甲光环（v0.2）**：`Sunder` / `Hex` 在场时，给**全场怪物**叠加减抗光环——
   每座破甲塔把对应类型抗性**降低 0.10**（百分比点，可叠层、封顶 0.30）。
   有效抗性 = `clamp(静态抗性 − 破甲量, 0, 1)`。破甲是「物攻/魔攻 build」的核心件。
6. **🆕 真实伤害（v0.3）**：第三种攻击类型，**无视一切抗性**（不吃物抗/魔抗，不受破甲影响）。
   - 定位 = 克制高抗性怪的「通用解」；代价 = 面板 dps **刻意压低**（Oblivion 6 / Void 5），
     只有面对高抗性怪时才划算 → 保持「打什么怪用什么塔」的构筑决策不被真实伤害抹平。
7. **工程落点**：伤害管线输出**按攻击类型拆分的 DPS 池**
   （`dps_by_type = {physical, magic, true}`），`total`（聚合 DPS）**逐位不变**；
   波次结算在开关打开时用三个池分别按**有效抗性**集火（真实池 factor 恒 1.0）。
8. **开关**：`combat_types_enabled`（默认 **false** = 旧聚合池口径，金标本零扰动）。

## 1. 系统目标（System Goal）

### 1.1 一句话

> 让「打什么怪」成为**可读的构筑决策**：玩家的塔有攻击类型，怪有抗性，**类型错配会刮痧、
> 类型对位会碾压**——从而在现有的「覆盖 × 链接 × 暴露」三维之上，再叠一个「**伤害类型**
> 」的第四维。

### 1.2 与支柱的兑现关系

| 支柱 | 本系统如何兑现 | 若不满足则 |
|---|---|---|
| **P1 不动如山 · 站位即策略** | 抗性是**怪物原型给的、玩家可读的事实**（不是随机数）→ 「这座塔放这打不打得动」是地图 + 原型共同决定的可预判结果 | 若抗性随机 / 由 RNG 决定 → 类型决策不可预判 → P1 塌一格 |
| **P3 每局一个新解** | 「这局抽到物理塔多还是魔法塔多」成为新的随机维度 → 与怪物构成共同决定每局的最优构筑 | 若类型固定 → 少一个随机维度 |
| **P4 零操作 · 高密度** | 玩家对类型**零操作**（不能切换塔类型、不能手动集火），类型决策只在**安全窗的买卡/建塔**被回应 | 若引入「手动切换攻击类型」→ 直接违反 P4 |

### 1.3 三条设计红线（自检用）

| # | 红线 | 出处 |
|---|---|---|
| 🔴 **CT-C1 · 零扰动红线** | 默认开关 `false` 时，伤害结算必须与金标本**逐位一致**（含浮点累加序列）。抗性全 0 时 `×(1−0)` 恒等、`消耗 = 怪hp` 退化为旧逻辑 | `wave-spawner` W-C1 同族 |
| 🔴 **CT-C2 · 失败唯一性红线** | 类型/抗性**不得新增任何失败判定**（核心 HP 归零仍是唯一失败来源） | 概念 §10 Q5 |
| 🔴 **CT-C3 · 守恒红线** | 抗性分化**不抬高整体难度**：加权平均减免 ≤ 0.10，且基准怪（Swarm）双抗恒 0 | 本文档 §3 |

## 2. 核心机制（Core Mechanics）

### 2.1 攻击类型（塔侧）

| 塔 | 攻击类型 | 理由 |
|---|---|---|
| Arrow（箭） | **物理** | 穿刺直伤 |
| Cannon（炮） | **物理** | 爆炸冲击（群伤，物理属性） |
| Frost（冰） | **魔法** | 霜冻法术（既有减速 → 天然魔法定位） |
| Lance（长枪·扩展包） | **物理** | 远程穿刺 |
| Tesla（电弧·扩展包） | **魔法** | 雷电法术（既有 shock tag + 减速 → 魔法定位） |

> 🔴 **攻击类型与塔绑定，不可切换**（P4：类型决策只在建塔/买卡时发生）。
> 🔴 **默认全物理不影响结算**：类型只有在开关打开时才被消费。

### 2.2 防御抗性（怪物侧）

| 原型 | 物抗 | 魔抗 | 设计角色 |
|---|---|---|---|
| **Rush** 快速低血 | 0.00 | **0.20** | 快而脆，怕魔法（法师克制） |
| **Swarm** 集群基准 | 0.00 | 0.00 | 基准怪，双抗零（金标本等价） |
| **Tank** 高血慢速 | **0.30** | 0.00 | 铁甲重盾，怕魔法（物攻刮痧） |
| **Elite**（词缀） | 沿用宿主 | 沿用宿主 | 只放大 HP，不加抗性 |

### 2.3 伤害结算公式

```
实际伤害 = 原始伤害 × (1 − clamp(抗性, 0, 1))

  抗性 = 0.00 → 伤害 ×1.0（恒等，浮点精确）
  抗性 = 0.20 → 伤害 ×0.80
  抗性 = 0.30 → 伤害 ×0.70
  抗性 = 1.00 → 免伤（伤害 ×0.0）
```

### 2.4 伤害分配（类型分池）

> 🔴 **关键改造**：现有伤害分配是「全场 DPS 聚合池 → 按剩余时间集火 → 溢出结转」
> （`wave-spawner` §2.7 W-A1~W-A4）。引入类型后，聚合池**按攻击类型拆成两个池**：

```
物攻池 physical_dps = Σ_{物理塔 i} Raw_i × (AoE × Crossfire × Aux × Empower)
魔攻池 magic_dps   = Σ_{魔法塔 i} Raw_i × (AoE × Crossfire × Aux × Empower)

聚合 DPS total = physical_dps + magic_dps   （🔴 与旧口径逐位一致）

波次结算（开关开）：
  物攻池 按「最接近核心优先」集火，每只怪扣 hp ×(1−物抗)，溢出结转
  魔攻池 按「最接近核心优先」集火，每只怪扣 hp ×(1−魔抗)，溢出结转
```

> 🔴 **零扰动保证**：`total = physical + magic` 恒等于旧聚合 DPS → 金标本判据链
> （起飞点 / 起飞率 / B/A 比）**读 total 不受影响**。只有开关打开时，波次结算才
> 改用分池，此时「类型错配」的构筑才会因抗性而变慢。
> 🔴 **分池溢出结转的守恒语义**：抗性全 0 时，`消耗的原始伤害 = 怪hp ÷ (1−0) = 怪hp`
> → 与旧逻辑**逐位同构**（浮点序列一致）。

## 3. 数值与守恒（Numbers）

### 3.1 抗性表（定稿初值 · 待拍板）

| 原型 | p（只数占比） | 物抗 | 魔抗 |
|---|---|---|---|
| Rush | 0.40 | 0.00 | 0.20 |
| Swarm | 0.40 | 0.00 | 0.00 |
| Tank | 0.20 | 0.30 | 0.00 |

### 3.2 守恒验算（CT-C3）

```
物抗加权平均 = 0.40×0.00 + 0.40×0.00 + 0.20×0.30 = 0.06  ✓（≤ 0.10）
魔抗加权平均 = 0.40×0.20 + 0.40×0.00 + 0.20×0.00 = 0.08  ✓（≤ 0.10）
基准怪 Swarm 双抗 = 0.00                                  ✓（金标本等价）
```

> 🎯 **设计意图**：Tank 是「漏怪主因」（吃 60% HP 预算、在场 15s），给它 0.30 物抗
> 让「纯物攻构筑」在成型期对 Tank 明显刮痧 → 逼玩家在安全窗**混入至少一座魔法塔**。
> 这与现有「Tank 是唯一能走到核心的怪」的设计**同向叠加**：Tank 从「怕硬」升级为
> 「怕魔法」，归因更清晰。

## 4. 验收标准（可试玩验证）

| # | 验收项 | 判据 | 方法 |
|---|---|---|---|

| **AC-CT3** | **抗性减免正确** | Tank 物抗 0.30 → 物理伤害 ×0.70；Rush 魔抗 0.20 → 魔法伤害 ×0.80 | 单测：`CombatTypes.apply_resist` 断言 |
| **AC-CT4** | **类型错配刮痧** | 纯物攻构筑打 Tank 的击杀数 < 同 DPS 混合构筑 | 试玩 + MC：开关开后纯物攻 vs 混合的 W10 击杀数对比 |
| **AC-CT5** | **实时↔批处理等价** | `wave_director` 与 `wave_sim` 在开关开时输出逐位一致 | 单测：同构筑同波次两边 kills/leaked 比对 |
| **AC-CT6** | **失败唯一性** | 类型/抗性不新增任何失败判定 | 试玩：核心 HP 归零仍是唯一失败 |
| **AC-CT7** | **破甲减抗正确** | Sunder 每座减物抗 0.10（封顶 0.30）；有效抗性 clamp(静态−破甲, 0, 1)，不产生负抗性 | 单测：`armor_reduction` / `effective_resist` 断言 |
| **AC-CT8** | **破甲提高击杀** | 纯物攻 + Sunder 打 Tank 的击杀数 > 纯物攻打 Tank（破甲后物伤因子 0.70→1.00） | 试玩 + MC：带/不带 Sunder 的 W10 击杀对比 |

| **AC-CT10** | **真实伤害无视抗性** | Oblivion/Void 打 Tank 全额（不×0.70）、打 Rush 全额（不×0.80） | 单测：`monster_resist(proto,"true")==0` + `apply_resist` 断言 |
| **AC-CT11** | **真实拆分守恒** | 含真实塔的构筑 `physical + magic + true == total` 逐位一致 | 单测：`dps_by_type` 三分量求和断言 |
