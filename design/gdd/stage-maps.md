## 0. 结论前置

三句话：

1. **现在的 10 张图不是 10 张图，是 1 张图改了 7 个度数。** 实测：`variant-a` 把三条脊各加宽 6°、`variant-b` 给一座孤台加 1 格、`variant-c` 挪 2°、`variant-d` 收窄 4°、`variant-e` 整体转 18°……玩家在屏幕上看不出差别，**每一关要解的问题还是同一个**。这就是「每关都差不多」的真实原因 —— 不是内容不够，是图纸没换。
2. **地图的唯一合法杠杆有三个：口宽组合、开口总宽、脊的径向区间。** 前两个决定「火力怎么分」，第三个决定「哪里不能建」。三者都只改数据表，不碰 `t_reach`、不碰寻路、不消费 RNG —— 金标本逐位不变。
3. **每张图必须能一句话说出「这一关逼玩家做什么取舍」。** 说不出来的地图不是地图，是背景板。本文 10 关各有一句，且每句都指向不同的取舍。

一句话：**地图不是难度旋钮，是提问方式。**

## 2. 设计语言：三个旋钮

### 2.1 旋钮一 · 口宽组合（决定「火力怎么分」）

| 口型 | 角宽 | 语义 | 最优解 |
|---|---|---|---|
| **宽口** | ≥ 150° | 摊薄税：怪稀、覆盖贵 | 广覆盖 / 长射程，或干脆放弃半环 |
| **中口** | 70°–150° | 标准战场 | 任意流派 |
| **窄口** | ≤ 70° | **密度爆点**：同样波数挤在小弧上 | AoE / 单点高伤 / 减速后集火 |

> 🔴 **窄口是这套设计里唯一的"爽点发生器"。** 一个 50° 的窄口，单位弧长上的怪密度是 150° 宽口的 3 倍 —— 这是熔炉（击杀爆炸、死亡爆炸）唯一能兑现的舞台。整条关卡链必须保证「前 3 关至少出现一次窄口」，否则熔炉玩家在第一章学不到自己阵营的爽点。

### 2.2 旋钮二 · 开口总宽（决定「全局密度」）

`open_deg = 360 − Σ脊宽`，红线下限 **300°**（`AC-R1`）。

- 开口越小 → 同样波数的怪挤在更小的环上 → **局部密度上升**（更难），且可建区被岩脊切得更多。
- 开口越大 → 摊得更薄 → 更考验覆盖而不是爆发。

这条轴的价值是**不需要动一个伤害数字就能调难度**。全链只用 300–332 这个区间就够，不要靠 `hp_growth` 加码。

### 2.3 旋钮三 · 脊的径向区间（决定「哪里不能建」）——本轮真正的新东西

现有 10 张图的岩脊全是 `r0≈24-32 → r1=58`，等于「外环一圈墙」。这只用到了这个旋钮的 1/3。`BuildGrid.buildable()` 的判定是 **角度 ∩ 径向双重命中**：

```
不可建 ⟺ 角度 ∈ [a0,a1] 且 半径 ∈ [r0,r1]
```

所以把 `r0/r1` 拉开，可以造出三种全新的地形：

| 地形 | 参数特征 | 玩家的体感 |
|---|---|---|
| **外墙** | `r0 24~32, r1 58` | 现状。只影响"外圈能不能站" |
| **中环孤墙** | `r0 14~16, r1 30~34` | 中圈被切一刀：墙内（r<14）能建但射程浪费，墙外（r>30）能建但离核心远，**中间那圈走廊直接消失** |
| **核心护壁** | `r0 8, r1 18` | 贴核心的一小块被抹掉：**"核心周边堆塔"这条无脑解被地形否决** |

渲染层 `monster_layer._sector_poly()` 已经按 `r0/r1` 画扇环 —— **中环墙会自动画成一段悬空峭壁，零新增渲染能力**。

### 2.4 红线（不能碰）

| 项 | 约束 | 来源 |
|---|---|---|
| `t_reach` / 寻路 / RNG | 一行不动 | 架构红线（改 = 金标本等价破产） |
| 开口总宽 | ≥ 300° | `AC-R1` |
| 岩脊 `r1` | ≤ 58（不越出生环 55 + 路肩） | `scene-map` §4 |
| 脊-弧互补 | 弧的 `a0` = 上一座脊的 `a1`（跨 0° +360） | `map_theta_deg()` 保序保测度前提 |
| 1-1 | **必须保持 `tri-fissure` 原表** | 它是回归与对照锚点 |
| `sites` 表 | 本轮**不改**（自由摆放模式下不影响可建判定，只影响视觉） | `free-placement.md` |

## 4. 逐关设计

> 每关三段：**几何签名**（数据）/ **取舍**（玩家要做什么决定）/ **常见错法**（预判玩家会怎么玩崩）。

### 1-1 余烬·初燃 · `tri-fissure`（保持不变）

- **几何**：脊 东南 18°–36°(18°) / 西 150°–164°(14°) / 北 254°–262°(8°)，全部 `r0 24-32 → 58`；开口 320°，三口 114 / 90 / 116。
- **取舍**：三个中口，没有爆点也没有主攻方向。玩家在这一关学到的是**"摊薄是有代价的"** —— 三面各放 1-2 座箭塔，还是赌南口（最宽）集中、赌另外两口漏得过？
- **为什么不动**：它是 300 局 MC 与全部回归断言的对照锚点。**1-1 一旦变形，"关卡变难了"和"引擎变了"就分不清了。**
- **常见错法**：把 10 塔均匀撒一圈 → 每座塔都打不满 → 第 7 波起崩。

### 1-2 余烬·聚流 · `south-sweep`

- **几何**：脊 北壁垒 `0°–24°`(24°) / 南壁垒 `240°–264°`(24°)，`r0 26 → 58`；开口 312°，两口 **216 / 96**。
- **取舍**：**从三面变成两面**。覆盖成本下降（口径少了），但南环 216° 极宽 —— 这段弧上的怪是"稀的"，塔放中间等于两头都打不满。真正的解法是**贴着 96° 北口打爆发、南环只做减速/拖延**。
- **设计意图**：这是熔炉玩家的第一次"聚火"训练。第一章不能一上来就给窄口，要先让他体验"口少了，我就能把塔堆在一起"。
- **常见错法**：把塔沿着 216° 弧均匀排开 → 塔均摊在长弧上，北口的 96° 无人集火。

### 1-3 余烬·成塔 · `choke-tri`

- **几何**：脊 东短脊 `0°–18°` / 西南壁 `188°–206°` / 北脊 `266°–284°`，`r0 30 → 58`；开口 306°，三口 **170 / 60 / 76**。
- **取舍**：**西侧 60° 窄口是整条第一章唯一的密度爆点**。把 AoE 塔堆在这个缺口前，一波怪进来就是一次连锁爆炸；代价是该方向的塔对另外 246° 完全无贡献。
- **设计意图**：本章毕业考。窄口 = 熔炉的爽点兑现处，玩家要在这里第一次感受到"我这一波全清了"。
- **常见错法**：把 60° 窄口当成"小口不用管"，结果窄口密度最高，最先破防。

### 2-1 霜线·初凝 · `twin-gate`

- **几何**：脊 东壁垒 `0°–24°` / 西壁垒 `180°–204°`，`r0 26 → 58`；开口 312°，两口 **156 / 156**（完全对称）。
- **取舍**：两端等宽对开。**对称带来一个难受的问题：你没有任何理由偏心，但你的塔不足以两面都强。** 霜序的答案是「两面都减速、只在一面集火」，而不是「两面平均输出」。
- **设计意图**：换阵营的第一课。减速塔的价值在"驻留时间"，而驻留时间在宽口上才有意义 —— 156° 的宽度正好让减速覆盖变成可算的账。
- **常见错法**：因为对称就两面各放 5 塔 → 两面都不够强 → 第 9 波两面同时漏。

### 2-2 霜线·封冻 · `mid-wall`（首个使用中环墙的关）

- **几何**：脊 东南断崖 `20°–34°`(14°) `r0 30→58` / 西断墙 `150°–164°`(14°) `r0 24→58` / **北中环墙 `240°–262°`(22°) `r0 14 → r1 30`**；开口 310°，三口 116 / 76 / 118。
- **取舍**：北面那 22° 楔形在中圈（r14–30）被抹掉。于是同一块地面被切成三个层级：
  - **r < 14（内圈）**：能建，但射程大半浪费在核心上；
  - **r14–30 该角区间**：**禁建**（墙本体）；
  - **r > 30（外圈）**：能建，但离核心远，怪已经走近了。
  玩家必须决定：**在墙的两端各堆一座（横向补位），还是在墙内侧做一层纵深（放弃横向）**。
- **设计意图**：霜序主场。Armor 慢速 + 中环墙 = 怪从墙外侧绕进来的那段时间，正好是减速塔能兑换成"多打几轮"的窗口。**纵深是霜序的语言，横向是熔炉的语言，这张图强迫玩家说前一种。**
- **常见错法**：把墙当成"装饰"，在墙内侧贴核心堆满 → 内圈射程浪费 + 墙外走廊无人管。

### 2-3 霜线·永冬 · `quad-diag`

- **几何**：四条脊各 14°，位于 `0° / 90° / 180° / 270°` 起，`r0 28 → 58`；开口 304°，四个 **斜向** 口各 76°（东南 / 西南 / 西北 / 东北）。
- **取舍**：四面持续压力。76° 是「中口偏窄」——**不是爆点，但四面都要有人**。霜序的解法是「两面减速 + 两面输出」的轮转，而不是四面对称。
- **为什么是斜口不是正口**：正口（东南西北）会让玩家形成"上下左右"的格子直觉；斜口配六边形网格，四个口恰好落在六个蜂窝方向之间 —— **没有哪个塔位天然"正对"某个口**，必须靠站位算角度。
- **常见错法**：四面对称布防 → 四面都半残；第 14 波起四面同时进装甲兵。

### 3-1 晶格·初织 · `penta`

- **几何**：五条脊各 8°，每 72° 一座，`r0 30 → 58`；开口 320°，五个 **64°** 口均布。
- **取舍**：**没有主攻方向**。任何"堆一处硬抗"的策略在这里直接失效 —— 五面各 64°，你放弃任意两面就是 40% 的漏怪量。枢网的答案是「长射程 + 少塔多覆盖」，用一座塔的射程同时够到两个口。
- **设计意图**：枢网主场的第一课，也是整条链上第一次"覆盖成本"超过"输出成本"。
- **常见错法**：把 10 塔按 2 塔/口 分完（正好 10）→ 五面都刚好不够，且没有预备队。

### 3-2 晶格·致密 · `corridor`（双中环墙）

- **几何**：脊 北壁 `30°–42°`(12°) `r0 30→58` / **东中环 `120°–135°`(15°) `r0 16 → 34`** / 南壁 `210°–222°`(12°) `r0 30→58` / **西中环 `300°–315°`(15°) `r0 16 → 34`**；开口 306°，四口 78 / 75 / 78 / 75。
- **取舍**：两道中环墙**对角放置**，把中圈切成两条斜向走廊。走廊的**入口**（外圈、正对墙端）与**内侧**（内圈、墙背后）收益差最大 —— 一座塔站在墙端能同时打两个方向的来怪，站在墙背后则只能打一条线。
- **设计意图**：全链最"考站位"的一张图。枢网的长射程在这里第一次能兑现成"一塔两用"。
- **常见错法**：沿两条走廊对称布防 → 忘了墙端那个"一塔两用"的黄金点。

### 3-3 晶格·满阵 · `hexa`

- **几何**：六条脊各 10°，每 60° 一座，`r0 30 → 58`；开口 **300°（红线下限）**，六个 **50°** 口均布。
- **取舍**：极限。六口 + 最窄开口 = 怪最密、方向最多。10 塔对 6 口，**边界上必然有 1–2 个口是靠"漏过去再用内圈补"来处理的**，这一关考的是"放弃得对不对"。
- **设计意图**：第三章毕业考。同时也是**「不可能完美守」的第一次明示** —— 通关条件只是核心不归零，不是零漏怪。
- **常见错法**：追求六面全封 → 塔数不够，六面都薄，第 12 波起同时崩。

### 4-1 核心·终局 · `fusion-core`（核心护壁）

- **几何**：脊 东南断崖 `14°–38°`(24°) `r0 30→58` / 西断墙 `150°–166°`(16°) `r0 24→58` / 北短脊 `254°–264°`(10°) `r0 32→58` / **核心护壁 `300°–310°`(10°) `r0 8 → 18`**；开口 **300°**，四口 112 / 88 / **36** / 64。
- **取舍**：三件东西同时上：
  1. 开口压到 300° 红线下限（最密）；
  2. 一个 **36° 的极窄口**（处刑口，密度是 112° 宽口的 3 倍）；
  3. **核心护壁**：贴核心的 10° 楔形在 r8–18 被抹掉 —— **"核心周边堆一排塔"这条无脑解被地形否决**，最后一关必须把防线外推。
- **设计意图**：把三章的地形语言（外墙 / 中环墙 / 核心护壁）叠在一张图上，让终局是"你学会的三种地形同时出现"。
- **常见错法**：按前三章的习惯往核心附近收拢 → 护壁那一侧没有塔位，36° 处刑口直接怼到核心。

## 6. 验证计划（先定"怎么算通过"，再上线）

| 层 | 验什么 | 方法 | 通过标准 |
|---|---|---|---|
| **L1 数据** | 脊-弧互补 / 开口 ≥300 / `r1 ≤58` | 扩 `MapVariants.validate_arcs()` 到 10 张全跑（已有函数，只需遍历） | 10/10 ok |
| **L2 几何** | 出生角不出脊、映射保序保测度 | `test_suite_radial.gd` E-M3 口径逐图对拍 | 零台阶、零出脊 |
| **L3 可建** | 中环墙真的挡住中圈 | 断言：墙角区间内 `r0+1` 与 `r1-1` 两半径的格点 `buildable()==false`，`r0-2` 与 `r1+2` 为 true | 双层边界全对 |
| **L4 平衡** | 每图 B 起飞率 | 300 局 MC（`scene-map` §11 纪律，逐图继承） | `[待定]` 建议 0.60–0.85 区间，**不做"每关都 0.8"** |
| **L5 体感** | 玩家能否一句话说出三张图的区别 | 5 人盲测：给 1-1 / 2-2 / 3-3 三张图，问"哪张最好守" | ≥4 人排序正确 |

> 🔴 **L4 的口径提醒**：`campaign-progression.md` R2 说"每张变体都要跑 300 局 MC"。这里的判据要改一下 —— **后段关卡本来就该更难**，用统一的 `B ≥ 0.80` 会把 3-3 判成设计错误。建议改成**逐关目标区间**（见 §8 Q3），并把"邻关之间落差 ≤ 15pp"作为曲线连贯性的判据。

## 7. 失败信号

| 信号 | 观测 | 判定 | 处方 |
|---|---|---|---|
| **A · 图纸无感** | 盲测中玩家无法指出三张图的区别 | 差异还是不够（可能又退回"改度数"） | 加大口数差 / 引入中环墙 |
| **B · 中环墙变装饰** | 玩家从不走进墙内侧，也不在墙端建塔 | `r0` 太小（墙太靠外）或 `r1` 太大（墙太宽） | 把墙往里推 2–4 单位，或缩短径向跨度 |
| **C · 窄口成唯一解** | 所有流派都只打窄口，宽口全靠漏 | 宽口税太重 | 收窄宽口 / 给宽口加"绕行时间"（不改运动学，只改弧长分布） |
| **D · 难度断层** | 某关 B 起飞率比前一关掉 > 25pp | 不是"变难"，是"跳变" | 先调开口总宽（±6°），不要动 `hp_growth` |
| **E · 阵营失配** | 章节主场阵营在该章的起飞率反而低于其他阵营 | 地图没有兑现"定价器"作用 | 回炉该章地图的口宽组合 |
