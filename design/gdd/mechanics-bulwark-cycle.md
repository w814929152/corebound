## 0. 结论前置（给赶时间的人）

1. 🏆 **最终形态 = 一个机制**：**战斗中被动复活 `M-1`**（波内自动重启），定稿参数 **`N = 0.5s` / `K = 1` / 资格 = 死亡时刻快照「暴露位 & 非 carry」 / 满血 / 原地**。它把塔死亡的空窗期从"不可承受"变成"可承受"，**结构改善真实（塔死亡 −5~6%、漏怪窗口 −0.86、在线率 +4.1pp）且零胜率代价**（V-8 B1 vs B0：Δ_surv +0.0128，ns-positive）。
2. 🔴 **残响 `Reverb`（死塔减速场）不采纳** —— V-8 的 B4 臂是**混淆臂**（残响时长 ≡ 肉盾整波离线时长，负向来自离线罚而非残响）；V-8b 去混淆后（复活 ON、复活参数四臂逐位相同）**全剂量域无正向胜率边际**（V1 +0.008 / V2 −0.005 / V3 −0.031，全部 ns），且剂量拉 6.18× 胜率不升反降 → **它是"次感知型"不是"剂量不足型"**。🟢 但它**没有被证明有害**，且世界观同源性（§2.4 ① 的外化）**未被推翻** → 未来可作纯体验层重启（§11）。
3. ⚪ **K 成长玩法挂起**（`K ∝ h` 是**未验证的独立维度**，本轮不主张、不实现）；🔴 **(C2) 残骸嘲讽维持否决**（用户"死亡的塔不会嘲讽"是对的，两轮数据均不支持翻案）。

> 🟢 **玩家最终得到什么**：**一个"肉盾会自己爬起来"的循环** —— 塔死亡仍是真惩罚（失去 DPS + 吸火），但暴露位肉盾会在 0.5 秒内被动重启、每波限一次，**死亡从纯负面变成"带一次免费机会的负面"，而水仍然在流、惩罚仍然真实、玩家不需要多读任何一个新量。**

## 1. 概述（Overview）

### 1.1 一句话

> **塔在战斗中倒下后，若它倒下的位置是暴露位、且它不是本局输出最高的那座（carry），系统会在 `N` 秒后自动把它原地满血重启，每波每塔限 `K` 次；次数用尽后，它回到 §2.3 的波次间三选一（修 / 拆 / 放着）。**

### 1.2 它解决什么问题（问题陈述）

| 问题 | 出处 | 本机制的解 |
|---|---|---|
| **塔死亡是正反馈螺旋的不可脱出环节**（修好的塔 96.78% 后续波又被打停；修完连一整波都活不过） | V-7（`v7-final-adjudication.md` §3 / R-T10） | 不用"修"来脱出（修 = 玩家在安全窗的**第二层代价**），而是在**战斗内**给一次系统侧的自动重启 → 螺旋在**它发生的当场**被打断一次 |
| **空窗期（塔 Disabled → 波末）危害不可承受**：怪解锁直冲核心 | v1 §5 / v2 §2.1 | 复活把空窗从"整波"压缩到 `N = 0.5s` → 该塔的 DPS 与吸火回归 |
| **A 单核流冗余不足**（R-B3）：肉盾最需要的路径（A，`max_towers=2`）恰恰最没补位空间 | v1 §5 ③ / §10 | 复活**不依赖冗余**（单塔自身即可重启）→ R-B3 解除（§2.6） |

### 1.3 与支柱的兑现关系

| 支柱 | 兑现方式 | 判定 |
|---|---|---|
| **P1 不动如山 — 站位即策略** | 资格闸门用**死亡时刻的暴露位快照** → 「**站哪儿决定了你倒下后会不会自己起来**」→ 站位第三维（暴露度）在**死亡时刻**仍起作用 | 🟢 **强化**（且零新增资产，复用已有 `is_exposed`） |
| **P2 雪崩无上限** | 复活只恢复**这座塔原有的** DPS（`hp = hp_max`，不改任何层数/乘区）→ 不新增上限、不破雪崩；🟢 且它让"成型期塔死导致 DPS 崩"这条螺旋被剪断一次 → 与雪崩**同向** | 🟢 不冲突 |
| **P3 每局一个新解** | 是否触发、触发几次，由「本局站位 × 仇恨走向 × 死亡时点」决定 → 每局不同 | 🟢 新增随机变量 |
| **P4 零操作，高密度 — 决策而非动作** | 🔴 **零玩家输入**（系统自动）、🔴 **零战斗内读数**（只给塔体动效）→ APM 增量 = 0；决策密度增量 = 0（波次间三选一**一字未改**） | 🟢 **零违反** |
| 概念 §4.1 **归因清晰** | 玩家能说清"它站得太靠路 → 它挨打 → 它会自己起来一次" | 🟡 有**新风险 R-B20**（半数死亡事件被闸门拒绝 → "有时起来有时不起来"的归因模糊），见 §13 |

## 2. 核心机制（Mechanics）

### 2.1 最终形态：塔的「死」的四段时间线（🔴 权威定义）

```
波内 t0 ──────────── 塔 HP 归零 ─────────────────────────────────→ 波末
             │                                                    │
             ▼                                                    ▼
       ┌───────────┐  N=0.5s   ┌───────────┐  K 用尽后再死  ┌──────────────────┐
       │ ① 停机    │ ────────► │ ② 重启    │ ────────────► │ ③ 终局 Disabled  │
       │ Disabled  │  （自动） │ 恢复主动  │               │ 直到波次间       │
       │ 资格判定  │           │ K 余量 -1 │               │                  │
       └───────────┘           └───────────┘               └──────────────────┘
             │                       │                              │
             │ 闸门拒绝（carry /     │ 重回仇恨池                     │
             │ 非暴露位）→ 直接进 ③  │ （零新代码，E-T5 自然生效）     │
                                                                     ▼
                                                   波次间：§2.3 三选一（修 / 拆 / 放着）
                                                          🔴 定性一字不改
```

| 段 | 状态 | 主动（DPS / 吸火） | 谁决定 |
|---|---|---|---|
| **① 停机** | `disabled = true`，`K` 未用尽，资格 ✅ | ❌ 停输出 · ❌ 不被选为仇恨目标（E-T5） | **系统**（自动） |
| **② 重启** | `disabled = false`，`hp = hp_max`，`K` 余量 −1 | ✅ 恢复 · ✅ 自动重回仇恨池 | **系统**（自动，零玩家输入） |
| **③ 终局 Disabled** | `disabled = true`（闸门拒绝 或 `K` 用尽） | ❌ | 系统 → **波次间交给玩家**（§2.3） |
| **④ 波次间** | 保持或解除 | — | **玩家**（§2.3 三选一，一字不改） |

> 🏆 **这张表是本定稿的核心**：**一座塔在任一时刻，要么主动、要么停机，永不同时** → 状态与效果一一对应 → 认知负担最小（无"半死不活"的第 3 态）。🔴 **注意：残响砍除后，停机态不再附带任何正向效果** —— 惩罚是干净的。

### 2.2 🏆 机制 M-1 · 战斗中被动复活（**采纳 · 本 GDD 唯一落地机制**）

| 项 | 定稿规格 | 依据 |
|---|---|---|
| **发起者** | 🟢 **系统**（自动 / 被动），**零玩家输入** | 用户拍板「被动触发」；T-C1 L1 输入层合规（v2 §3.2 三层检验 L1/L2/L3 全过）。🟢 **2026-10-09 升格**：该合规结论已由上游写成**显式豁免条款 `T-E1`**（`mechanics-tower-life-death` **§2.2.1**）→ 本机制是 `T-E1` 的**唯一**引用方；🔴 豁免三要件 = 系统发起 ∧ 对象为死亡时刻「暴露位 & 非 carry」∧ 战斗内被动且零择时提示 |
| **时点** | 塔 `Disabled` 后 **`N` 秒**（波内即时，不是波首） | Q-B0 = 战斗中 |
| **N（复活延迟）** | ✅ **`0.5 s`**（定稿） | V-8：N_short(0.5s) Δ +0.0128 ≈ N_long(2.0s) Δ +0.0081，差 0.005 ≪ 判读线 0.035 → **两档无差异，取短档求手感爽脆** |
| **K（每波次数上限）** | ✅ **`1`**（每波两条命，有限非无限） | Q-B0″；V-8 / V-8b 唯一测过的 K；`K` 是防永动机的主要闸门（R-B10） |
| **资格（🔴 红线）** | **死亡时刻快照：`is_exposed == true` 且 非 `h` 最高（非 carry）** | §2.2.1 安全红线 |
| **效果** | 清 `disabled` + `hp = hp_max`（复用 `_clear_disabled`，与 §2.3 `Repair` 同口径，E-T6） | Q-B11 = (a) 满血 |
| **位置** | 🔴 **原地**（`Disabled` 塔不可移动 → 位置恒等） | Q-B13 = (a) |
| **重启 HP** | 满血（`hp = hp_max`），**不改层数、不动装配卡、不重算 `E_i`/`κ`/`N_tower`** | 与 §2.4 ① / §2.3 理由 3 同口径 |
| **处置弹窗** | 波内自动重启过的**不弹**；`K` 用尽的**照常弹** | Q-B12 |
| **开关** | `mvp_config :: repair_on_disable` = `9`（战斗内即时）/`11`（波首对照）；🔴 **默认恒 `0`** | 金标本零改动 |

#### 2.2.1 🔴 安全红线：资格判定（不可降级）

| 项 | 内容 |
|---|---|
| 判定式 | `death_exposed == true` **且** `death_carry == false`（复用 `_PathGeometry.slot_exposure[_radial]()` + `h` 最高判定，**零新字段**） |
| 快照时点 | 🔴 **死亡时刻**（`_death_snapshot`）。🟢 因 `Disabled` 塔不可移动 → 位置恒等 → 无需处理"移动后按哪儿判" |
| 硬断言 | 🔴 **`revive_misq` 必须恒 = 0**（= 已落地的重启违反资格）。非 0 → 该臂/该构建作废，修后重跑。V-8 / V-8b **全臂 PASS** |
| 为什么是红线 | 战斗内即时复活下，carry 被误判 ⇒ carry 在同一波内被反复重启 ⇒ DPS 反复归零又满血 ⇒ **塔死亡机制被实质取消**（不是"稀释惩罚"，是"取消机制"）→ 与 R-B10 同族 |
| 🟡 校准事实（不是 bug） | bulwark 口径下 **carry 并非"恒不挨打"**：`carry_death ≈ 0.65 次/局` vs `合格死亡 ≈ 0.64 次/局` → 闸门**正确拒绝约一半**死亡事件。🔴 v2 §7.1「carry 恒不挨打」假设**已正式撤回** |

#### 2.2.2 代价体系（两层，各就各位 —— 用户 P-1 / P-2 同时兑现）

| 层 | 时点 | 代价 | 发起者 |
|---|---|---|---|
| **第一层 · 战斗内** | 波内 | ① **`N = 0.5s` 延迟**（怪前进约 `N / t_reach` 的路径比）+ ② **`K = 1` 次数上界** | 系统 |
| **第二层 · 波次间** | 安全窗 | ③ **`repair_cost`（花钱）** + ④ **占 1 个动作位** | 玩家（§2.3，一字不改） |

> 🟢 **两层是互补不是竞争**：修 = 让这座塔**现在**活；复活 = 让它**本波内**多死一次也不倒 → 面向不同时间尺度。🟡 该判断**未经扫参验证**（V-8b 只扫残响，`H_STEP` 轮未跑）→ 见 §11。

### 2.3 🔴 机制 B · 残响 `Reverb`（**不采纳 · 决策留档**）

| 项 | 内容 |
|---|---|
| 原设计 | 死塔保留被动：Disabled 塔在半径 `R_reverb` 内对怪施加减速 `s_reverb`（`t_remain -= DT × (1 − s)`），绑定到 `disabled` 状态，波次间 OFF |
| 原定性依据 | 🏆 **它是已定稿 §2.4 ① 的推论**：§2.4 ① 定「Disabled 塔仍供 `h_j`」，理由是「停机但**结构仍在** → 谐波体依然存在」。同一物理前提，**向内**是 `h_j`（供共鸣），**向外**就是"残响"（辐射场）→ 零新增世界观 |

| 裁决依据 | V-8b 去混淆实证：**全剂量域无正向胜率边际**（§9.3）+ 第 7 个需读量的认知过载（R-B19） |
| 🔴 三条边界 | ① **不是"被证明有害"** —— V3 的 −0.031 是二次对照、多重校正后不稳健；正确表述是「**无正向价值**」。② **不推翻 §4.1 世界观同源性**。③ **不动 §2.3 / §2.4 ①** |
| 未来 | 🟡 可作**纯体验层**重启（零玩法数值、零胜率期望），需用户显式拍板；默认为砍（§11.2） |

### 2.4 ⚪ 机制 C · 增加复活次数 `K`（**挂起 · 未验证的独立维度**）

| 项 | 内容 |
|---|---|
| 原设计（用户原话「可以有相应的玩法来增加复活次数」） | L1 **`K ∝ h` 涌现**（`K_i = K_base + floor(h_i / H_STEP)`）主推 + L2 T1 卡「冗余核心」备选；L3 波次间买充能、L4 原型属性**不推荐** |
| 原设计理由 | 与 P2「失控必须被 earned」三次同族（`HP ∝ h^0.6` 是耐久侧表达，`K ∝ h` 是同一语义的第三次表达）；🟢 补上"肉盾塔是纯成本"这个洞（投 `h` → 换重启次数） |
| **状态** | ⚪ **挂起 —— 本轮不主张、不实现** |

## 4. 公式（Formulas）

> 🔴 全部公式标变量与单位；下标 `i` = 塔，`w` = 波次，`t` = 波内时间（秒）。

### F-1 资格判定（死亡时刻快照，一次性求值）

```
death_exposed_i  = slot_exposure( pos(slot_i), path )        # 复用 _PathGeometry，零新字段
death_carry_i    = ( h_i == max_j h_j )                       # 死亡时刻的 h 快照
eligible_i       = death_exposed_i AND ( NOT death_carry_i )
```
- 单位：布尔（无量纲）。求值时刻：`hp_i` 由 `> 0` 变为 `≤ 0` 的那一帧。

### F-2 重启触发条件（每个 `DT` 步进判定一次）

```
IF ( w > WARMUP ) AND ( disabled_i == true )
   AND ( eligible_i == true )                                # F-1，死亡时刻快照
   AND ( revive_used_w[i] < K )                              # K = 1，次
   AND ( revive_t_disabled[i] >= N )                         # N = 0.5，秒
THEN  revive( i )
```
- `revive_t_disabled[i]` 单位：**秒**，每 `DT` 累加 `DT`。

### F-3 重启结算

```
disabled_i      ← false
hp_i            ← hp_max_i                                   # HP 单位，满血
revive_used_w[i]← revive_used_w[i] + 1                       # 次，本波内计数
revived_ever_i  ← 1
# 🔴 不动：h_i / attach / E_i / κ / N_tower / Coverage / 7 乘区（Disabled_i 因子归 1）
```

### F-4 波次重置（每波开始）

```
revive_used_w[i] ← 0        ( ∀ i )                          # K 是「每波」配额，不是每局
revive_t_disabled[i] ← 0
# 🔴 revived_ever / death_* 不清（跨波语义： revived_ever 是本局波浪标记）
```

### F-5 塔 HP（引用既有定稿，本 GDD 不改）

```
HP_i = HP0 × h_i^0.6        # HP0 = 120（HP 单位），h_i 无量纲层数
```

### F-6 空窗期路径损失（复活延迟的代价，设计侧估算）

```
Δpath( N ) ≈ N / t_reach                                     # 无量纲（占全程路径的比例）
```
- `N` 秒；`t_reach` = 怪从出生走到核心的秒数（口径与 `N` 的"5% × t_reach"参数化同源，实测换算得 `N_short = 0.5s` / `N_long = 2.0s`）。

### F-7 🟡 未来（挂起，未验证）—— K 成长

```
K_i = K_base + floor( h_i / H_STEP )      # K 次；H_STEP = PLACEHOLDER，未扫
```
- 🔴 **未采纳、未验证**。K 的定稿值恒为 `K_base = 1`。

### F-8 胜率对照（验证口径，非游戏内公式）

```
Δ_surv( arm vs base ) = p_arm − p_base                        # 无量纲
SE = sqrt( p_arm(1−p_arm)/n_arm + p_base(1−p_base)/n_base )   # 独立两比例（配对破功时）
95% CI = Δ ± 1.96 × SE ；判读线 |Δ| > 0.035
```

## 10. 关键教训（设计理论沉淀 · 供后续机制评审复用）

| # | 教训 | 出处 | 可复用形式 |
|---|---|---|---|
| **L-1** | 🔴 **范畴错误（资产修复 vs 消耗品循环）** —— V-7 的 FREE/PRICED 把塔当"**可修复的资产**"（修 = 恢复原状），数据证伪（96.78% 再被打停、restore-events=0）；正确范畴是"**消耗品循环**"：塔会倒、倒下有代价、代价分层（战斗内 `N`+`K` / 波次间钱+动作位）。**范畴错了，参数怎么调都是错的** | V-7 | 任何"补救类"机制先问：**它在修资产，还是在管消耗品？** |
| **L-2** | 🔴 **⊖ 符号由角色决定** —— 同一个"恢复"动作，对 carry 是 ⊕（DPS 回归）还是 ⊖（重新暴露仇恨）取决于**它在阵型中的角色**；V-7 FREE 臂显著有害（−3.85pp）正是因为对全场无差别恢复 → ⊖ 项压过 ⊕ 项。**资格闸门（暴露位 & 非 carry）就是把符号按角色分开** | V-7 / v2 §3.4 | 无差别 buff 前先做**角色分解** |
| **L-3** | 🔴 **混淆臂（两个参数共变焊死）** —— B4 把"残响全程在场"与"肉盾整波离线"焊在一起 → 负向信号**不可归因**。🔴 **识别法**：若某臂的"处理变量"与"某代价"严格共变，它就不是净效应臂。**解法**：按住混淆变量（V-8b 的四臂复活参数逐位相同） | V-8 / v3 R-B16 | 臂设计检查表：**每个臂是否只改变一个可归因变量？** |
| **L-4** | 🔴 **`gap_leak↓ ≠ 胜率↑`（机制活动量 ≠ 结果量）** —— B3 把漏怪窗口压得最狠（z=−2.97）却几乎不动胜率（z=+0.19）。🔴 **纪律**：机制量只能证明"机制按设计工作了"，**不得**作为胜率代理引用 | V-8 §5 | 判据分层：主判据（结果）/ 机制量（活动）/ 护栏（失守） |
| **L-5** | 🔴 **carry 非恒不挨打** —— 直觉假设"carry 站后排所以不会死"在 bulwark 口径下**不成立**（`carry_death ≈ 0.65` vs 合格 `≈ 0.64`/局）→ 闸门覆盖率只有预期一半。🟢 这是**校准更新不是 bug**（`revive_misq = 0`） | V-8 §6.1 | 资格类机制必须**实测量化覆盖率**，不能靠直觉估 |
| **L-6** | 🟡 **"次感知型"机制注定了无价值** —— 加剂量 6.18× 仍动不了胜率 = 覆盖太薄（4 只/局）→ 它不是"调参能救"，是"结构够不着"。🔴 **判据**：若机制量随剂量线性上升而结果量不动 → **判次感知，不要再加剂量** | V-8b | 剂量响应曲线：机制量↑ + 结果量平 = **砍** |
| **L-7** | 🟡 **"没价值" ≠ "有害"，交代必须分清楚** —— 砍残响的依据是"全剂量域无正向边际 + 认知过载"，**不是**"证明有害"（V3 的 −0.031 多重校正后不稳健）。🔴 两种交代对用户的后续决策完全不同（一个是"别做"，一个是"做了会坏"） | V-8b §2.3 / §8 | 裁决文档必须写**依据类型 + 边界** |
| **L-8** | 🟡 **不加跑的勇气** —— 已有数据足以支撑决策时，加跑是**零决策增量的消耗**。🔴 **判据**：先算"翻倍局数后效应量能否越过判读线"，不能则不加跑 | V-8b §4 | 加跑前必做**功效估算** |
| **L-9** | 🟢 **"堵" vs "疏"是范畴判断，不是强度判断** —— (C2) 嘲讽 = 消灭空窗（堵，与永动机同族）；复活/残响 = 让空窗可承受（疏）。🔴 强度调低也救不了"堵"，因为它**取消了机制**而非**降低斜率** | v3 §7.1 | 空窗/负面窗口类设计先定范畴 |
| **L-10** | 🟢 **世界观同源性可以独立于玩法价值存活** —— 残响作为 §2.4 ① 的外化**未被推翻**，只是玩法上不采纳 → §2.4 ① 保持定稿，残响留作未来可重启项。🔴 **砍玩法层 ≠ 砍世界观层** | V-8b §6 / §7.2 | 砍机制时**分层砍**，别把地基一起埋了 |
