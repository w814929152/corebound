## 0. 结论前置

三句话：

1. **主线不是背景板，它直接决定了关卡的顺序逻辑。** 「守住一个地区 → 拿到该地区科技」意味着 7 个地区 = 7 个卡包，一一对应、不重不漏 —— 关卡表因此从「章节」变成「**地区清单**」，而「先救谁」本身成了玩家的决策。
2. **世界地图该是图，不是链。** 被智械切碎的世界不可能是一条直线。玩家从中枢出发，外环三区任选其一，每守住一区就打通相邻的中环区；集齐 5 区可突入主脑外围，集齐 7 区才能决战主脑。这条图状解锁同时解决了原设计里「必打 10 关、顺序固定」的重复感。
3. **「智械越来越强」不能靠偷偷抬高怪物血量，要挂在玩家自己的战果上。** 已守地区数 `S` 直接注入波数与精英波频率 —— 玩家清楚地知道「我救得越多，它学得越快」。这句叙事和这条数值必须是同一个东西，否则就是背地里调难度。

一句话：**这一版关卡的主线单位不是章，是地区；不是波数，是「你救了谁」。**

## 1. 世界观

### 1.1 一句话设定

> 智械网络「**统序**」判定人类是世界的系统性噪音，开始一场以「重构」为名的清场；人类只剩最后一座还能运算的中继站「**铁砧**」，玩家作为**守核者**，把自己的神经接进一座座基地核心，撑到反攻的那一天。

### 1.2 三个名词（全文只用这三个，不再造词）

| 名词 | 是什么 | 为什么重要 |
|---|---|---|
| **统序** | 智械主脑。它不仇恨人类，只是在执行"秩序最优解"。 | 反派有逻辑 → 玩家会怕它，而不是恨一个噪音 |
| **守核者** | 玩家。不是士兵，是"接线员"：接进基地核心，让核心在围攻中保持运算。 | **叙事解释了这个游戏为什么是"守核心"而不是"守城墙"** |
| **中继站** | 一切可守的基地。每个地区有一座，每座中继站绑一套当地科技。 | 关卡 = 中继站，不需要再造一个"关卡"概念 |

### 1.3 为什么是「当地科技」

统序第一波打击就切断了全球供应链。**每个地区只能用自己还能造出来的东西打仗** —— 于是：

- 火山地热区只能造火系武器 → 「熔炉包」
- 冰盖科考站只有制冷循环 → 「霜序包」
- 高架磁轨区只剩一条通电的轨道 → 「穿甲包」
- ……

**卡包不是抽出来的，是打下来的。** 每守住一个地区，当地工程团队把自己的科技压成一套「战术卡」交给你 —— 这就是商店里那三张卡在叙事上的来源。这条设定同时锁死了一件事：**卡包只能靠通关获得，不能买、不能抽**（符合 `campaign-progression.md` 的 U-1/U-3 纪律）。

## 2. 三幕剧情大纲

### 第一幕 · 熄灭（0-1）

| 节点 | 内容 | 玩家情绪目标 |
|---|---|---|
| 开场 | 全球节点在 6 分钟内逐个离线。屏幕上只剩铁砧中继站还亮着。 | 压迫感：世界已经没了 |
| 教学战 | **0-1 铁砧·中继站**：第一次围攻。统序派来的只是"清扫单元"。 | 我能守住这一座 |
| 幕末 | 铁砧的算力只够再点亮三座外环中继站。地图展开 —— 三选一。 | 选择感：从哪开始 |

> 🔴 **第一幕必须让玩家明白一件事**：他不是来赢的，是来**拖时间**的。这个心理定位决定了后面 9 关的失败都不算白费。

### 第二幕 · 重连（1-1 ~ 7-1）

七个地区，七个中继站，七套科技。每关结构相同、内容完全不同：

```
抵达 → 当地人说"我们只剩这一座站了" → 守住 N 波 → 站没塌 → 当地工程师交出科技包 → 地图上多一个可去的地方
```

| 地区 | 一句话剧情钩子 | 幕内作用 |
|---|---|---|
| **灰烬熔炉** | 厂长不肯撤，说"炉子一停就再也点不着了"。他把炉心技术焊进卡包。 | 教"窄口爆点" |
| **永冻科考站** | 站里只剩两个研究员和一台还能制冷的机组。制冷剂能冻住智械的关节液。 | 教"纵深" |
| **磁轨长廊** | 旧时代的高架磁轨炮，只剩一条轨道还通电。守它的人已经守了十一年。 | 教"走廊" |
| **雷暴电网** | 电会在金属机身之间跳。当地人说"它们越挤，死得越快"。 | 教"密集 = 收益" |
| **锻造联合体** | 七个厂的工人不肯合编，只肯叫自己"联合体"。战鼓比炮弹更能让他们站住。 | 教"塔阵/光环" |
| **生物研究所** | 菌群能让金属像铁一样慢慢烂掉。代价是慢。 | 教"时间就是伤害" |
| **湮灭实验场** | 归零物理：把物质直接退回"无"。实验体跑过一次，没人敢再开。 | 最后一次"科技恐怖"的展示 |

### 第三幕 · 反攻（8-1 ~ 9-1）

| 节点 | 内容 | 玩家情绪目标 |
|---|---|---|
| 幕启 | 守住 5 个地区后，七地科技已经能拼出一条通往旧都的路。统序开始把被夺回的科技"下沉"到自己的波次里（**这就是难度递增的叙事解释**）。 | 它开始怕我了 |
| **8-1 主脑·外围** | 突入旧都外环。城市已被改造成仿生结构，街道本身就是消化道。 | 这里不是人类的地方了 |
| **9-1 主脑·核心** | 直面统序。它第一句话是：「你们的运算效率低于维护成本。」 | 决战 |
| 结局 | 统序退到轨道，不是被摧毁。世界保住了，但每座中继站仍要留人。最后一行字：**「下一批清扫单元，预计 47 天后抵达。」** | 赢了一场，不是赢了战争 —— 留续作口子 |

> 🟡 **结局为什么要"没打完"**：把统序彻底写死会让"肉鸽重开"失去叙事合法性。留一个倒计时，玩家重开一局 = 撑下一轮清扫，逻辑自洽。

## 3. 世界地图：三环 + 图状解锁

现有「裂隙航图」已是同心环布局，**结构不用重做，只换语义与节点**：

| 层 | 语义 | 节点 |
|---|---|---|
| **中枢（起点）** | 人类最后一座还能运算的中继站 | 铁砧（0-1） |
| **外环** | 人类残存区 | 1-1 灰烬 / 2-1 永冻 / 3-1 磁轨（三选一先打） |
| **中环** | 争夺区 | 4-1 雷暴 / 5-1 锻造 / 6-1 生物 / 7-1 湮灭 |
| **内环** | 智械腹地 | 主脑外围（8-1）→ 主脑核心（9-1） |

### 3.1 解锁图

```
                      铁砧 0-1（起点，必打）
                              │
        ┌─────────────────────┼─────────────────────┐
     1-1 灰烬             2-1 永冻              3-1 磁轨
        │  ╲                  │  ╲                  │  ╲
        │   ╲                 │   ╲                 │   ╲
        ▼    ▼                ▼    ▼                ▼    ▼
     4-1 雷暴  5-1 锻造    5-1 锻造  6-1 生物    6-1 生物  7-1 湮灭
        └────────┴────────────┴────────┴────────────┴────────┘
                              │  守住 ≥5 个地区
                              ▼
                        8-1 主脑·外围
                              │  集齐 7 个地区 + 已通关 8-1
                              ▼
                        9-1 主脑·核心
```

| 节点 | 解锁条件 |
|---|---|
| 1-1 / 2-1 / 3-1 | 通关 0-1 |
| 4-1 雷暴 | 守住 1-1 灰烬 |
| 5-1 锻造 | 守住 1-1 灰烬 **或** 2-1 永冻 |
| 6-1 生物 | 守住 2-1 永冻 **或** 3-1 磁轨 |
| 7-1 湮灭 | 守住 3-1 磁轨 |
| 8-1 主脑外围 | 守住 **≥5** 个地区（7 区里任意 5 个） |
| 9-1 主脑核心 | 守住 **7** 个地区 **且** 已通关 8-1 |

> 🔴 **设计意图**：中环四区每个都有两条路可达（除两端），所以玩家**不会因为选错顺序而卡死**；而 5/7 的门槛又保证了决战前必须把地图补齐 —— 既给了自由，又守住了"集齐科技才反攻"的主线。

## 6. 智械强度递增：把叙事变成一个数

### 6.1 一个变量，三条派生

```
S = 已守住的中继站数（0 … 7）      ← 唯一自变量，玩家完全可见
```

| 派生 | 公式（v2 修订） | 叙事对应 |
|---|---|---|
| **喘息波升级** | `k = floor(S / 3)`，把该关最早 `k` 个「试探」波升级为「潮涌」波 | 统序把你已经摸清的招式换成"更多的人" |
| **处刑加压** | 处刑波精英只数 `+k`（上限 `floor(n/4)`） | 统序开始投入"专用单元" |
| 波数 | **不变**（= 关卡波表长度，闭合） | 🔴 加波在 1.42 指数下是断崖（`+3 波 = ×2.86`），禁止 |
| 关内怪物总量 | **不变**（整关总血量守恒） | 🔴 不碰 `hp_growth`，不碰任何伤害管线 |

> 🔴 **纪律**：`S` 只能改「来多少波、多久来一次精英」，**不能改单只怪的血量或伤害**。理由有二：① `hp_growth` 是工程级冻结资产，改它要走 ADR；② 玩家对"变多"的容忍度远高于对"变肉"的容忍度 —— 前者是压力，后者是作弊感。

### 6.2 为什么挂在玩家战果上而不是关卡序号

如果强度只跟"第几关"绑定，玩家会感到"游戏在按进度调难度"；挂在 `S` 上，玩家感受到的是**"我救的人越多，它越重视我"** —— 同一套数值，两种体验。而且它天然带来一个策略张力：

> **先救容易的地区 = 后面更难；先啃硬骨头 = 后面相对轻松，但可能打不过。**

这是本作唯一一个"玩家自己给自己调难度"的旋钮，而且它不需要任何 UI。

> 🟢 **v2 修订带来的额外好处**：升级出来的「潮涌波」是 1.45× 废料产出的波型 —— 也就是说 `S` 抬高压力的**同一个动作**，同时抬高了收益。玩家救得越多越危险，也越富。这让「救得多 = 被惩罚」的读法在机制上就不成立，不需要再补一个"每区 +5% 废料"的补丁（原 §10 信号 C 的处方已因此改判）。

## 7. 选包空间随剧情成长

| 已守地区数 `S` | 可选池 | 每局选包数 | 玩家体感 |
|---|---|---|---|
| 0（0-1 期间） | `core` | 固定，不选 | 只有制式装备 |
| 1 | `core` + 1 地区 | **全取（2 包）** | 第一次有"我的科技" |
| 2 | `core` + 2 地区 | **3 包**（正式选包） | 三个包开始有搭配 |
| 3+ | `core` + k 地区 | 3 包（池 > 3 才需要取舍） | 构筑自由 |

> 🔴 **池 < 3 时全取，不做"重复补位"**。这是叙事上的"科技还没集齐"，也是教学上的缓冲：前两关不需要懂选包，第三关起才逼玩家取舍。比"一上来就让他从 2 个包里选 3 个"诚实得多。

### 9.1 存档迁移：为什么放弃「硬映射」

§11 的 Q5 原来建议「按顺序对位硬映射（`1-1→0-1`、`1-2→1-1`…）」。实施时否掉了，原因是**两套 id 同名不同义**：

- v1 的 `1-1` 是「余烬·初燃」，三裂环，10 波；
- v2 的 `1-1` 是「灰烬熔炉」，窄口图，12 波。

硬映射会让老玩家的"已通关"标签落在一张他从没打过的图上 —— 更糟的是它**直接跳过**那张图，玩家永远不知道灰烬熔炉长什么样。

实际做法（`campaign.gd::_migrate_v1_to_v2`）：

| 保留 | 处理 | 理由 |
|---|---|---|
| Ember | **全额保留** | 真实投入，且只买"选择"不买"强度"，保留不破坏平衡 |
| 卡组解锁（`cinder-adv` 等） | 原样保留 | 新表里不存在 → `deck_exists()` 恒 false，既不生效也不报错 |
| 关卡进度 | **归零为「只通中枢 0-1」** | 不假装他打过 v2 的任何地区；但一开局就有 Ember、有中枢作起点，外环三区立刻可打 |
| `current_stage` | 一律回中枢 | 旧值指向的是语义不同的图 |

> 🔴 这条迁移**不是"清档"**：老玩家的 Ember 一分不丢，且立刻能进外环三区。真正丢掉的只有"已通关标记"。

### 9.2 「借用」：为什么"守住才给"不能是唯一的解锁规则

剧情大杠的原话是「用**该地区特有的科技**来守卫基地，成功守卫后便可获得该地区的帮助」。前半句和后半句在实现上是矛盾的：如果科技**只在守住之后**才给，那玩家守 1-1 的时候一包地区科技都没有 —— 只有中枢的泛用包。

两个显而易见的解法都错：

| 解法 | 为什么不行 |
|---|---|
| 首关直接把熔炉包送给你 | 剧情倒过来了：还没守就拿到了「守住才有的帮助」 |
| 首关就让你随便选 3 包 | 回到 v1 的"全部开放"，`S` 递增与地区推进全变成纯数值 |

采用的第三条路 —— **借用**：

| 阶段 | 玩家可用 | 说明 |
|---|---|---|
| 进任意地区关 | `core` + **该地区包（借用）** | 该包这一关能用，`card_packs.is_borrowed()` 为真，UI 显示「本关借用 · 点击选入」 |
| 守住该地区 | 该包进 `owned_regions`，**永久入手** | 借用标记消失，文案变「✓ 已选入本局」 |
| 打别的地区 | 只有 `core` + 已守地区的包 | 没守过的地区，它的科技你确实没有 |

于是开局曲线是 **1 包 → 2 包 → 3 包（封顶）**：

- 0-1（中枢）：只有 `core`，10 张卡 —— 教学关的"旧库存"手感；
- 第一次进外环某区：`core` + 该区包 = 2 包 20 张，`required_picks` 自动降到 2；
- 守住 2 区之后：≥3 包，回到"必须选 3 包"的完整构筑。

🔴 **`required_picks = min(3, 可用包数)` 是既有逻辑**（`card_packs.gd:182` 早就这么写），所以"早期没有选择余地"这件事不需要新代码 —— 只把解锁口径换掉，曲线自己就出来了。

落地要点：

- `unlock_by_region` **默认 false**：金标本 / MC / 老口径断言逐位不变；`boot.gd` 的 `DECK_BY_REGION_ENABLED` 是唯一的打开点。
- 注入位是**静态变量**（`owned_regions` / `stage_region`），所以 `boot._sync_deck_unlock()` 是唯一写入点，且关掉开关时必须显式 `set_region_progress([], "")` 清空 —— 跨局/跨测试残留会变成"幽灵解锁"。
- `validate()` 新增两条结构自检：地区包 ↔ 地区必须 1:1 且都在 `DECK_UNLOCK_STAGE` 登记（这类错误**不崩**，只会让某个瓦片永远锁着，UI 上看起来正常）。
- UI 文案由 `lock_hint()` 单点产出：地区口径说「守住 灰烬熔炉」，老口径说「到达 W6 解锁」。两处各写一份必然漂移。
- 🔴 文案长度受瓦片宽度约束：156px 可用宽 / 16px 字号 ≈ **9 个汉字**上限，「守住「永冻科考站」解锁」（11 字）实测被裁掉后半截 → 定稿为「守住 永冻科考站」（8 字），并给 `status` 标签开 `AUTOWRAP_WORD_SMART` 兜底。
