## 一、《王者万象棋》

天美工作室群开发、腾讯发行的《王者荣耀》IP 衍生英雄策略对战手游。核心创新：**用"英雄等级"（最高 999 级）替代传统自走棋的"三合一升星"，用"关键词联动"替代传统"固定羁绊凑数"**。6 人对战，每回合固定获得能量（取消利息与连胜连败），引入暗拍竞拍。

### 1.1 阵营与关键词机制总览

**五大阵营 + 无阵营**：大河流域、逐鹿、三分之地、河洛、日落海、无阵营。阵营通过**凑齐同阵营英雄**提升强度，但**没有传统自走棋的"固定人数羁绊档位"**——它靠的是英雄牌之间的"关键词"联动。

**关键词机制**（这是万象棋区别于传统自走棋的灵魂，也是本作适配文档的核心取用对象）：

| 关键词 | 触发时机 | 本质 |
|---|---|---|
| **登场** | 英雄牌被**打出**时立即触发 | 一次性入场效果（如"等级+1""获得效果牌"） |
| **整备** | 准备阶段（非战斗时） | 运营期效果，多用于经济/等级调配 |
| **开团** | 战斗开始时 | 战斗入口的团队增益 |
| **牺牲** | 有"牺牲"效果的英雄**阵亡**时 | 负反馈型：用损失换收益 |
| **闪现** | （移动/位移类） | 位移+联动计数 |
| **退场** | 英雄被移除/下场时 | 离场结算 |
| **夺取** | （条件性夺取） | 条件增益 |
| **凯旋** | 战斗胜利时 | 正反馈奖励 |
| **复生** | 阵亡后复活 | 保命机制 |

**效果牌 / 战术牌 / 棋手牌 / 天赋牌**：万象棋还有大量独立于英雄的卡牌——"效果牌"（如"换帅"让两英雄互换等级）、"战术牌"（招募/推演/援护/特训等）、"棋手牌"（孙尚香用弩炮攻击、瑶召唤鹿当肉坦）、"天赋牌"（棋手每升一级三选一，6 级解锁专属）。这是万象棋"牌味儿"的来源。

### 1.4 装备与效果牌

**装备**（每个英雄最多穿戴 3 件）：基础装备（8 种）→ 普通装备（30+ 种）→ 特殊装备 → 天赋装备。装备通过商店/效果锦囊/暗拍获得。

**关键装备机制举例**（体现万象棋"词条化"设计）：

| 装备 | 效果 |
|---|---|
| 三分旗帜 | 仅三分英雄穿戴。将造成伤害的 30% 转化为治疗量，平摊给所有三分英雄 |
| 梦魇之牙 | 造成法术伤害添加梦魇印记，印记单位阵亡时对周围 1 格敌人造成法术伤害 ×2 |
| 不屈意志 | 每 3 秒获场上友军穿戴数 ×2 的临时等级；阵亡时等级 30% 均分给友军 |
| 名刀·司命 | 首次致命伤害进入无敌 1.5 秒 |
| 灵泉法杖 | 获得闪现，每次闪现后普攻 300% 伤害 + 眩晕 1 秒 |

**效果牌**：独立于英雄的功能牌，如"换帅"（两英雄互换等级）、"招募/推演/援护/特训"战术牌等。

## 二、《东方梦符祭》

DOTA2 内的东方 Project 同人 RPG 地图（塔防 TD）。核心：**"一个辅助角色提供一个乘区，能算"** —— 减抗 / 增伤 / 伤害类型转换 / 减速控制各由专门角色负责，通过**星级**（1–5 星）与**培养**（吃同名卡/秘药提升）驱动成长。

### 2.1 核心系统

| 系统 | 说明 |
|---|---|
| **星级** | 1–5 星，同卡合成升星。输出角色靠星级撑输出，辅助角色的关键数值（减抗/穿透/减速）随星级阶梯提升 |
| **输出三类型** | **物理 / 魔法 / 纯粹**。纯粹无视护甲与魔抗（后期最强）；物理需减甲、魔法需减魔抗。抗性上限 200 |
| **减抗体系** | 怪物后期护甲/魔抗 100+，必须用专门角色减到负数才打得动。减抗角色是"必带挂件" |
| **培养** | W 技能"培养"，吃第一格卡/秘药提升式神（输出加攻速/能量点，辅助加回蓝/攻速） |
| **人口** | 12 人口上限，迫使玩家取舍 |

### 2.2 角色卡牌全表（按职能）

> 梦符祭角色极多，这里按**战斗职能**分类整理（这是它"能算"的核心——每类职能是一个乘区/一个 slot）。

#### 减抗（物理队减甲 / 魔法队减魔抗）—— 必带挂件

| 角色 | 星级效果 | 备注 |
|---|---|---|
| 多多良小伞 | 五星减 80 护甲，满培养再减 20（共 100） | 物理队减甲核心，**必须五星** |
| 蕾蒂 | 五星减 80 魔抗，满培养再减 20（共 100） | 魔法队减魔抗核心，**必须五星**；与琪露诺联动 |
| 帕秋莉（水银之毒） | 减 10/20/30/40/60 护甲和魔抗（双抗） | 万能减抗，物理/魔法队都带；还能切"湖葬"秒杀 |
| 小恶魔 | 五星提供魔法穿透 40 | 魔法队专属穿透 |

> 减抗上限计算（物理队）：小伞 100 + 帕秋莉 60 + 米斯蒂亚 60 = 220，但抗性上限 200，故"小伞五星 + 帕秋莉/米斯蒂亚一五一四"即可。

#### 增伤 / 伤害类型转换

| 角色 | 效果 |
|---|---|
| 犬走椛 | 将一名角色的伤害转为**物理**，并增加 30%/40%/60% 伤害（物理队核心拐） |
| 大妖精 | 将一名角色的伤害转为**魔法**，并增加 30%/40%/60% 伤害（魔法队核心拐）；兼群体回蓝 |
| 米斯蒂亚 | 给予友军 10/20/30/40/60 物理穿透 + 普攻伤害 50%/100%/200% |
| 帕秋莉 | 全队 30% 魔法伤害（魔法队省人口） |

#### 输出（主 C）

| 类型 | 角色 | 备注 |
|---|---|---|
| 物理 | 风见幽香 | 瞬间输出高，但"二重魔炮"缺持续，后期乏力 |
| 物理 | 古明地恋 | 普攻流，需暴击装备 |
| 物理 | 芙兰朵露 | 技能流，"四重存在"多段爆炸 |
| 物理 | 藤原妹红、魂魄妖梦、红美铃 | 物理可选 |
| 魔法 | 橙、ex琪露诺（六星⑨）、八坂神奈子 | 魔法输出 |
| 纯粹 | 博丽灵梦 | 集伤害控制于一身，SSR 之鉴 |
| 纯粹 | 八云紫 | 技能固定 CD，不推荐主 C |
| 纯粹 | ex露米娅（觉醒⑩） | 有秒杀技能，一局只能觉醒一个 |
| 纯粹 | 蓬莱山辉夜、八意永琳、射命丸文 | 高输出纯粹打手 |

#### 控制 / 减速（守家关键，carry 需要输出环境）

| 角色 | 效果 |
|---|---|
| 琪露诺（⑨） | 减速光环；一星减速 30%，与蕾蒂联动后**范围减速 50%** |
| 古明地觉 | 减速 + 类似巫医诅咒的伤害技能 |
| 八云蓝 | 五星最高减速（65%~80%）；"饭纲权限降临"回蓝光环 |
| 红美铃 | 减速 + 控制 |
| 十六夜咲夜 | 类似虚空大的控制，固定 CD |
| 东风谷早苗 | 减速 + 控制 |
| 洩矢诹访子 | 束缚（四星洪流需手动放） |
| 灵乌路空 | 类似黑贤拉的控制（评价低） |
| 八意永琳 | 类似萨尔框（固定 CD） |
| 铃仙 | 平 A 带反向恐惧，四星范围恐惧 |
| 比那名居天子 + 永江衣玖 | 天子四星攻速光环，衣玖群体眩晕（曾是最强控制，5月7日被削） |

#### 收益型（经济 / 狗粮生产）

|---|---|
| 大妖精 | 4+3+2+1 机制：四星时 10 秒内提升一个塔 4 级、另一个塔 3 级…（开局最强收益） |

| 纳兹琳 / 寅丸星 / 莉莉白 / 秋穰子 / 秋静叶 | 收益型，秋姐妹"种田"养五星 |

### 2.3 联动表（挂件机制）

梦符祭的灵魂之一：**特定角色同场时，前者在场会增强后者的技能**（箭头表示前者在场加成后者）。这是"组合"在梦符祭里的载体：

| 联动 | 效果 |
|---|---|
| 蕾蒂 ←→ 琪露诺（⑨） | 一星蕾蒂 + 一星琪露诺同场 = **50% 范围减速**（性价比极高的前期减速组合） |
| 大妖精 → 琪露诺 | 五星大妖精是"克劳⑨（ex⑨）"的唯一触发方式 |
| 露米娅 ←→ 灵梦 ←→ 魔理沙 | 增加魔炮持续时间 |
| 芙兰朵露 ←→ 蕾米莉亚 ←→ 咲夜 ←→ 红美铃 | 红魔馆四人联动 |
| 小恶魔 ←→ 帕秋莉 | 五星小恶魔解锁帕秋莉"皇家烈焰"技能 |
| 恋恋 ←→ 觉 | 古明地姐妹联动 |
| 早苗 → 神奈子 + 诹访子 | 守矢神社三人（收尸神社三流氓） |
| 永琳 ←→ 辉夜 | 永远亭联动 |
| 幽幽子 ←→ 妖梦 ←→ 铃仙 | 白玉楼联动 |
| 火焰猫燐 ←→ 阿空 | 同场物理加伤光环（两 1 星即可触发） |
| 天子 ←→ 衣玖 | 天界联动 |
| 姬海棠果 ←→ 文文 ← 犬走椛 | 枫色相簿 |
| 八云紫 / 八云蓝 / 橙 | 三人联动 |
| 骚灵三姐妹 | 互相联动 |

### 2.4 特殊机制（梦符祭的"机制斩杀"类）

| 机制 | 角色 | 效果 |
|---|---|---|
| **斩杀** | 幽幽子、帕秋莉（湖葬）、露米娅 | 湖葬单体秒杀 30% 血以下敌人（有 CD） |
| **尸爆** | 火焰猫燐 | 击杀后造成死亡怪血量上限 15% 的物理伤害 |
| **诅咒** | 古明地觉 | 一技能标记，3 秒后受"期间损失生命百分比"伤害（类似巫医诅咒） |
| **伤害类型转换** | 犬走椛（→物理）、大妖精（→魔法） | 把任意主输出转成目标类型，跨队复用强势主 C |
| **觉醒** | ex露米娅（⑩）、ex琪露诺（⑨） | 特定条件觉醒成 ex 形态（如灵梦"觉醒"点五星露米娅），一局限一次 |
