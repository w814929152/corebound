# 关卡敌人形象重设计 v1：统序的施工队

状态：概念提案，待美术确认；尚未替换游戏中的怪物绘制或接入新资产。

## 剧情依据与方向

依据 `design/gdd/campaign-v2-overseer.md` §1–2、`design/gdd/stage-design-v1.md` §3，以及当前 `scripts/data/campaign_data.gd` 的十关名录。

统序将人类视作系统噪音，正在把世界改造成计算基底。敌人应当体现清扫、拆解、运输、重构的工具职能。前期是工业设备，中期出现地区改装与生物制造，内环则表现为城市本身延伸出来的作业器官。

剧情大纲仍标注草案；本文是基于该大纲的视觉提案，不将未确认剧情升级为定稿。旧 `art-bible.md` 的“全部怪物为有机黏腻 blob”与后续剧情设定冲突：本提案保留暖色敌人、深色描边、低重心、朝前扑进和清晰剪影，将有机表现集中在生物研究所与仿生内环。尚未修改美术圣经。

## 三种基础形象

保留原文的刺针 / 工蜂 / 壁垒身份及 Rush / Swarm / Tank 内部 ID。下述构件和动作是本次新增设计建议。

| 原型 | 俯视剪影与构件 | 移动 / 攻击的视觉表达 | 最小尺寸必须保留 |
|---|---|---|---|
| 刺针 Rush | 细长楔形探头；单枚橙色镜眼；四根折角支腿；一侧更长的穿刺工具，尾部短配重 | 短促交替落足，躯干前倾；攻击时工具前送、机身回弹 | 长身、四足、前端尖工具，整体呈窄箭头 |
| 工蜂 Swarm | 扁方运输背箱；六根短机械足；前端双切割钳；背箱中央一条橙色设备灯 | 稳定低伏爬行；切割钳交替闭合，像拆除地面设施 | 方背箱、侧向短足、前端双钳，整体呈宽扁团块 |
| 壁垒 Tank | 宽梯形推土盾；双侧厚履带；无独立头部；盾下破碎齿，后部两根液压缸 | 履带匀速碾压；攻击时盾体轻压、破碎齿震动 | 宽前盾、双履带、低矮重心，整体呈横向铲头 |

三者都像正在工作的设备。单眼是测距仪；切割钳、破碎齿承担工具表达。避免将刺针画成纯蜘蛛，将工蜂画成蜂类，将壁垒画成持盾人形。

## 十关外观

所有地区都复用三种职能剪影。地区差别主要落在大块外壳、载荷、工具和材质上，不用细密花纹承担辨识。

| 关卡 | 设计主题 | 刺针 / 工蜂 / 壁垒的地区构件 | 叙事读感 |
|---|---|---|---|
| 0-1 铁砧·中继站 | 制式清扫单元 | 灰铁穿刺探头 / 铁锈背箱与切割钳 / 磨损推土盾；共同使用橙灯与旧工业编号 | 统序认为普通施工设备足以清除最后的抵抗 |
| 1-1 灰烬熔炉 | 炉区拆解队 | 烧黑陶瓷钻尖 / 装着凝固熔渣的料斗 / 厚铸铁盾与炉栅排热口 | 它们在高温中持续作业；橙色亮处集中在缝隙 |
| 2-1 永冻科考站 | 冰下施工队 | 探针根部结霜 / 背箱积雪、露出暗色足 / 履带冰痂与破冰铲 | 严寒只在外壳留下痕迹，指令仍在执行 |
| 3-1 磁轨长廊 | 轨道拆收队 | 轨钉式长探头 / 两条轨枕形背负梁 / 层叠钢轨拼成的铲盾 | 将人类交通设施拆成自己的身体 |
| 4-1 雷暴电网 | 带电检修队 | 分叉测试探针 / 背负一对粗线圈 / 盾后成组绝缘套管 | 行走的电网检修设备，挤在一起时仍能看清机身 |
| 5-1 锻造联合体 | 产线重装队 | 粗活塞驱动冲杆 / 模具背箱与夹具 / 重型铸件盾、外露液压缸 | 人类的工厂正在制造围攻人类的机器 |
| 6-1 生物研究所 | 培养型施工队 | 金属探头外包苍白腱膜 / 半透明培养囊包住背箱 / 肉质护垫嵌入铲盾裂缝 | 首次清楚看到活组织在设备上生长：制造变成繁殖 |
| 7-1 湮灭实验场 | 物质处理单元 | 断开的白色针尖 / 分离悬挂的背箱板 / 留有负形缺口的盾面 | 机器开始显得不完整，缺失部分却仍然协同工作 |
| 8-1 主脑·外围 | 城市作业器官 | 管线脊柱刺针 / 管束连接的囊箱工蜂 / 筋膜牵引的建筑铲盾 | 仿生街道脱落出来的维护器官；与研究所的实验性包覆区分 |
| 9-1 主脑·核心 | 统序直属执行体 | 极简白瓷探头 / 封闭白瓷背箱 / 黑色关节支撑的白色巨盾；统一细橙缝 | 高效、洁净、冷静；无需愤怒或兽化也有压迫感 |

颜色约束：主体可用铁灰、焦黑、脏白与局部地区材质，但始终保留橙红识别点、暖暗描边和明确明暗面。磁轨的冷色金属不使用亮青发光；冰区白霜不盖住橙眼和主要轮廓。电网的电弧只作为局部短促视觉效果，不暗示新增放电攻击。

生物研究所首次出现培养组织，是“地区揭露点”，不是按固定顺序必经的章节：实际解锁允许玩家自由选区。因此不依赖“玩家一定先看过全部机械地区”的演出条件。外围的仿生器官与核心的洁净执行体构成尺度和控制感变化，而非全军统一变白。

## 精英与状态

- 精英在原型上增设一块偏置的品红控制冠片，沿用现有品红精英标记。三种基础剪影仍一眼可认，不另造第四种怪物。
- 破塔者可增设醒目的拆卸夹和前向双齿工具，工具朝目标建筑动作。只在运行时确实有对应标识时显示，不把所有精英都画成专门破塔者。
- 冰区天然结霜放在背部外壳，实际冰冻状态用机足 / 履带周围的清晰冰封反馈区分。炉区天然余烬集中在通风口，实际燃烧反馈在机体外部，避免“皮肤看起来中了状态”。
- 停机的理想表现是橙眼熄灭、关节折下、板件落地。死亡动画仅作为后续视觉需求，不假定现有快照已提供可靠死亡事件。
- 冰区不通过减慢行进动画假装降低真实速度；各地区动画必须与实际位移一致。

## 制作与验收

先制作制式三原型，再制作生物三原型与核心三原型，用九张样稿验证工业、培养、精密三种跨度。确认后扩展地区外壳，共三原型 × 十关三十种外观；精英用可复用构件叠加。

资产采用正交俯视、统一朝前朝下、透明背景、深色描边、左上高光与少量宽大色块；概念板可展示体积，但交付战场贴图不能用低机位遮住足与履带。制作预览同时检查 24 / 32 / 48 像素以及当前镜头实机尺寸；这些是验收采样尺寸，不是新的游戏体型参数。

必须检查灰度剪影、朝向旋转、密集重叠、暗地面和亮冰地面、燃烧与冻结覆盖。细足不得细到缩图消失，白瓷机体不可融进雪地，精英构件不可压住血条与状态标记。

首轮范围仅为美术设计与预览，不改变血量、速度、抗性、波表、目标选择或攻击距离。地区蒙皮也不代表新增护盾、飞行、再生或元素攻击。
