## 1. 为什么单独开这一包

资产包 v1 补齐的是**静态界面件**——按钮、面板、卡框、图标。但**战斗 HUD 一件贴图都没有**：

| 元素 | 改造前 |
|---|---|
| 金币/积分读数 | 一个 `StyleBoxFlat` 方块（214×86） |
| 波次进度条 | 一根 300×10 的裸细条悬在战场上 |
| 核心血条 | 20 个直角方块，底部一整块底座面板 |
| 画面四角 | 空白 |

结果是 HUD 读起来像"浮在战场上的字"，而不是一套设备读数。这一包把 HUD 变成仪表层，并且**不改动任何布局**：所有贴图按既有常量出图，接入只是在 `_draw` 里垫底。

## 3. 视觉规则（本包新增，后续 HUD 资产沿用）

1. **承托板比战场亮一档。** 战场实测底色 `#231B2B` / `#111A2B`，用面板底 `#141726` 画承托板等于隐形（首版实测就是"看不见"）。HUD 承托板固定用 `#242B3E`（`P_HUD`，`P_CARD #1E2332` 再提一档），**靠明度差分离，不靠发光**。
2. **切角 = 零件切口。** 承托板用对角切角（左上 / 右下），切出来的两个斜面染耀青 —— 这是整件最锋利的识别点，也是与 v1 圆角面板区分开的语言。
3. **刻度尺只给"有量程"的东西。** 波次条上方 11 根刻度与填充的 12 格同相位（每 25px），第 4/8/12 格加长加深。装饰性刻度一律不加。
4. **凹陷三段式**：外 1px 暗缝 → 内墨黑 `#05070E` → 底 1px 反光。只用在"槽"上（波次条、血条段位）。
5. **红色不靠颜色单通道**：告警段同时换色（`#FF2E4E`）**和**加 45° 斜纹（§9.2）。
6. **角标信息量只留一条 L + 两个收头点**：加第二组刻度在 2× 放大下会读成"游离短划"。

## 4. 接入方式（零布局改动）

两个文件，只在 `_draw()` 里加绘制：

```gdscript
# hud.gd / core_hp_bar.gd 各一份缓存（_draw 每帧跑，禁止每帧 load + exists）
var _tex_cache := {}
func _ht(name: String) -> Texture2D:
    if _tex_cache.has(name): return _tex_cache[name]
    var path := "res://art/2d/ui/" + name
    var t: Texture2D = null
    if ResourceLoader.exists(path): t = load(path) as Texture2D
    _tex_cache[name] = t
    return t
```

- **判空降级**：贴图缺失（headless 无 `.import` / 文件丢失）→ 逐项退回原 `StyleBoxFlat` / `draw_rect` / `draw_style_box` 路径，画面与改前逐位一致。
- **旧件让位**：贴图生效时，`_box_score`（金币方块）与 `_box_slot`（血条整块底座）**不再绘制** —— 否则读成双层盒子。
- **不动控件**：没有新增节点、没有改 `position/size`、没有改锚点。
- **四角角标**用 `draw_set_transform` 镜像，画完必须复位，否则同帧后续绘制全被镜像。

## 5. 制作过程中踩到的坑（可复用）

| 坑 | 现象 | 结论 |
|---|---|---|
| 承托板同色 | 底板与战场底色几乎一致，整块隐形 | **HUD 底必须比战场亮一档**（`#242B3E`） |
| 纹理高光带 | 22px 的段加 4px 渐变高光，20 段连排后像钢琴键 | 小尺寸段只留 **1px 亮顶 + 2px 暗底** |
| 空槽纯黑 | 低血时 16 个空槽连成一条黑带，"太重" | 槽底 α246 → **α178**，让战场底色透一点 |
| 盖住读数 | 波次导轨 56px 高把"已出/总数"整个罩住 | 导轨高度**只到读数上沿之上**（36px，收在 by+13） |
| 撞按钮 | 导轨 392 宽压到"开始下一波"（bx+326 起） | 右端只外扩 **20px**（348 宽） |
| 冒烟假象 | 低血帧拍出一片纯白块 | 血条靠 `set_hp` 触发重绘；冒烟工具没绑 controller → **须每帧 queue_redraw**，否则碎段闪白那帧被冻住 |
