## 战斗类型系统（物理/魔法 × 物抗/魔抗）

应需求「丰富游戏属性，增加物理攻击/魔法攻击/物防/魔防等机制」，落地了一套完整的战斗类型机制。

### 设计决策（经用户确认）
- 攻击类型**按塔分**：Arrow/Cannon/Lance → 物理；Frost/Tesla → 魔法（单一类型，不可切换）。
- 抗性用**百分比抗性**：伤害 = 基础 × (1 − 抗性)，抗性 ∈ [0,1]。
- 零扰动铁律：默认开关 `combat_types_enabled=false`，抗性全 0 时 `×(1−0)` 恒等 → 金标本逐位不变。

### 抗性定稿初值（守恒验算通过）
- Rush：物抗 0.00 / 魔抗 0.20（怕魔法）
- Swarm：物抗 0.00 / 魔抗 0.00（基准怪，金标本等价）
- Tank：物抗 0.30 / 魔抗 0.00（铁甲，物攻刮痧）
- 加权平均减免：物抗 0.06 / 魔抗 0.08（≤0.10，不抬高整体难度）

## 真实伤害（True Damage）· 第三种攻击类型（2026-11-07 第四次）

应需求「新增真实伤害」，在战斗类型系统之上补全第三种攻击类型「真实」，无视一切抗性。

### 设计
- **真实伤害语义**：无视物抗/魔抗，也不受破甲影响（抗性表 `true` 键恒 0 → `apply_resist(dmg,0)=dmg` 全额）。
- **克制对象**：Tank（物抗 0.30）/ Rush（魔抗 0.20）—— 真实伤害打谁都全额，是「高抗性怪」的通用解。
- **平衡代价**：真实伤害塔面板 dps 刻意压低（Oblivion 6 / Void 5），只有打高抗怪才划算，保住「打什么怪用什么塔」的构筑决策。
- **两塔 + 双强化 + 卡包**：Oblivion（真实主塔·单体）/ Void（真实第二塔·aoe），tag 独立 `true`，强化 TrueUp/TrueUp2，卡包「湮灭包」@20。

### 新增/修改文件
- **修改** `scripts/data/combat_types.gd`：新增 `TRUE` 常量 + DAMAGE_TYPES 三元组；TOWER_DMG_TYPE 加 Oblivion/Void→true；MONSTER_RESIST 各原型加 `"true": 0.00` 键。
